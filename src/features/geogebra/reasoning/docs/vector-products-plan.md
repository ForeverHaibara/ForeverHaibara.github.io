# 向量点乘、叉乘：修订设计与首批实现

2026-10-23，依据用户对上一版计划的审阅修订。首批实现已经接入发现、局部条件建议、条件／目标 IR、混合 DDAR、可读证明和项目导出；数学与验证细节见 [数学推导](vector-products-math.md)、[实验记录](vector-products-experiments.md)。

## 1. 本次修订的关键决定

1. 原点可以是独立参考框架，不必是构造中的几何对象。位置原子 `A·B`、`A×B` 是相对于该原点的“非齐次”量，位移积 `(B−A)·(D−C)`、`(B−A)×(D−C)` 是“齐次”表达式；这里指平移和原点语义，不与多项式次数混淆。两类都可表示，不能要求为了内部原子表而创建 O。
2. 沿用现有 DDAR／可读证明的条件性非退化处理：积运算本身允许零向量；转换成直线方向、相似逆定理等时检查相应条件，坐标选择分支单列 guard。不要求先建立一个覆盖所有退化情况的全新证明系统。
3. 面积作为叉乘的后续视图，当前不增加有向／无向三角形面积产品功能。
4. 问题 B 完全可以先证明 `AH∥FG`，再结合等腰构型得到垂直。上一版漏掉这条线性叉乘路径，误将四次证书视为必需。该判断已撤回，当前实现不引入高次运算或多项式求解器。
5. 事实交换以长度乘积和对应角为通用依据；逆相似是重要实例，不能把所有转换都限制成一个命名的逆相似模板。

## 2. 共享表达式与原点

`geometry/vectorProducts.ts` 定义有向向量引用、带整数系数的积方程、原子展开、规范键、数值复核和格式化。

```text
VectorReference = [from, to]       // 端点可为 null，表示独立坐标原点
VectorProductTerm = coefficient × product(left, right)
VectorProductEquation = { operation: dot|cross, terms } = 0
```

例如 `[A,B]` 表示 B−A，`[null,A]` 表示位置向量 A；`null` 不是对象 ID，不进入点预算、作图图或依赖评分。项目导出保存原点在归一化坐标中的位置，避免把内部平移后的 (0,0) 错当成 GGB 原点。

内部编译为对称点乘原子与反对称叉乘原子的稀疏行：

```text
AB·CD = B·D − B·C − A·D + A·C
AB×CD = B×D − B×C − A×D + A×C
```

端点反转保留负号；点乘交换参数不变，叉乘交换参数变号。系数按 gcd 和整体符号得到语义键，恒等零行不作为发现结果。对用户显示原始有向线段表达式，不从展示字符串解析公式。

当前 UI 自动搜索优先覆盖位移积；独立原点的位置积已由公共表示、IR、归一化、后端和格式化支持，不需要命名原点。后续如增加任意参考框架的输入控件，应继续使用同一表示。对非齐次观测不宣称原点移动后仍保持同一数值关系。

## 3. 自动发现与代码复用

新增目录类型 `dot-products`、`cross-products`，归入 Vectors，参与 Compute、List filters、偏好迁移、检索和对象联动。

`analysis/relations/vectorProductRelations.ts` 采用有界候选：

- 先用已有三角形匹配提出逆向混合积候选，独立进行数值复核，不把观测提升为证明。
- 共享顶点的积优先，再轮转枚举有向线段对。每类使用现有 `maxAngles` 候选预算、`maxComparisons` 比较预算及最多 64 个输出。
- 复用 `groupScalarClasses` 的等值簇和 `RationalRelationSpace` 的有理约化。等值／反值用符号保存，不对有符号积取 log。
- 共线、平行、垂直、等长、中点的已观测线性积后果用于展示压缩。关闭压缩可展开，并保留来源；这些来源不会自动变成已接受条件。
- 近似等值簇内部按稳定的符号键选择代表，避免浮点舍入使镜像或单位变化后选出不同的展示星形。
- 最终用原始位移式复核，按 `max(1,Σ|c|·||u||·||v||)` 管理残差；方向病态与相等容差分开。

原子数量 O(n²) 不等于全部关系搜索只有 O(n²)。通用位移积候选最坏 O(n⁴)，本实现不穷举所有两积配对；截断会明确报告 partial。仍是有限预算的数值发现，不是完备性质库。

局部建议继续复用 `proposeConditions`、独立发现池、Jacobian 秩与发现／留出样本。新增积谓词接入残差、成本、语义去重和样本复核。有限差分在归一化多项式上执行；没有将局部秩 2 解释成逻辑充分性证明。

## 4. 证明层：线性积域与几何规则双向交换

新增 `public/geometry-reasoning/vector_algebra.py`；固定的 `vendor/alphageometry2/` 保持原样。

### 4.1 有理线性核心

复用 `proof_algebra.Basis/ProofGraph`，增加 dot、cross 两个实数加法域。各行记录精确有理来源，线性消元直接由现有独立回放器复核。模 π 角域仍用整数格，不套用实数域约分规则。

首版不实现大型仿射商空间求解器。已接受的中点保留原生语义，向各位置向量做点乘／叉乘收缩，产生有来源的线性行。这与先进行仿射代换的路线在本批需求上等价，后续可在确有性能需求时加入仿射基约化。

### 4.2 交换规则

| 几何事实 | 积域后果／逆向转换 |
| --- | --- |
| 平行、共线 | 叉乘为零；相关方向非零时恢复平行 |
| 垂直 | 点乘为零；相关方向非零时恢复垂直 |
| 等长 | 平方范数相等；反向恢复等长 |
| 已证正有理长度比 | 平方范数的相应平方倍率 |
| 中点、点重合 | 仿射关系与各位置向量的积收缩 |
| 相同长度乘积与相同／相反模 π 角 | 点乘／叉乘等式，射线的 π 提升另记 guard |
| 两条混合积等式 | 非退化时恢复对应的逆相似，进一步产生边比与角关系 |

通用“长度＋角”交换先在旧长度乘法基中证明两向量长度乘积相等，再在角基中证明两夹角相等或互为相反数。由于旧角语义为模 π，符号需要对应射线提升，按现有条件性证明模式保存 `witness-product-angle-lift`。数值只提供该明确分支，不补充长度／角前提。

已知逆相似会向这一通用转换器提交两个混合积候选；直接选作目标的二项积等式也可调用同一转换器。数值三角形形状仅用于限制逆命题的搜索范围，必须同时在线性积基中证明点乘、叉乘两式，才可回写相似事实。

### 4.3 闭包与一致的执行路径

```text
已接受条件
  ├─→ AG2 几何子集 → DDAR 闭包
  └─→ 原生中点／积语义 → dot/cross 精确线性基
                        ↕
             长度、角、平行、垂直、等长、相似
```

站点外层先运行既有 DDAR；若目标仍需新能力，再按需展开积域并反复同步，以新增独立行和几何事实判断进展。已完成的目标优先保留其来源，避免新域挤占旧证明的记录预算。没有复制或修改上游闭包算法。`check`、可读证明和 coverage 对带向量上下文的问题使用同一协调器。

首版资源边界：40 点和 250 谓词沿用原限制；方向交换最多扫描 80 条有效线段；相似候选最多枚举 3000 个三元组、768 个对应；积基查询预算 100000；外层最多 12 轮；证明图仍受已有节点限制。截断标记进入报告，不将未推出解释成否证。

点合并沿用上游机制，显式重合前提也向积域提供仿射收缩。尚未为所有上游隐式点合并重建独立的几何证书；现有来源缺口继续显示，不作完整形式化认证承诺。

## 5. 条件性非退化与证明可信边界

参考现有 `Knowledge.separated/guard`、DDAR 数值方向与相似分支处理：

- 积表达式允许零向量，包括同一端点的位移；这与直线方向未定义是两回事。
- 从零积恢复方向关系时检查非零，并写入 `witness-nonzero-vectors`。
- 混合积逆定理检查两个三角形非退化，并单列相应坐标 guard。
- 假设模式可以接受不满足数值见证的积方程，继续精确线性推导；不从原图补方向或非零分支，也不调用要求坐标真值的 DDAR。
- 采样通过、已接受条件、引擎推导和 gap 仍独立记录。查询目标的语法可以引导规则尝试，但目标真值绝不作为前提。
- 代数回放只验证来源系数；几何模板与分支仍是当前检查器的显式可信输入，`certificate` 继续为 null。

Worker 加载新增模块；既有取消、超时、解释器复用和快照隔离保持原路径。可读证明增加积原子、长度／角转换、仿射收缩和逆相似的规则标签与 Markdown 展示。

向量在界面上使用上方箭头排版：单个点名表示位置向量，两个端点表示有向位移。虚拟坐标原点不展示；若原点本身是命名的几何对象，则保留其真实名称。每个点乘／叉乘整体加括号，标量系数置于括号外，避免把标量乘法和叉乘混为一谈。可读证明、关系卡片和 Markdown 数学公式共用格式化规则；纯文本及无障碍标签分别使用 `vec(B)`、`vec(A, B)`，分数系数保留精确值。长公式允许在容器内横向滚动。

## 7. A、B 的验收

A：中点、高线、投影条件进入积基，线性推出 `MA·MD=MB²`；与共线叉乘式合起来恢复 `BMD∼AMB`。不命名反射点。

B：先由相似／直角转入点乘，推出 `BG=DG`；叉乘直接证明

```text
AH×2FG = AH×(BE+DC)
        = AB×BE + AC×DC
        = AB×AE + AC×DA = 0.
```

于是 `AH∥FG`；等腰三角形 BGD 中 F 为 BD 中点，得到 `FG⊥BD`。实现也可以直接从等距平方范数及中点的线性积式推出同一垂直事实。所有新代数步骤都是二次几何量的线性组合。

回归包含两条 B 路径：从长度与角条件开始，向积域转换；以及从两个积条件开始，回写逆相似、让 DDAR 推出直角，再返回积域。另覆盖六构型自动建议到三项目标的原生端到端检查。
