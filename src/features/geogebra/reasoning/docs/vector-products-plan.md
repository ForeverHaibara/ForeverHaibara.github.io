# 向量点乘、叉乘：发现与证明的联合设计计划

日期：2026-10-22。状态：源码调研与设计，**尚未实现**。本轮只新增设计文档，不修改运行代码、上游内核、构图或测试实现。

配套：[数学规则与两个题目的推导](vector-products-math.md)、[本轮实验与复现](vector-products-experiments.md)。

## 1. 结论与范围

建议增加一个以**仿射向量表达式和原子双线性积**为核心的共享语义层，在发现侧复用已有的标量索引、等值簇和有理行空间，在证明侧增加带精确来源的双线性消元，并通过可审计规则与 DDAR 反复交换事实。

需要区分三个层次：

1. 向量的仿射线性关系，例如 `2M−B−C=0`。
2. 将点乘、叉乘提升为原子量后的有理线性消元，例如由垂直关系推出 `AB·AC=AB·AD`。
3. 利用二维代数恒等式、方程乘法和非零因子消去的有限规则。它们能补足线性提升的能力边界；问题 B 的最后一条目标给出了实际需求。

不能只增加数值检测器，也不能只在 DDAR 结束后验证向量结论。新增关系必须能进入前提、成为中间步骤，再产生平行、垂直、等长和带对应顺序的相似关系，继续触发 DDAR。

首批目标是二维、精确有理系数、齐次的点乘／有向叉乘等式。面积作为叉乘的语义视图。任意整数关系挖掘、完整多项式理想求解、三维叉乘、辅助点搜索不作为前置工作。

## 3. 原点、方向和语义边界

### 3.1 支持原子积，但不把任意原子等值当作内在几何关系

任选坐标原点 O，记 `gᵢⱼ=OPᵢ·OPⱼ`、`wᵢⱼ=OPᵢ×OPⱼ`。所有有向线段积都可展开，例如：

```text
AB·CD = gBD − gBC − gAD + gAC
AB×CD = wBD − wBC − wAD + wAC
```

原子表是优良的内部消元坐标，但 `OA·OB=OC·OD` 一般依赖 O。当前 scene 还会随参与点集合改变归一化原点，直接搜索这种原子等值会产生随列表范围变化的“几何关系”。

建议分为两种明确的语义：

- 默认内在几何：表达式由位移或系数和为零的仿射向量组成，因此原点自动消去。
- 显式参考原点的关系：用户确实研究 `OA·OB` 时，保留 O 的身份。O 可以是现有点，也可以是明确的 GGB 坐标原点框架引用；后一种不假装成命名几何点，不增加作图对象或依赖评分点。

首版先做好默认内在几何和既有命名参考点。GGB 固定原点支持可在下一小阶段加入，不能借用随场景变化的数值原点冒充它。内部证明原点可任选既有点，属于换坐标，不是辅助作图或附加假设。

如允许直接输入原子行，需做平移不变性检查。对于按 `i≤j` 保存的点乘行，要求每个 i 的 `2cᵢᵢ+Σⱼ≠ᵢcᵢⱼ=0`；对于按 `i<j` 保存的叉乘行，要求每个 i 的有向入出系数平衡。仿射前提下才成立的平衡也必须记录所用前提，不能无条件化。

### 3.2 规范化

- 有向线段 `AB=B−A`；反转一个参数使积变号。线段端点可以规范排序，但必须返回符号。
- 点乘交换两个向量不变；叉乘交换两个向量变号，`u×u=0`。
- `gᵢⱼ=gⱼᵢ`；`wᵢⱼ=−wⱼᵢ`，`wᵢᵢ=0`。后者与消项后零行都是恒等式，不作为发现结果。
- 系数用精确有理数，按清分母、gcd、整体正负号得到稳定键。该实数域允许整体约分，与模 π 的角方程不同。
- 点乘与叉乘分别维护关系域。镜像保持点乘、改变叉乘符号，同域齐次等式保持有效。首版不自动搜索混合 `dot=cross` 这类依赖定向约定的等式。
- 点乘和叉乘都是 L² 量纲。默认等式齐次，不将它们与 L¹ 长度相加，也不拟合无参考量的有单位常数。
- 有向双面积 `[ABC]₂=AB×AC`；面积视图不创建重复的计算域。无向面积需要绝对值及分支语义，另行处理。
- 零向量的积仍有定义。只有从 `u·v=0/u×v=0` 转回直线垂直／平行时，才需要相关向量非零。

## 4. 建议的共享表示与模块边界

### 4.1 最小公共语义

在 `src/features/geogebra/` 下新增中立的 `geometry/` 或 `algebraicGeometry/` 小目录，供发现与 reasoning 共同依赖。不要让发现器反向依赖 AG2 编译器，也不要把 Python 后端语法用作前端 IR。

概念数据，不是本轮接口定稿：

```text
AffineVector = Σ rationalᵢ · PointRefᵢ       // 位移要求 Σ rationalᵢ=0
VectorProduct = { operation: dot|cross, left: AffineVector, right: AffineVector }
ProductEquation = Σ rationalₖ · VectorProductₖ = 0
AffineEquation = Σ rationalᵢ · PointRefᵢ = 0 // 系数和为零
Similarity = { first, second, correspondence, orientation: preserving|reversing|unspecified }
```

保存两个视图：有向线段／仿射表达式适合用户阅读；规范原子行适合键、去重、消元。二者由确定性的编译过程关联，不同时维护两套可分叉的真值。

正／逆相似必须有独立语义或明确的命题展开。只接受当前的两条边比，不能据坐标默默增加逆向条件。如果通过采样发现了两个混合积等式，可以把它们作为一个合取候选，用户接受后才成为条件；它们与从边比加方向 guard 得到的事实来源不同。

### 4.2 原子行和仿射消元

证明先处理已接受的仿射约束，如 `2M−B−C=0`，再在其商空间中展开原子积。可以先把各点向量精确表示成少量形式基向量，再展开基向量的对称积／反对称积，减少中点等带来的变量膨胀。

另一种等价实现是对仿射行与各向量做点乘／叉乘，登记双线性后果。优先采用前者；证书需保留仿射替换来源，使其可回放，而不是只保留替换后的数值结果。

没有仿射约束、n 个点时，任选一个既有点作内部原点，点乘和叉乘原子总数上界是 `(n−1)²`；40 点为 1521 个。它们是形式量，不是 1521 个独立的真实几何自由度。二维 Gram 秩、Plücker／Lagrange 恒等式仍有非线性约束。

### 4.3 复用与必须分开的部分

| 可以共享 | 必须区分 |
| --- | --- |
| 稀疏有理行合并、排序、签名、原始来源集合 | 发现观测行空间与严格证明行空间 |
| 实标量排序检索、小系数组合索引、预算计数 | 角的模 π 整数格、长度 log、点乘／叉乘实数域 |
| 等值簇的有界直径和代表见证结构 | 单位、方向、零值合法性、原点和镜像语义 |
| 仿射／积表达式编译及恒等消项规范 | TypeScript 与 Python 的执行实现，须用共同规范用例约束 |
| 条件、目标、采样证据、依赖支持集框架 | 数值近重合与符号点相等、数值不共线与严格非退化前提 |

现有 `RationalRelationSpace` 可用于发现压缩；`Basis` 可扩展实数域用于证明。但不能直接依靠当前 `Basis.geometric()` 对字符串 `pi/log(...)` 的特殊判断，需要为新域明确声明变量与常数。通用化做到实际有两个以上调用者的部分即可，不引入运行时 DSL 或大型泛型框架。

## 5. 自动发现的设计

### 5.1 发现对象与候选顺序

内部原子表是表达和约化工具，用户关心的候选仍应优先是可解释的向量式：

1. `u·v=0`、`u×v=0`，作为垂直／平行的多项式视图，保留零向量边界。
2. 共用因子等式：`AB·AC=AB·AD`、`AB×AC=AB×AD`。
3. 中点／平行四边形产生的线性组合、共享顶点的三角形有向面积等式与小有理倍率。
4. 已有相似候选提供的明确顶点对应，独立核验正／逆语义及两条混合积等式。
5. 局部依赖域内的两积等式、少量三项和／小有理系数式；支持点可以重合，不统一禁止共享参数。
6. 用户指定局部对象集中的更一般 `AB·CD=EF·GH`、`AB×CD=EF×GH`。

不限于命名线段、直线或向量对象；由已有点对形成表达式即可。每个候选在规范化后先去恒等式，再做数值匹配，最后在原始位移式中复核。

共同因子化还可以复用现有退化与评分思想：`AB·AC−AB·AD=AB·DC`，与 `AB⊥CD` 对应；`AB×AC−AB×AD` 同理。默认保留信息量最高的几何表述，展开可看等价向量式。证明侧只对已接受／已证明的同义命题做转换，不以展示压缩结果替代逻辑来源。

### 5.2 不做全量 n⁴／n⁸ 搜索

原子量只有 O(n²)，不代表任意位移积的搜索只有 O(n²)。p=O(n²) 个点对形成 O(p²)=O(n⁴) 个积，朴素两积比较可到 O(n⁸)。不能先生成全部 `AB×CD` 再期望分桶挽救内存。

采用局部依赖域、共享端点／共享因子、已有三角形匹配、目标关联和稳定轮转候选。已约化的同一符号表达式只保留一份数值索引，见证单独收集。复杂模式按用户计算开关或局部范围启用；关闭列表展示不改变已接受条件。

需要独立统计：仿射表达式数、积候选数、索引比较数、原子列数、发现约束秩、证明规则实例、乘法证书大小、行系数位数。达到上限返回 partial 和原因。初始预算由 20/40/80 点散点、网格、同圆和题 A/B 实测后决定，不把现有 128 行或 200000 比较原样扩成新性能承诺。

### 5.3 数值政策

归一化后积按 scale² 变换。绝不对有符号积取 log，也不把两个很小值的商稳定性与等式成立混为一谈。

建议候选比较采用绝对误差下限加按各项输入向量范数乘积累计的误差界；参考形式为 `Σ|cᵢ|·||uᵢ||·||vᵢ||`，另加浮点展开／替换误差。它依赖输入量，不用接近零的结果作为唯一分母。精确阈值在首批测试中定标。几何病态判据、浮点相等判据与采样 Jacobian 步长分别管理。

原子展开可能产生大项相消，数值真值优先从原始位移式直接计算；比较原子与位移的数值差异，超出误差预算则标病态。内部原点可选局部已有点改善条件，换原点后的符号语义必须相同。

数值近重合只用于减少观测重复。进入证明仍使用真实点 ID；只在明确接受／证明 `coincident` 后做符号替换。零向量使积恒为零时，不据单快照将这一偶然退化推广为非退化构型的性质。

### 5.4 局部条件建议

在 `proposeConditions.ts` 的白名单、候选键、成本和复核流程接入新类型。`localConstraints.ts` 计算规范化多项式残差，优先用解析梯度，有限差分作为校验。多项条件的各行分别贡献 Jacobian；不能把一组双线性式算成一个自由度。

题 B 的 E 是重要案例：逆相似的点乘／叉乘二式对 E 通常给出秩 2 的线性刻画，可比三边比加坐标方向分支更直接。采样需要在独立副本中变化 ABCD，固定内部语义原点策略；不能每次按新的数值等值簇重新解释原命题。

沿用发现样本与留出样本分离；未定义构图、合法的零积、真正反例和病态残差分别计数。局部秩 2 和多个样本通过仍不是逻辑充分性证明。自动建议不采用被拒绝候选，但保留现有实验假设入口。

## 6. 证明系统：形成真正的双向闭包

### 6.1 先保留语义，再分派后端

新增混合问题编译层，保留原生仿射、双线性、带方向相似和非退化条件。AG2 文本仅是可降级子集的兼容输出，不能作为混合问题唯一载体。

- 普通既有题继续支持纯 AG2 导出。
- 有新条件时，混合 JSON 保存全部条件、规范表达式、名称映射、参考框架及证书。
- 导出纯 AG2 遇到不能无损表达的条件时明确说明，不能丢掉新条件后给出相同名称的“完整问题”。
- `check/proof/coverage/无目标后果生成` 统一通过混合协调器；其中可读报告的向量证明应改变正确的 checks，而不是被 `engine.check_pred` 的 false 覆盖。
- Worker 初始化加载新 Python 模块，取消／超时、解释器复用、旧响应隔离和快照失效语义保持一致。

可以将目前 `backends/ag2/` 逐步划分为 AG2 适配器和站点混合后端；先保留兼容 API，避免为目录命名进行大范围无关重构。

### 6.2 事实交换规则

| 已有事实 | 注入新域的后果 | 回写几何域的条件 |
| --- | --- | --- |
| 平行／共线 | 相应叉乘为零 | 两方向非零；三点共线的点重合边界单独处理 |
| 垂直 | 相应点乘为零 | 两方向非零 |
| 等长 | 两平方范数相等 | 距离非负可恢复等长；注入 AG2 前满足其非零要求 |
| 正有理长度比 p/q | `q²u·u−p²v·v=0` | p,q 正且分母非零，不能误当长度加法 |
| 中点／重合／已证明仿射关系 | 保留原生仿射行；收缩为点乘／叉乘后果 | 从纯积式恢复仿射向量需额外证明，不能任意逆用 |
| 逆相似 | 对应的两条混合积等式，详见数学文档 | 两式共同成立及非退化后恢复逆相似，并生成角／边比后果 |
| 有向面积关系 | 同一叉乘行 | 保留顺序及 1/2 因子；无向面积需额外分支 |

正相似、全等可提供对应边长比和同类积的倍率；没有有理尺度时，不把未知实比例伪造为有理线性系数。一般角等式也不直接导入线性积域：涉及 cos/sin、长度尺度或高次约束，只有明确规则支持时转换。

从 DDAR 接收事实必须有来源，或显式带 gap 标记；不能查询“数值成立的所有候选”作为新前提。当前依赖数值朝向的相似也必须保留 guard。新层回写的事实以证明来源加载到 DDAR，不能标成用户前提。

### 6.3 调度与终止

```text
显式接受条件 + 明示非退化／方向分支
    ↓ 语义编译
仿射基 → 点乘／叉乘原子行 → 精确线性基
    ↕ 已证事实队列               ↕ 有证书的有限高次规则
DDAR 适配器 ← 平行／垂直／等长／相似等可表达后果
    ↓ 新几何事实
重复，直到无新增独立约束／事实，或资源预算耗尽
```

初版可在外层反复调用上游完整 `deduction_closure()`，再同步新的规范事实、双线性独立行和回写事实，直到稳定。按规范键和证明版本去重；不要复制一份上游闭包循环到项目中。后续只有实测出现性能问题再细化为增量事件调度。

每轮“进展”必须是新独立行、新规范几何事实或更完整的证明来源，不能仅凭新增解释节点继续循环。点合并同步处理所有域的重命名和非零 guard 失效；不按旧列名继续运行。发现模型／UI 等值簇不参加严格闭包。

需要新增一个验收用例，明确出现 `DDAR → 向量消元 → DDAR 新规则 → 再次向量消元`，以排除实际仍是单向尾处理的实现。

### 6.4 非退化和证书

点乘、叉乘等式本身在零向量处依然有意义；逆定理、比值、平行／垂直的直线含义、乘法消去分别声明 guard。

区分三种非退化来源：用户明确假设、已证明非零、当前坐标见证。最后一种可以沿用现有条件性证明模式，但不能展示成无附加条件的定理。反例／矛盾模式禁止利用坐标偷偷补充非退化。

新积域的线性节点记录精确有理组合，可复用消元回放。有限高次规则记录结构化乘子、前提多项式、恒等差及消去因子。校验器将点乘／叉乘展开为**形式坐标多项式**检查恒等式；不读取数值坐标，不只是把原子积当作互相独立的符号。

问题 B 的证书最高涉及四次多项式。无需引入浏览器 SymPy 或通用 Gröbner 求解器：可先实现有理稀疏多项式的乘法、规范化和有限模板回放。SymPy 只用于本轮离线核对。

仍诚实保留现有边界：旧 DDAR 几何模板和数值分支并未全部独立审计，不能因为新增积域回放成功就把全系统的 `certificate:null` 改成“完整形式化认证”。

## 7. 两个目标题如何推动设计

### 问题 A

用户已确认 M 为 BC 中点。H 是黑盒垂心，D 的反射中间点不命名、不加入构图。只接受／采样得到 M 中点、两条垂心条件、D 在 AM 上及 `HD·AM=0`。

以 M 为内部原点，精确仿射替换 C=−B。两条高线条件和投影条件经有理线性组合得到 `MA·MD=MB·MB`；D 在 AM 上给出第二条叉乘条件。二式恰是 `BMD` 与 `AMB` 逆相似的混合积判据。这里新积域能作为真正的中间步骤，详见配套推导。

本轮在一般非退化实例上，原 DDAR 的两个相似边比均未推出。该结果只说明所记录输入上的当前能力，不宣称所有可接受条件集下均不可解。

### 问题 B

逆相似必须包含方向语义，不能只保留两条无向边比。

- DDAR／相似规则可先推出 `DA⊥DE`。
- 新积域结合逆相似混合点乘式与两个直角得到 `BD·(BC+BE−BD)=0`。
- 原生中点代换直接得到 `BG=DG` 和 `FG⊥BD`，可回写 DDAR。
- `AH⊥BD` 使用两条混合积式、直角和 H 的两条关联条件，通过明确四次恒等组合及非零消去得到。它揭示了单纯原子线性空间的边界。
- 最后由两条垂直和方向非退化得到 `AH∥FG`。

不能在第一层线性消元完成后就宣称整题可解。验收应分别报告前三项与最后一项的证明路径。

“任意 D”还需明确构图和目标的定义域：E、H 有定义，相关直线非零、H≠A、D≠B 等。即使 `(H−A)·(D−B)=0` 对 H=A 仍成立，也不能将零向量叫作一条与 FG 平行的直线。数学文档给出具体退化说明。

## 9. 测试与评估计划

1. **代数正确性**：任意端点反转、参数交换、对角原子、平行四边形／中点替换；逆相似二式均为正号；单独一式的反例；规范化不得借用无向线段排序。
2. **坐标不变性**：平移、旋转、镜像、统一正缩放 `1e−10/1/1e10`、内部原点更换。默认内在关系及证明结果等价；显式固定原点的关系只检查其声明的协变语义。
3. **退化**：向量为零、点接近重合、三角形扁平、D=A/B、E=B、H 不存在或 H=A、叉乘为零时禁止消去。合法零积与未定义直线区别报告。
4. **发现质量**：一般随机点的误报、网格／同圆密集等值簇、既有点重命名、预算截断公平性、有效支持评分、关闭新类型的旧行为；变换测试需要在无截断样本上比较完整集合。
5. **证明边界**：只给坐标不接受条件时不证明；缺少任一逆相似积式不调用逆定理；假设模式不借数值补条件；不从 gap 祖先输出“完整证明”；查询目标不能变成事实来源。
6. **中间步骤**：A 的积分解到逆相似；B 的 `DDAR 直角 → 点乘 → 等距／垂直 → 后续几何`；额外构造至少一例回写几何后再次产生新的积分解。对同一问题关闭回写时应出现明确能力差异。
7. **证书**：有理线性组合、仿射代换、双线性展开、四次乘子组合和非零消去各自可回放；修改符号、系数、前提 ID、乘子或删除 guard 应被拒绝。
8. **端到端**：全局发现与局部建议、接受条件、目标／无目标证明、check、coverage、Markdown／JSON 和纯 AG2 降级、Worker 重跑／取消／超时／快照更新。原生和浏览器都不创建辅助点。

每次实施后只运行适合该阶段的检查，再在最终合并前运行既有 TypeScript、原生 proof/reasoning/pedal 回归、TypeScript 类型检查和生产构建。本文不把历史测试统计当成本轮测试结果。

## 10. 明确的后续边界

- 线性提升可靠且不完备。Gram 秩约束、二维积恒等式不会由一个高斯消元器自动出现。
- 不将逆相似规则扩张成“所有角／长度关系都能线性转成向量积”。能转换的有限模式写清前提。
- 更多面积、圆幂、极线、投影与仿射条件可以沿公共表示接入，不为每种几何名称各写一套搜索和证明器。
- 任意高次自动搜索、LLL/PSLQ、通用多项式求解、完整射线顺序证明等后续单独评估，不挡住 A 和 B 所需的有限规则。
- 本轮完成的是可实施方案与可核对数学路径，没有修改或声称已经获得新的线上发现／证明能力。
