# 向量积扩展的数学语义、规则与无辅助点推导

日期：2026-10-22。配套 [联合设计计划](vector-products-plan.md)。本文是数学与算法分析，不表示这些规则已接入程序。

## 1. 固定符号与基本恒等式

平面采用固定正向：

```text
u·v = ux vx + uy vy
u×v = ux vy − uy vx
J(u) = (−uy, ux)
AB = B−A
```

因此 `u×Jv=u·v`，`u·Jv=−u×v`。叉乘是有符号的实数，不是绝对面积，也不是三维向量。

对任选原点 O 的位置向量 a、b、c、d：

```text
AB·CD = (b−a)·(d−c) = b·d − b·c − a·d + a·c
AB×CD = (b−a)×(d−c) = b×d − b×c − a×d + a×c
[ABC]₂ = AB×AC = a×b + b×c + c×a
AB×CD = [ABD]₂ − [ABC]₂
2 AB·CD = |B−C|² + |A−D|² − |B−D|² − |A−C|²
```

最后一个恒等式说明点乘域与平方距离的加法域可以共用核心；它不是普通长度加法，也不是 log 长度域。

这些表达式是多项式，因此没有 atan2 主值切口，也不需要为了定义点乘／叉乘而排除零向量。这种光滑性是代数表达式的性质，不表示数值上不会病态：大项相消、除以小量、近退化逆定理仍需单独处理。

## 2. 原点不是无条件可忽略的

位置原子 `a·b`、`a×b` 本身依赖所选原点。例如原点 O=(0,0) 时，A=(1,0)、B=(0,1)、C=(2,0)、D=(0,3) 满足 `a·b=c·d=0`；原点移到 (1,1) 后两值变为 0 与 −3。

位移式自动平移不变。若直接处理一般原子行，需要检查：

- 点乘行 `Σᵢ≤ⱼ cᵢⱼ pᵢ·pⱼ`：每个点的权 `2cᵢᵢ+Σⱼ≠ᵢ cᵢⱼ` 为零。
- 叉乘行 `Σᵢ<ⱼ cᵢⱼ pᵢ×pⱼ`：每个点的有向出入系数和为零。

这里要求的是不依赖任何额外几何条件的恒等平移不变性。有仿射前提时可以产生条件性不变性，但要记录来源。

将一个已有点选为内部原点，或对整幅图平移、旋转、统一缩放，只是证明中的坐标选择，不增加辅助点。若 O 是用户明确研究的 GGB 固定坐标原点，则必须保留该框架语义，不能随数值场景重新居中。

## 3. 几何事实与积等式的相互转换

### 3.1 平行、垂直与共用因子

```text
AB⊥CD ⇒ AB·CD=0 ⇒ AB·AC=AB·AD
AB∥CD ⇒ AB×CD=0 ⇒ AB×AC=AB×AD
```

逆向在相应两条方向非零时成立。若 C=D，右侧仍是合法恒等式，却不能据此声称 CD 是一条可与 AB 垂直／平行的直线。

同类式子应先做符号因子化、消项和有效支持约简，再评分和去重。平行与叉乘等式之间不需要补充辅助线对象。

### 3.2 中点、仿射关系

`M` 是 `BC` 中点时，保留精确向量关系 `2M−B−C=0`。于是对任意向量 u：

```text
2 u·AM = u·AB + u·AC
2 u×AM = u×AB + u×AC
```

不需要构造命名的 AM、AB、AC 向量对象。一般仿射关系 `ΣaᵢPᵢ=0, Σaᵢ=0` 可以用同一规则与任意形式向量收缩。

反向从所有收缩等式恢复向量为零需要充分条件，例如与一组已知独立方向的点乘均为零；不能只凭一个方向上的投影为零就恢复原生仿射关系。

### 3.3 等长、平方范数和有理比例

```text
|u|=|v| ⇔ u·u=v·v
q|u|=p|v| ⇔ q² u·u=p² v·v    (p,q>0)
```

平方不丢失长度的非负语义；但原生 AG2 对长度方向的非零要求仍要满足。不能把 `|u|²+|v|²=|w|²` 当成其长度加法消元器中的一条 `distseq`。

## 4. 逆相似的符号：两条等式都是正号

对应顺序固定为 `ABC∼DEF`，其中 A↔D、B↔E、C↔F。设

```text
u=AB, v=AC, p=DE, q=DF.
```

若相似反向，存在非零复数 k，使 `P=k·conj(U)`、`Q=k·conj(V)`。因此

```text
U·conj(Q) = V·conj(P)
```

取实部与虚部得到：

```text
AB·DF = AC·DE
AB×DF = AC×DE
```

两式都是正号。若反转某一有向线段，或调换第二个积的参数顺序，会出现负号，那是写法变化。程序应根据显式角色推导符号，不能把 ± 当作可任选分支。

例如 u=(1,0)、v=(0,1)、p=(1,0)、q=(0,−1) 为反射相似，两侧叉乘都是 −1。

### 4.1 逆定理需要两式联合成立

若两式共同成立，U≠0、P≠0，则令 `k=P/conj(U)`，可由上述复等式推出 `Q=k·conj(V)`。再要求 `u×v≠0`，便得到两个非退化三角形的逆相似。也可直接采用“两三角形非退化”作为较易展示的 guard。

**单独点乘式或单独叉乘式，通常都不足以推出逆相似，增加普通非零条件也不够。**

- 仅点乘成立：u=(1,0)、v=(0,1)、p=(2,0)、q=(0,3)。两侧点乘为零，但尺度不同，三角形不相似。
- 仅叉乘成立：u=(1,0)、v=(0,1)、p=(1,1)、q=(2,−1)。两侧叉乘为 −1，但两侧点乘分别为 2 和 1，也不相似。

每组都可分别作为三角形两边，且两三角形均非退化。候选目标应保留合取语义，不把其中一条标为“等价于逆相似”。

### 4.2 与现有相似事实的关系

两条无向边比给出的是 SSS 型相似约束，允许两种朝向。不能仅因为当前坐标是反向，就把逆相似混合积二式无来源地加入所有分支的证明。

可行来源是：明确接受有向相似命题、接受两条积等式、或从其他已证条件加显式方向 guard 推出有向相似。正相似也不应机械地套用“把两式各换一个正负号”的规则；其线性混合积表征需要另行确定参数结构。

## 5. 问题 A：纯线性积消元已经足够

条件：三角形 ABC 非退化，M 是 BC 中点（用户已确认），H 为黑盒垂心，D 是 H 到 AM 的正交投影，即题目给出的 `D=(H+Reflect(H,Line(A,M)))/2`。

反射点不命名，也不作为推理点引入。只用 A、B、C、M、H、D 六点。

### 5.1 适合发现／接受的原生条件

```text
2M=B+C
AH·BC=0
BH·AC=0
AM×AD=0
HD·AM=0
```

普通一般位置可以把两条高线和投影条件表示成 perpendicular。积式在 A=H、D=H 等高线方向退化处依然有定义，覆盖面更自然。黑盒命令文本不是证明规则；以上条件需要接受、采样刻画或可解释的构造语义来源。

### 5.2 有理线性证书

以 M 为内部原点，写 a=MA、b=MB、h=MH、d=MD，中点给出 c=−b。记

```text
P₁ = (a−h)·(−2b) = 0          // AH⊥BC
P₂ = (b−h)·(−b−a) = 0         // BH⊥AC
P₃ = (h−d)·a = 0              // 投影
```

直接展开得到

```text
a·d − b·b = P₂ − (1/2)P₁ − P₃ = 0.
```

证书只有三个前提与精确有理系数 `1,−1/2,−1`，适合复用当前带来源的消元器。D 在 AM 上另给出 `a×d=0`。

### 5.3 回写为逆相似

对三角形 BMD 与 AMB，使用对应 B↔A、M↔M、D↔B：

```text
u=BM=−b,  v=BD=d−b
p=AM=−a,  q=AB=b−a

u·q−v·p = a·d−b·b = 0
u×q−v×p = d×a = 0.
```

由联合逆定理得到 `BMD∼AMB`，且为逆相似。原三角形非退化意味着 `a×b≠0`；结合 `a·d=b·b>0` 和 `a×d=0`，D 不等于 M，BMD 也非退化。

这条路线展示了 `中点／垂直 → 积消元 → 有向相似 → 边比／角后果`，不能以“数值上发现 BMD 相似 AMB”替代最后的推导。

### 5.4 一个核对实例

```text
B=(−1,0), C=(1,0), M=(0,0)
A=(1/3,4/3), H=(1/3,2/3), D=(3/17,12/17).
```

此时 `a·d=b·b=1`，`a×d=0`。本轮原 DDAR 对两个独立边比均返回未推出；见实验文档。

## 6. 问题 B：线性层可得到等距与中点连线垂直

ABC 在 B 处为直角，逆相似对应为 ABC↔ADE；F 为 BD 中点，G 为 CE 中点，H 为 BE 与 CD 的交点。不引入任何辅助点。

以 B 为内部原点，设

```text
a=BA, c=BC, d=BD, e=BE, h=BH,
f=BF=d/2, g=BG=(c+e)/2.
```

直角给出 `f₀=a·c=0`。逆相似的混合点乘／叉乘式分别等价于

```text
R = a·e − a·d + c·d − a·c = 0
X = a×e + c×d + a×c − a×d = 0.
```

### 6.1 DDAR 与积域的第一次合作

相似保持直角，所以 `DA⊥DE`，即

```text
T = (a−d)·(e−d) = 0.
```

这可以来自已有相似／角推理，也可以由明确且可检查的有向相似规则提供。于是

```text
S = d·(c+e−d) = R − T + f₀ = 0.
```

这是纯有理线性积证书。代入 F、G 的原生仿射关系：

```text
|BG|² − |DG|² = g·g−(g−d)·(g−d) = 2g·d−d·d = S = 0
FG·BD = (g−f)·d = S/2 = 0.
```

故 `BG=DG`；当 BD、FG 均非零时，得到 `FG⊥BD`。两个结果都可回写 DDAR，参与后续几何推理。

### 6.2 为什么不能声称最后一条也来自同一次线性消元

H 的关联条件是两条叉乘式：

```text
C₁ = h×e = 0
C₂ = (h−c)×(d−c) = 0.
```

所求 `AH⊥BD` 对应 `Q=(h−a)·d=0`。在上面那组原子点乘线性行中没有涉及 H 的点乘项，而关联条件只在叉乘域。因此仅对这些已列行做线性组合，不能产生 Q 中的 `h·d`。

这不是原命题的反例，而是把原子积当独立形式变量后的不完备性。即使把 `BG=DG` 和 `FG⊥BD` 回写，本轮原 DDAR 的小实例仍未推出 AH 垂直。需要进一步的二维代数桥接规则。

## 7. 问题 B：最后一步的精确四次证书

记 `K=a×c`。对任意平面向量 a,c,d,e,h，下式是**无条件的多项式恒等式**：

```text
K · ((h−a)·d)
 = (a·a)(C₁−C₂)
   − R(h×a)
   − X(h·a)
   − f₀( h×(2a−d) + a×d ).
```

其中 f₀、R、X、C₁、C₂ 按上一节定义。所有乘子都是二次多项式，等式两边均为四次。

前提 `f₀=R=X=C₁=C₂=0` 给出 `KQ=0`。ABC 非退化给出 `K≠0`，故可消去 K，得到 `Q=0`，即 `AH·BD=0`。再加方向非零恢复 `AH⊥BD`，与前节 `FG⊥BD` 合并得到 `AH∥FG`。

该恒等式本轮已用 SymPy 在十个独立形式坐标变量上展开，余式严格为零。它可转成有限规则的可回放证书：

1. 记录五个多项式前提。
2. 记录上述精确乘子及线性组合。
3. 将点乘、叉乘展开到形式坐标，核对多项式恒等差为零。
4. 单独验证非零 guard `K≠0` 的来源。
5. 执行有依据的乘法消去，再转换为几何垂直与平行。

无需数值验证 Q，也不需要通用 Gröbner 搜索。但若在“独立原子积变量”上检查此式，会漏掉二维恒等式来源；校验必须使用形式坐标多项式或等价的已审计二维恒等式库。

### 7.1 恒等式的推导

令 `w=e−d+c`。利用二维基分解和基本点乘／叉乘恒等式：

```text
(a·a)w = R a + X Ja + f₀(2a−d) + K Jd.
```

两侧左乘 `h×`，并使用

```text
h×w = C₁−C₂−c×d
h×Ja = h·a
h×Jd = h·d
(a·a)(c×d) = f₀(a×d) − K(a·d)
```

整理便得到证书。J 是形式上的平面旋转算子，没有创建旋转点或向量对象。

### 7.2 一个更直观的坐标说明

作相似坐标选择 `B=(0,0), A=(1,0), C=(0,k)`，k≠0。设 D=(x,y)，题目复数表达式给出

```text
E=(x−ky, y+kx−k)
e=d−c+kJd.
```

由 H∈CD 得 `h×(d−c)=c×d=−kx`，由 H∈BE 得

```text
0=h×e=h×(d−c)+k(h·d)=k(h·d−x).
```

消去非零 k，得 `h·d=x=a·d`。这条解释与四次证书是同一数学结构；引擎可以采用后者避免在证明中任意选择坐标数值。

### 7.3 构图定义域与“任意 D”的限制

在上述坐标中令 `Δ=x²+y²−ky`。一般情况下

```text
H = ( x(x−ky)/Δ, x(kx−k+y)/Δ ).
```

需要 ABC 非退化；复数除法的 A−B 非零；BE、CD 是有效直线且有唯一有限交点（相关分母和方向非零）；BD 非零；若把结果读为直线平行／垂直，还需 H≠A。

特别地：

- D=A 会使 ADE 退化。
- D=B 会使 BD、FG 退化。
- E=B 或 D=C 时，定义 H 的某条直线失效。
- Δ=0 对应关联求交的退化分支，不能直接套用该有理公式。
- H=A 时，积命题 Q=0 仍正确，但 AH 不是有效方向。例如 k=1、D=(2,−1)、E=(3,0)，H=A，且 FG、BD 都非零。原题直线表述需要排除此情形。

引擎不应因为题面写“任意 D”而跳过这些检查；也不应把全部零积视为未定义。多项式关系与其几何直线表述有不同的定义域。

## 8. 从这两个题目提炼的算法需求

- A 需要可靠的仿射替换、点乘线性组合、叉乘共线和联合逆相似识别；不需要任意高次算法。
- B 的等距和 FG 垂直要求 `几何相似 → 直角 → 积消元 → 几何后果`，能检验双向接入是否真实生效。
- B 的 AH 垂直要求一个独立可检查的有限高次模板与非零消去，不能宣称线性提升自动完备。
- 可以先实现 A 和 B 的线性部分，再实现这条及其他有实际需求的有限证书模板。将模板表示为表达式和乘子数据，可减少为每个命名定理硬编码一套证明流程。
- 新模板的来源校验与旧 DDAR 几何规则的完整形式化校验仍是两件事，最终报告要逐步区分。
