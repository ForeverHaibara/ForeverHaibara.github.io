# 角关系的语义标准与实施记录

2026-10-19。由等角共轭黑盒在跨分支采样中出现反例的问题补充。

## 标准

1. 默认自动角条件为**直线有向角，模 π**：
   `∡(A,V,B) = dir(VB) - dir(VA) ∈ R/πZ`，逆时针为正。
   界面必须标出 `∡` 和 `(mod π)`，不能沿用无向角符号而改变含义。
2. 直线端点反转不影响方向类；交换角的两边使角变号。
   不能单独排序两边后丢弃负号。镜像使所有有向角变号，常数也须变号。
3. 保存整数系数与精确有理 π 常数。允许加减整周、合并相同直线及整式整体变号；
   禁止在模方程中擅自约掉倍数：`2α=0 (mod π)` 不能替换成 `α=0`。
4. 角是圆周值，只有局部实数提升连续光滑。采样用圆周残差，Jacobian 用局部
   提升后的增量，不对跨越 0/π 或 atan2 主值切口的数值直接相减。
5. 两条定义向量必须非零且数值分离良好。共线本身不是有向角未定义；
   点重合／未定义样本必须单独计数，不算反例，也不能凑够通过样本。
6. 无向角 `∠∈[0,π]` 是另一种精确语义。保留旧候选及人工接受入口，
   不从某一快照的无向角等式直接改写出普遍的有向角命题。自动建议独立发现
   有向角，避免把内外角、射线反向和补角变化当成对应有向关系的反例。
7. AG2 的 `angeq` 是模 π 的直线方向方程。无向角前提可以保留快照分支后
   导出其模 π 后果；新无向角目标需要额外的射线顺序、不等式或整周证明。
   在没有该证明器时拒绝给出“已推出无向角”的结果；仅允许报告明确接受过的
   同一无向条件。模 2π 的射线有向角留待独立后端能力支持，不能降级成模 π。

## 本批实施

- 数值发现增加独立的有向角等式、反向等式、倍角及差／和为 π/2 的候选搜索。
  使用圆周索引与资源预算；不依赖命令名称，不把等角共轭硬编码为构造语义。
- 发现结果、IR、局部残差、Jacobian、显示和 AG2 导出一致采用上述约定。
  保留旧 `ordinary-angle-equation`；新增显式 `directed-angle-equation`。
- 默认局部建议采用有向角；人工列表仍区分两种角。当前只列有限个已观测的
  原子等式，不用无向角的端点对称规则压缩有向关系。
- 基准覆盖等角共轭的内／外部 P、镜像与不同形状，以及 0/π 切口、
  真反例、未定义角、不可约掉的倍数、无向角目标的禁止升级和原生 DDAR。

## 验收边界与后续

等角共轭样例应保留三个顶点的模 π 等式；可以建议其中局部独立的条件。
建议不要求输出“等角共轭”这个命名标签，也不保证 DDAR 能由两条自动推出
第三条。没有通过有向关系的样本仍作为真实反例保留，不能因预期构造而豁免。

有限样本通过和局部秩 2 依然不是充分性／全局唯一性证明。继续推进全局
分支、退化与非零条件的符号记录，以及具备射线／不等式能力的独立证明检查。

## 验证记录

全仓库 36 个测试文件、359 项测试通过；TypeScript 检查与生产构建通过。
原生 DDAR 回归增加内点、外点镜像下自动条件的组合后果，均能推出；既有
真／假目标隔离与两个上游 IMO 样例仍通过。

浏览器通过实际 `Q=IsogonalConjugate(A,B,C,P)` 的编译长表达式作图，
取外部一般位置 `P=(-2.3,1.1)`，自动得到三个候选、两个局部独立建议，

顶点等式，界面显示未覆盖；该等式的 4+2 样本证据独立保留，允许人工额外承认。
