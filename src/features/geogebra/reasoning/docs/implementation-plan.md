# 条件性几何推理与 AlphaGeometry2 接入计划

2026-10-19。状态：实施中；实际交付与验证记录见 [README](../README.md)。

P2 的局部候选池、自动条件建议、独立 GGB 副本的六构型检查及 DDAR 覆盖评估
已完成首批，详见 [算法与边界](local-characterization.md)。全局充分性、补充
引理搜索和完整证明链仍按后续里程碑推进。

角语义已提升为 P2/P3 的必要验收项：自动条件采用直线有向角（模 π），
无向角保持独立语义；禁止把仅有模 π 推导升级为新的无向角结论。
标准、等角共轭回归及实施范围见 [角语义规范](angle-semantics.md)。

2026-10-20 调整：可读证明生成成为下一阶段主线；页面目标的是非检查优先级降低。
允许用户明确接受被数值筛选拒绝的命题作实验假设，保留反例和诊断，并与自动
建议分开。P4 的表示、追踪与验收见 [可读证明计划](readable-proofs.md)。

## 目标与已经确认的原则

目标是在现有静态 GeoGebra Studio 中，选择／承认一组已知性质作为条件，
推导目标或其他性质，再逐步研究性质筛选、推理规则和辅助点搜索。

1. 黑盒输出获得充分性质后即可视为一种刻画，不要求恢复原始定义。
2. 证明始终相对于明确列出的条件成立。数值发现、接受为前提、引擎推出、
   独立证书验证是不同状态；不能用一个可信度分数代替。
3. 任意复杂命令只需保留依赖、顺序、原始表达式和数值输出。`Element/Zip/If`
   组成的长表达式即便实际构造等角共轭点，也不要求自动识别其含义。
   这一例子说明黑盒边界，不强制作为专项基准。
4. XML 可以补充可靠依赖和多输出算法边界；从 XML 正向还原几何语义优先级低，
   不作为主线的前置条件。少量简单命令翻译也只是可选增强。
5. 不改动当前构图来做试验。重采样应使用隔离副本，保留原有合法自由度。

## 现有基础与边界

复用 `analysis/constructionSource.ts`、完整依赖图和数值发现。
现有 `nonTriviality` 仅为构造局部性启发；`derivedFrom` 仅为观测压缩来源，
二者都不是定义识别或证明。不可将显示筛选、分数阈值或截断结果当成完整候选库。
首批人工选择入口可以使用已保留的发现结果，但必须明确这是有预算的快照观察。

## 中间表示与职责

`reasoning/ir` 保存版本化对象、坐标见证、原始依赖和表达式、几何条件。
`sources` 将发现结果转换为候选；不解释黑盒函数，不自动接受性质。
`selection` 将用户接受的条件与目标分开冻结；以后加入局部性质集建议。
`backends/ag2` 负责能力、语义展开、名称映射、Worker 和原生对照接口。
`proof` 后续保存推导来源与检查器。

谓词需要区分普通角、方向角、长度加法与乘法。保留精确有理常数、非零条件、
方向／镜像／交点分支。普通角条件只能在显式坐标分支下翻译为方向关系；
这些分支也属于条件，必须在项目及界面列出，不承诺跨分支的普遍结论。

对象名称只在展示使用，导出统一映射为安全名称；项目文件保留双向映射及所有原对象。
不支持的对象／性质必须保留诊断，不得悄悄替换目标为更弱结论。

## AG2 目标语言与运行方式

固定上游提交 `251e7e16f0bba8ac7c83cdea789fccc195d0c0c7`。
仓库已经是无语言模型的 DDAR，外部依赖为 NumPy；点必须有坐标。
AG1 的构造 DSL 与 AG2 的低层谓词语言分别适配，不混用名称。

当前 AG2 支持 `coll`、`para`、`perp`、`cong`、`eqangle`、`s_angle`、
`aconst`、`angeq`、`eqratio`、`rconst`、`distmeq`、`distseq`、`cyclic`、
`cyclic_with_centers`、`overlap`；`acompute` 是查询。
中点、垂足和三角形关系由表示层展开。初始能力表应区分上游支持、本站导出支持、
可作前提、可作目标及能否提供证书。

静态运行优先 Pyodide + NumPy + module Worker，按需加载固定运行时。
使用版本化 JSON 消息及独立 Python 桥，保留原生 Python 对照基准。
取消直接终止 Worker；不要求依赖 SharedArrayBuffer／额外响应头。
限制点数、条件数、初始化时间和求解时间；部分或超时不能写成否证。
先测实际性能，再判断是否局部移植为 TypeScript；远程运行只作为可选研究后端。

上游消元明确不提供证明记录，且部分分支及退化判断依赖数值见证。
首批结果只表示引擎在这些条件和见证下推出／未推出目标，不能称为独立验算的证书。

## 黑盒性质筛选研究

1. 根据依赖顺序把候选归属到新对象／多输出步骤。先用直接输入、祖先，
   再扩展到已构造且共享局部背景的对象。禁止默认使用任意后续对象刻画前面的对象。
2. 在隔离 GGB 副本中改变合法自由输入，混合局部扰动和一般位置形变；发现与
   验证样本分开，保存种子、误差、退化／未定义样本和反例。刚体变换不算充分重采样。
3. 去除表达重复及已有条件的代数组合，再检查 DDAR 的推导覆盖。
   数值多样本通过不是证明；原始定义、熟知性质、人工接受、采样证据分别记录。
4. 联合评价条件成本、作用域、几何约束能力和当前后端的推理能力。
   Jacobian 及条件数只说明局部约束能力；代数行秩不等于几何自由度，
   不强制每点两式，不将局部孤立误写为全局唯一。
5. 加权贪心、有限替换和反向删除得到有预算的建议集，不宣称唯一／全局最小。
   廉价约简先行，少量候选集才调用完整 DDAR。保留未覆盖关系及筛选原因。
6. 核心刻画条件与补充承认性质分开。几何上冗余但当前后端无法推出的性质可以
   显式补充；不能为了证明某目标而自动补入相关观察。

先固定条件再选择目标；若目标已经直接包含在前提中，应标为“已接受为条件”。
等价表达也要检查，不能只比较关系 ID。条件选择后修改构图、目标或候选快照，
旧运行立即失效。未接受的观察不进入内核；观测压缩的来源不会被自动提升为前提。

## 里程碑与验收

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| P0 | 固定上游、能力表、原生／浏览器基准 | 同一输入结果一致，记录冷暖启动与资源成本 |
| P1 | IR、人工条件选择、AG2 文本与项目导出 | 实际 AG2 可解析；目标与条件隔离；无静默降级 |
| P2 | 黑盒重采样与局部性质集建议 | 偶然关系被拒绝，作用域／分支／不充分性可见 |
| P3 | 页面目标检查、取消、过期结果隔离 | 使用真实 DDAR，条件可回看，失败不等于否证 |
| P4 | 推导与消元来源、独立检查 | 可以追踪依赖和分支，明确证书信任边界 |
| P5 | 切线／圆幂／面积等扩展、辅助点搜索、增量优化 | 固定基准与消融实验报告收益、耗时及限制 |

先完成 P0/P1 与基本 P3，把可运行链路和条件模型做实，再推进 P2。
不把全部 GeoGebra 命令语义表或 XML 还原列为必做前置工作。

基准包含中点、垂足、交点、O/H/I/G 和未知三角形中心；一般位置与特殊位置、
镜像、共线／重合、匿名表达式、多输出、条件不足、独立目标、目标已在前提中。
高阶曲线、自由直线／圆没有点表示、三维、复数、随机／脚本对象先显式报告边界。
