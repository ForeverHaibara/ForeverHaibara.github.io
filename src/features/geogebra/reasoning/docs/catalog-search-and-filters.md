# 关系目录的结构化检索与筛选

2026-10-22。

## 交互标准

原来的 Compute／Show 共用一张类型表：Show 受 Compute 集合限制，All 视图
应用显示筛选，而 Accepted／Goal 绕过其中一部分；局部条件又没有全局关系的
类型和分数元数据。这使相同筛选在不同视图中含义不同，也容易把“隐藏”误解成
“不接受”。重新计算缩小候选池还会意外取消原已接受的输入。

现在分为三个独立状态：

1. **Discovery settings** 只控制下次发现的计算范围、预算及派生关系展开。
   Auto 开启时自动重算，关闭时等待 Discover relations。这里没有 Show 列。
2. **All／Accepted／Goal／Rejected** 决定查看哪个角色集合。每个视图分别记住
   本次会话的查询、类型、价值、是否包含无分数条件和对象过滤；初始均无筛选。
3. **Accept condition／Use as goal** 才改变证明输入。所有视图以相同规则执行
   列表过滤；筛选成零条也不取消任何条件。Reset filters 只重置当前视图。

目录类型过滤不受计算类型开关限制，局部条件从 IR 推断类型。最低价值只比较
有全局评分的条目；无分数条件是否保留由单独的 Include unscored conditions
控制。对象过滤取“包含任一选中对象”；没有选中对象时显示零条并提示选择对象。
状态行分别显示当前可见数、匹配总数和这个角色集合的总数。

已接受条件与目标在同一作图快照中独立保留。重新计算不再删除这些输入，原全局
类型、评分、见证和采样诊断也保留可查；新观察若提供同一语义，则继续合并并映射
旧 ID。谓词发生变化、作图快照更新仍使旧选择失效。计算设置等待执行时，同一
快照已有条目仍可以人工选择。旧存储中的 visibleKinds／minimumValue 不再隐式
控制目录；保留旧 schema 的读取兼容，新的视图过滤仅属于本次面板会话。

## 查询语法与边界

| 查询 | 含义 |
| --- | --- |
| `AO CO`、`OA=OC`、`(A, O)=(C, O)` | 查同时包含这两个线段量的条目，忽略端点顺序 |
| `A O C` | 只按对象过滤，不要求某个具体线段或角 |
| `ABC DEF`、`∡(A,B,C) = ∡(D,E,F)` | 查包含两个角量的条目，中间对象是顶点 |
| `CBA FED` | 与上一行检索相同的角量；这只是检索对称性 |
| `midpoint M`、`共圆 A B C`、`有向角 ABC DEF` | 类型词与几何量／对象组合 |
| `△ABC` | 查记录了这个三角形的条目，不限定三顶点书写顺序 |

名称忽略大小写，统一 Unicode 兼容字符、撇号、下标和下标花括号；例如
`A′`／`A'`、`O₁`／`O_1`／`O_{1}` 可以互查。已知对象名作为词典解析紧凑写法，
支持多字符名称。名字存在紧凑分词歧义时优先最长名字，用逗号或空格分隔名称可
明确查询对象。普通文字按词匹配标题、类型及诊断，不再要求整个查询成为连续子串。

**这是一种结构化检索，不是用户输入公式的证明器。** 等号等分隔符用于识别
查询量；系数、运算和角方向不据此做蕴含判定。一个模型同时含两个量，不等于
它断言这两个量相等。搜索两角时允许交换一个角的两边帮助查找，原始有向角条件、
模 π 因子、普通角分支和后端输入均不改变。必须阅读卡片／Details 的实际条件。

## 索引及扩展

- `selection/relationSearch.ts` 只读语义 IR 和结构化见证，不解析 formatRelation
  的展示字符串作为几何事实。索引包括线段、固定顶点的角、三角形、共线载体及
  受限射线别名；完整等值类、全部已记录的有限族实例、前置条件都参与检索。
- 方向／长度生成模型通过已展开的 IR 成员方程索引；先合并相同线段并消去零项，
  不将已经抵消的参考量当成有效方程量。方向模型支持用相交的两条成员线查询角量。
  不生成有限性质族的笛卡尔补全。
- `selection/relationCatalog.ts` 负责合并、角色／列表过滤和同快照输入保留。
  搜索文档在候选目录更新时构建；输入查询只解析一次，再匹配缓存文档。
- `CatalogFilterControls.tsx` 管理展示控件；`RelationTypeControls.tsx` 是单一用途的
  通用类型选择器，计算与目录过滤分别持有状态，不能互相修改。
- 增加关系目录类型后，分类控件和默认全集自动更新；新增 IR 谓词必须补全
  `predicateKinds` 的穷尽分支及对应量索引。新关系自动支持目录标签和 kind 检索，
  额外中英文同义词集中添加到 ALIASES；无需在组件中追加字符串解析分支。

## 验证

回归覆盖标点／空格、端点和等式两侧换序、角顶点错误、非首项等角、完整等值类、
有限性质族、生成模型抵消项、射线别名、多字符／带撇／下标名称、三角形及条件量。
目录测试覆盖局部类型过滤、无分数策略、无选中对象、各角色一致过滤、候选池缩小
保留输入及新快照失效；SSR 检查同一快照等待重算时仍可选择条目。

浏览器以两个中点条件验证：All 类型清空后接受数量不变，Accepted 独立显示两条；
在 Accepted 清空类型得到零条，Reset filters 恢复两条。计算范围缩到零后，两个
条件及原评分保留，真实 Pyodide DDAR 仍生成 20 步可读推导，4 步代数回放通过，
3 项坐标分支，0 个解释缺口。搜索 `BA AM` 与 `(B,A)=(M,A)` 得到同一中点条目；
`ANM ACB` 与 `∡(M,N,A)=∡(B,C,A)` 得到同样的两条相关条目。

全仓库 44 个测试文件、419 项测试通过，TypeScript 检查和生产构建通过；
构建仍有原有的第三方模块浏览器兼容及包体积提示。
