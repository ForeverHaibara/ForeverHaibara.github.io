# P4：可读推导与实验假设

2026-10-20。按实际使用反馈调整优先级：页面目标的 DDAR 是非检查只作辅助，
接下来以生成可读推导、保留推理来源和逐步检查为主。

## 使用原则

- 数值判定为错误、不充分或出现反例的命题仍可由用户明确选作假设；自动建议
  不采用它们。保留命题、诊断、反例、接受状态和实验模式，不能直接删除。
- 假设与当前坐标不相容时，不关闭 DDAR 的断言、不伪造坐标。实验模式走不依赖
  坐标真值的符号代数推导，明确给出能力范围和发现的矛盾；不使用爆炸律生成任意结论。
- 拒绝数值见证不等于否定用户想研究的特殊情形。结构无效、缺失对象、未定义方向
  等需要独立报告；即使暂时不能求解，项目导出也保留用户选择。

## 证明表示

推导保存为有向无环图：显式前提、几何规则、角／长度代数、数值分支条件、
未追踪步骤和矛盾。每个代数节点记录精确有理系数及所用节点；展示原始点名，
支持导出 Markdown 和完整 JSON。没有目标时也应从接受条件生成可读后果。

角方程使用模 π 语义，禁止将非整数线性组合当作无条件的模角推导。长度乘法
使用素数对数形式，长度加法独立记录。记录器不能用数值“看起来成立”补全缺失理由。

固定上游源码继续保持原样；在站点适配层增加带记录的 DDAR 子类和精确代数
来源层。先重建共线、线段加法、长度比转换、SSS／AA 相似和圆周角等常见规则。
未重建的 DDAR 推理必须出现明确缺口，不能包装成完整证明。规则覆盖、解释完整度、
代数回放和独立几何证明检查分别报告，`certificate` 仍不能冒充形式化证书。

## 本批验收与后续

先验证中位线的可读推导、有向角线性组合、长度关系与共圆后果；逐项追踪到
用户接受的条件。检查篡改系数会被回放器拒绝、模角不能约掉倍数、未证明结论
不会被当成来源、假设模式容许不匹配坐标、矛盾假设不会产生任意“已证明”。

后续扩充 SSA、无坐标分支的 SAS、点合并、弦弧交换等规则的完整来源，减少数值分支依赖，
并增加独立几何检查器、证明压缩与更自然的数学叙述。不将额外页面目标功能列为主线。

## 已实现的边界

`public/geometry-reasoning/proof_ddar.py` 的 `TracedDDAR` 调用未修改的上游 DDAR，
旁路记录可重建的几何事实；`proof_algebra.py` 用独立稀疏有理消元保存来源。
上游发现了事实而来源尚未重建时，产生明确 gap 节点。消元回放不读取点坐标，
但暂不独立验证几何定理模板；“无解释缺口”不表示已取得完整形式化证书。

普通模式可重建线方向、线段加法、长度比加法／乘法转换、SSS／AA／带朝向
条件的 SAS 相似、圆周角和逆定理。点序、朝向、普通角 lift 单列为坐标分支；
圆心、部分合并和弦弧传递仍可能出现缺口。默认最多记录 1600 节点，查询
32 个额外候选；长度转换检查至多 80 条非零线段，超出部分不承诺有解释。

假设模式使用已接受的角／长度方程以及共线、共圆的符号后果，进行精确消元
和正长度比转换；不会调用要求坐标真值的 DDAR 闭包，也不从原图补充点序或
朝向。它只发现部分代数矛盾，不承担完整的几何可实现性与一致性判定。

局部池每对象保留至多 16 条被前四构型拒绝的候选供实验，并明确报告截断；
它们占总候选预算，不参加自动条件选择。留出检查失败的候选同样允许显式
选择。缺少支持语义或对象的候选不会因开启假设模式而被当成有效谓词。

步骤、5 个回放通过的代数步骤、3 个坐标分支、0 个解释缺口。

原生检查：`python scripts/geogebra-proof-smoke.py`。当前 12 项回归覆盖中位线、
有向角、长度比、共圆、无目标生成、普通角分支、错误坐标假设、矛盾、模角倍数、
系数篡改与来源缺口。另有全仓库 363 项 TypeScript 测试，保留既有原生 AG2 回归。

浏览器实测：无目标生成后自动聚焦中位线平行的 22 步推导，5 步代数回放通过，
3 个分支条件，0 个解释缺口。修改构图后旧证明与选择立即失效。在等腰三角形
的特殊位置样例中，重心 X 的 `XA=XB` 被副本形变否定；开启假设模式后可
明确接受该候选并生成符号结果，原反例诊断保持可见。生成的这一条件被准确
标为“已给定”，没有冒充新证明。生产构建包含两个新增的 Python 公共资源。
