## 记号与条件

D、E、F 分别为 X 到 BC、CA、AB 的垂足。基础条件仅为每个垂足的共线与垂直，
另明确接受两条垂心垂直条件，或两条有向角平分条件。X 在测试坐标中分别取 H、I。
仅凭模 π 的角平分条件不承诺全局区分内心与旁心；推导中用到的朝向、点序和
非退化条件仍显示为分支条件。

按用户澄清，A′ 是 A 在外接圆上的对径点，程序样例以 U 表示 A′：O 为外心，
O 是 AU 中点；U、X、P 共线且 A、B、C、P 共圆。R＝AP∩BC，M 为 BC 中点。
内心样例另取 W＝AI 与外接圆的另一交点、S＝BI∩EF、T 为 A 到 BI 的垂足。
交点是已有测试输入；这批尚未实现自动添加辅助点。

辅助点的条件同样显式列入输入，不因命令或坐标自动成为前提。选择条件后才查询
独立目标，不能把目标的数值真值用作推导依据。

## 通用修补

- 角代数采用带来源的整数行格消元：例如 2α＝0、3α＝0 可以通过整数
  Bezout 组合推出 α＝0，单独的 2α＝0 则不能约掉 2。依赖行不能像普通
  有理消元那样直接丢弃。每步仍记录整数系数，回放器独立检查模 π 组合。
- 重建共线时尝试不同基点。例如已知 XA 与 XD 同方向，应先推出 A、X、D
  共线，再得到 AD 的方向，不能先要求尚未出现的 AD 方向已知。
- 等半径生成圆；三个等半径或等弦端距加圆周角关系识别圆心；记录圆的半径、
  半径与弦及圆周角关系。三个共同非共线点可以合并两个已知圆。
- 所有显式前提先进入解释层，再跟踪 DDAR 闭包，避免仅因输入处理先后产生
  假缺口。已能解释的相似后果不重复建立节点，节省 1600 节点预算。
- 来源映射使用 AG2 解析后的规范形式，`−180/2` 化简成 `−90` 后仍能回到
  用户选择的候选，直接给定目标也仍显示为已给定。
- 无目标生成在几何关系类型间轮询查询，不再由原发现排序中大量角方程占满
  32 个名额；跳过重复方程与已直接接受的方程。查询顺序不影响接受条件。
- 小整数长度乘法关系显示为乘积／平方等式；完整 JSON 保留精确对数方程，
  非整数幂仍显示原代数式，不作不可靠的格式化简。

上游固定源码保持原样。当前仍没有完整独立几何证书；几何规则实例和坐标
分支是明确的可信输入，`certificate` 仍为 null。SSA、点合并、一般弦弧交换、
圆幂／极线等规则的完整来源，证明压缩与辅助点搜索继续列为后续工作。
