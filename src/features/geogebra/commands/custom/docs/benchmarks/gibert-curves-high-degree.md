# 七次及更高曲线试验（2026-10-30）

Q001、Q100、Q105 录入为七次曲线。三条在边长 13/14/15、5/6/7、7/8/9 的三角形上通过来源特征点精确代入；生成器检查齐次性，命名管线维持 500,000 字符上限。Q100 使用图中有理方程清除分母所得的代数闭包，不把分母为零处解释为原有理表达式已定义。

初次试验的 Q100 展开配方在命名后约 642,050 字符，超过限制；将笛卡尔系数写为 Horner 形式并提取公因子后，三条均通过原有预算。测试组的一次编译样本约为：Q001 467,820 字符、102 个数值辅助量；Q100 约 464,000 字符、75 个数值辅助量；Q105 464,593 字符、79 个数值辅助量。数字反映编译表达式，不代表 GeoGebra 的实际运行时或内存消耗。

用户随后反馈这三条曲线实测有效；未记录具体构造耗时，也未确认是否覆盖移动点、共线/重合恢复及保存重开。独立浏览器控制的审批请求曾超时，因此没有自动化实机性能数据。

## 八次 Q109

单独读取 Q109 的 RTF；方程是八次齐次式，有 27 个重心单项式。X(4) 与三个垂足在三组精确三角形上代入为零。隔离生成得到 45 个笛卡尔项、60 个系数公共中间量；命名后的项表达式估计超过 100 万字符，编译器按现有预算拒绝。该次离线生成在同时运行其他检查时约 206 秒，不能作为独立基准。Q109 未加入支持列表；须进一步压缩并验证实际性能。

## 批量接入七次曲线

新增 Q008、Q009、Q025、Q030、Q079、Q082、Q096、Q148、Q194、Q196；均通过三组精确三角形的来源特征点检查及现有编译预算。Q079 使用页面列出的三条边的无穷远点作齐次代入，不作为有限点测试。对具有至少 24 个重心单项式的七次曲线调整 Horner 变量顺序，使 Q008、Q082、Q194 的配方通过预算；Q070 的两种顺序中较短者命名项的保守估算仍为 512,620 字符，超过 500,000 上限。

Q018 的命名项保守估算为 878,096 字符；Q020 与超限的 Q109 使用相同的八次单项式结构，暂缓。Q007、Q031、Q072、Q092、Q106 已检查方程和来源点，但各自的压缩试验超过 180 秒，暂缓，不据此断言其必然超出编译预算；这些试验期间有其他任务并发运行。Q015 尚无可直接使用的公式。上述时长和估算均为离线生成情况，不代表 GeoGebra 运行时性能。本批新增曲线尚无实机性能数据。
