# 七次及更高曲线试验（2026-10-30）

Q001、Q100、Q105 录入为实验性七次曲线。三条在边长 13/14/15、5/6/7、7/8/9 的三角形上通过来源特征点精确代入；生成器检查齐次性，命名管线维持 500,000 字符上限。Q100 使用图中有理方程清除分母所得的代数闭包，不把分母为零处解释为原有理表达式已定义。

初次试验的 Q100 展开配方在命名后约 642,050 字符，超过限制；将笛卡尔系数写为 Horner 形式并提取公因子后，三条均通过原有预算。测试组的一次编译样本约为：Q001 467,820 字符、102 个数值辅助量；Q100 约 464,000 字符、75 个数值辅助量；Q105 464,593 字符、79 个数值辅助量。数字反映编译表达式，不代表 GeoGebra 的实际运行时或内存消耗。

**实机验证尚未完成。** 独立浏览器控制的审批请求超时；需要验证真实 GeoGebra 的首次构造、移动点、共线/重合恢复及保存重开。不得据编译通过推断七次曲线交互流畅。

## 八次 Q109

单独读取 Q109 的 RTF；方程是八次齐次式，有 27 个重心单项式。X(4) 与三个垂足在三组精确三角形上代入为零。隔离生成得到 45 个笛卡尔项、60 个系数公共中间量；命名后的项表达式估计超过 100 万字符，编译器按现有预算拒绝。该次离线生成在同时运行其他检查时约 206 秒，不能作为独立基准。Q109 未加入支持列表；须进一步压缩并验证实际性能。
