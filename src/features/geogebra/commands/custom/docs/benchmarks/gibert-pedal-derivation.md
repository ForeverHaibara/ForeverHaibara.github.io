# Q018、Q020 的垂足构造推导

后续进展（2026-10-30）：两条已通过相似坐标与分阶段数值系数后端接入，见 [接入、实测与后续计划](gibert-pedal-integration.md)。下文保留推导阶段的结论和当时的限制。

本次仅作离线符号实验，没有接入曲线或修改生产生成器。来源：[Q018](http://bernard-gibert.fr/curves/q018.html)、[Q020](http://bernard-gibert.fr/curves/q020.html) 及各自链接的下载方程。

## 紧凑定义

对三角形 `ABC` 和有限点 `P`，令 `D=(Dₐ,Dᵦ,D꜀)` 为 P 在三边上的垂足三角形，`E=(Eₐ,Eᵦ,E꜀)` 为 P 的反垂足三角形：`Eₐ` 是过 B、C 且分别垂直于 PB、PC 的两条直线之交，余者循环。记三角形 T 的垂心为 `H(T)`，顶点向量和为 `S(T)`。九点圆心满足 `N(T)=(H(T)+S(T))/4`。

在构造有定义处，记二维叉积 `cross(X,Y)=XₓYᵧ−XᵧYₓ`，则两条来源定义可写成：

- Q018：`cross(H(D)−P, H(E)−P)=0`。
- Q020：`cross(H(D)+S(D)−4P, H(E)+S(E)−4P)=0`。

这里可共享垂足、反垂足、两个垂心和向量和，不需要预先写出完全展开的重心系数。第二式相当于两九点圆心与 P 共线，整体常数因子不影响零点。

## 一般三角形的符号核验

令 `A=(0,0), B=(1,0), C=(t,h)`，`h≠0`，`P=(x,y)`。这是任意非退化三角形经平移、旋转和相似缩放后的形式。脚本从投影、直线交点和垂线方程推导两个垂心，分别求上述叉积，并做有理式约分。下载式用同一三角形的边长平方和重心齐次坐标代入后，所得恒等式为：

| 曲线 | 化简后有限平面分子 | 分子 / 来源下载式 |
| --- | --- | --- |
| Q018 | 八次多项式 `F18` | `−1/(4h⁵)` |
| Q020 | 八次多项式 `F20` | `−1/(2h⁵)` |

这是符号恒等式，而非只对固定三角形抽样；由于 `h≠0`，比例因子不为零。另对三个具体三角形（包含一个等腰三角形）分别核对，均成立。原始等式中的分母除依赖三角形的非零因子外，含 P 所在的三条边直线和外接圆。它们反映构造中点或垂心可能不可定义：**不能将这些分母因子加入目标曲线，也不能在这些位置声称原始有理构造有效**。多项式方程包含的边上或圆上极限点，按来源下载式的代数闭包处理。

来源提到的无穷远直线不是本实验八次有限平面分子的额外因子。若从射影共线行列式直接清除分母，必须先逐项因式分解并明确剔除无穷远直线和其他构造产生的附加分支，再与八次下载式比较；不能在尚未检查的情况下将整个清分母结果送入 `ImplicitCurve`。此处的八次多项式取自有限平面的约分分子，其与下载式的全符号比较已经验证了目标分支，但不构成对其他射影推导中附加因子次数的结论。

## 对接入与性能的意义

一般三角形上，SymPy 对共享构造后的有理共线表达式统计约 1,191 个算术运算（Q018）和 1,527 个（Q020）；约分后完全展开的有限平面分子分别约 3,012 和 3,550 个运算。这说明定义式确实能以较少的符号运算表达，但这些是 **SymPy 表达式计数，不是 GeoGebra 编译体积、运行时间或内存测量**；它们还没有排除分支所需的多项式化成本。

现有 `ImplicitCurve` 管线需要关于世界坐标的多项式，且生成器会把重心式展开为世界系数。因此不能直接把以上含 P 的几何构造和除法绑定为普通数值中间量：它们依赖曲线的变量，且分母会引入未定义点。若先由 CAS 约分并展开成现有配方，得到的仍是原来的八次多项式，未证明能够通过现有预算。此前 Q018 的世界系数命名项估算约 878,096 字符，Q020 与 Q109 共用的单项式结构也超过现有预算。

下一步可针对这个具体的共享构造，探索**无除法的齐次多项式电路**，离线证明并约去全部附加因子；然后用真正的命名编译管线测量节点数与字符数，并在 GeoGebra 抽测普通三角形、边与外接圆附近、等腰及近退化情况。仅当它产生目标八次方程且实测稳定时再接入；目前没有证据表明这两条已能安全通过预算。

复现：`python scripts/geogebra/tools/experiment_pedal_loci.py CANDIDATES.json --generic`；去掉 `--generic` 可运行三个固定三角形。候选文件为先前审计脚本生成的本地 JSON，须包含 Q018 与 Q020。脚本仅读取数据。
