## 问题定位与方案选择

旧生成器先把重心单项式代入九个通用世界坐标框架量，再生成每个笛卡尔系数。Q018 的命名文本保守估算约 878,096 字符；仅在最终表达式上使用 Horner 并不能解决这个中间展开。Q020 的旧配方也超限。它们不是因为几何定义本身需要这么长的表达式。

已有[垂足推导](gibert-curves.md#q018q020-的垂足构造推导)证明了两条下载式与几何定义的约分分子相同。该证明本轮重新运行通过。生产实现采用与其等价的**相似标准三角形多项式**，而没有把含可动曲线变量的投影、交点和垂心当作普通数值辅助量。此处既不调用运行时 CAS，也不调用 Locus 或数值插值。

### 局部方程与非零因子

记 `A=(0,0), B=(1,0), C=(t,h)`，`h≠0`。在来源齐次重心式 `F` 中代入：

```text
a2=(t-1)^2+h^2, b2=t^2+h^2, c2=1
u=h*(1-X)+(t-1)*Y, v=h*X-t*Y, w=Y
```

Q018/Q020 均有且约去公共因子 `h^5`，剩余为八次多项式 `L(X,Y)`。生成器仅生成它的 45 个三角基系数及共享数值子表达式；系数按 `(0,0),(0,1),(1,0),…,(8,0)` 排列。共享节点最多保留 80 个，其余离线内联，给现有绑定节点预算留出阶段空间。这里的 80 是作者侧的结构选择，最终仍必须通过真实编译预算。

独立检查器完整重建多项式并验证 `h^5*L=F_substituted`，检查数值节点不含 `X,Y`，并在一般、等腰、反射和等边三角形上检查非零系数。没有约去依赖曲线变量的因子；边、外接圆和顶点处的代数闭包由原始多项式保留，几何有理构造的分母不进入运行时有效性条件。

### 世界坐标转换分为数值阶段

对实际输入令：

```text
dx=Bx-Ax, dy=By-Ay, s=dx^2+dy^2
ex=dx/s, ey=dy/s
t=ex*(Cx-Ax)+ey*(Cy-Ay)
h=ex*(Cy-Ay)-ey*(Cx-Ax)
X=ex*(x-Ax)+ey*(y-Ay)
Y=-ey*(x-Ax)+ex*(y-Ay)
```

依次绑定局部系数、`L(ex*x+ey*y,-ey*x+ex*y)` 的旋转缩放系数、再平移后的世界系数。转换使用静态二项式权重和前一阶段的数值依赖，避免把所有替换一次展开。最后才组成 `ImplicitCurve`。阶段中的所有辅助值均为原生动态数值对象；JavaScript 不读取输入点坐标。

最终乘以仅依赖三角形的 `s^(degree/2)`，本例为 `s^4`，恢复长度归一化造成的方程尺度。未恢复时原生 XML 已含非零系数，但显示方程会被四舍五入成 `0=0`，也不利于引擎的绝对容差。此尺度因子在非退化三角形中非零，不增加或删除曲线分支。它不能解决所有大坐标的消差问题。

有效性条件为三输入定义、非共线、`s!=0`、局部系数平方和非零。共线或重合时未定义，恢复一般位置后继续更新；等边三角形中的这两条仍为非零多项式，按既有约定保留。128 的上限统计绑定组节点，一个系数数组的绑定组会创建多个辅助对象；没有将辅助对象数误当节点数或绕开限制。

## 可替换的实现入口

`curves.json` 保留来源方程、次数和测试点，可通过 `backend` 选择 `similarityPolynomial`；其生成电路位于 `relatedCurveCircuits.json`。未指定此后端的曲线使用 `relatedCurves.json`。当前文件与支持范围以数据维护说明为准。

`builders/relatedCurveBackends.ts` 的注册表是实现选择入口。以后可以为某条曲线选择手写构造或变换后端，不必强行伪装成旧的生成配方。选择仍只根据编译期字面量编号发生一次，命令池只有一个 GibertCurve，不生成几百个 `If` 分支。未知后端失败，不静默回落。

新增后端需要在 TypeScript 注册表与离线生成器允许列表中同时登记，并提供与来源式的独立核验。所有实现仍使用既有 typed bind、命名白名单、原生类型检查与生命周期。不能用 JavaScript 坐标快照、隐藏 CAS 状态或新的私有辅助标签机制替代这些约定。新相似坐标生成器目前只接受边长平方齐次系数；含边长奇数次幂或其他定义需另行转换和验证。

## Q018、Q020 的垂足构造推导

来源与证明如下。来源：[Q018](http://bernard-gibert.fr/curves/q018.html)、[Q020](http://bernard-gibert.fr/curves/q020.html) 及各自链接的下载方程。

### 紧凑定义

对三角形 `ABC` 和有限点 `P`，令 `D=(Dₐ,Dᵦ,D꜀)` 为 P 在三边上的垂足三角形，`E=(Eₐ,Eᵦ,E꜀)` 为 P 的反垂足三角形：`Eₐ` 是过 B、C 且分别垂直于 PB、PC 的两条直线之交，余者循环。记三角形 T 的垂心为 `H(T)`，顶点向量和为 `S(T)`。九点圆心满足 `N(T)=(H(T)+S(T))/4`。

在构造有定义处，记二维叉积 `cross(X,Y)=XₓYᵧ−XᵧYₓ`，则两条来源定义可写成：

- Q018：`cross(H(D)−P, H(E)−P)=0`。
- Q020：`cross(H(D)+S(D)−4P, H(E)+S(E)−4P)=0`。

这里可共享垂足、反垂足、两个垂心和向量和，不需要预先写出完全展开的重心系数。第二式相当于两九点圆心与 P 共线，整体常数因子不影响零点。

### 一般三角形的符号核验

令 `A=(0,0), B=(1,0), C=(t,h)`，`h≠0`，`P=(x,y)`。这是任意非退化三角形经平移、旋转和相似缩放后的形式。脚本从投影、直线交点和垂线方程推导两个垂心，分别求上述叉积，并做有理式约分。下载式用同一三角形的边长平方和重心齐次坐标代入后，所得恒等式为：

| 曲线 | 化简后有限平面分子 | 分子 / 来源下载式 |
| --- | --- | --- |
| Q018 | 八次多项式 `F18` | `−1/(4h⁵)` |
| Q020 | 八次多项式 `F20` | `−1/(2h⁵)` |

这是符号恒等式，而非只对固定三角形抽样；由于 `h≠0`，比例因子不为零。另对三个具体三角形（包含一个等腰三角形）分别核对，均成立。原始等式中的分母除依赖三角形的非零因子外，含 P 所在的三条边直线和外接圆。它们反映构造中点或垂心可能不可定义：**不能将这些分母因子加入目标曲线，也不能在这些位置声称原始有理构造有效**。多项式方程包含的边上或圆上极限点，按来源下载式的代数闭包处理。

来源提到的无穷远直线不是本实验八次有限平面分子的额外因子。若从射影共线行列式直接清除分母，必须先逐项因式分解并明确剔除无穷远直线和其他构造产生的附加分支，再与八次下载式比较；不能在尚未检查的情况下将整个清分母结果送入 `ImplicitCurve`。此处的八次多项式取自有限平面的约分分子，其与下载式的全符号比较已经验证了目标分支，但不构成对其他射影推导中附加因子次数的结论。

## 生成算法的改进

上述相似坐标方案运行时已经分阶段，但离线生成仍把边长替换与重心框架替换一次性放进大表达式。Q106 的整体展开长时间未完成；仅把输出写成更短的 Horner 形式解决不了这部分作者侧成本。

新生成器先按重心单项式分组，然后在精确有理多项式环中：

1. 预计算 `(t²+h²)^j`、`((t−1)²+h²)^i`，先合并每个来源系数中的边长替换，消去这一步的重复项。
2. 预计算三个局部重心线性式的幂，在 `QQ[t,h][x,y]` 中复合。避免将尚未合并的巨大边长表达式反复与坐标幂分配相乘。
3. 通过多项式指数直接除去已确认的公共 `h` 次数，随后提取局部系数、因式分解和公共子表达式。无需对一个本来就是多项式的结果调用通用有理式约分。

这使七条都能完成生成；Q018/Q020 的既有生成数据也通过逐字一致性检查。运行时仍为同一分阶段系数后端，未改变旧 190 条世界系数配方或引入运行时 CAS。新生成器的 `--source` / `--output` 参数允许在独立候选文件上实验，不必先改正式支持列表。

## 独立恒等式与测试推广

次数不再假定为八次。令来源次数为 d、局部公共因子为 `h^k`，局部结果为 L；逆变换为：

```text
S=u+v+w
X=(v+t*w)/S, Y=h*w/S
L_hom = S^d * L(X,Y)
h^k * L_hom = h^d * F((t-1)^2+h^2,t^2+h^2,1;u,v,w)
```

检查器从电路重建 L，独立地沿逆变换恢复齐次重心式，比较完整多项式；没有复用生成器的正向复合过程。还检查数值节点不含曲线变量、系数数量、一般/等腰/反射/等边特化与非轴向世界坐标。三角形特化若使来源成为零多项式，应由系数守卫拒绝，而不是假定所有曲线在等边时都必须非零。

修正了原检查器世界尺度因子中只适用于八次的常数；转换单元测试现覆盖七至十次。原生夹具仍从来源方程用精确有理数计算，只在存储数值时舍入。顶点也记录其真正的来源值，不能对 Q070 这样的非 circum 曲线一律断言 A/B/C 在曲线上。

## 精度判据复审（2026-10-31）

上面的失败表保留原始观察，但仅凭它暂缓曲线偏保守：旧检查已经按普通参考点的方程幅值归一化，却对顶点额外收紧到 1e-8，而普通采样允许 1e-6；没有独立的几何误差依据支持这 100 倍差别。高次曲线的重复根也不适合直接用 `|F(P)|` 推断位置误差。看图正确是有用的辅助证据，最终仍应结合精确恒等式和动态测试。

专项页现统一使用混合容差。先对齐两个方程的非零整体倍数，记实际值为 a、来源参考值为 b，S 为四个独立非曲线参考位置的实际方程幅值：

```text
|a-b| <= 1e-6*S + 1e-6*|b|
```

近零点用相对方程尺度的绝对容差，避免除以应为零的 b；远离零点再使用相对值容差。S 不设为 `max(1,S)`，因此将整个方程乘非零常数不会改变正常数值范围内的判定。S 必须有限且大于零，所有求值必须有限；类型、非零多项式、动态依赖和精确符号核验的要求不变。该策略用于作者验证页，不修改运行时公式或几何退化条件。

顶点的旧 1e-8 检查保留为 `strictVertexDiagnosticPassed`，用于观察精度退步，不再单独阻止通过。上述五条的已记录平移残差均可通过新阈值，包括最差约 7.52e-7 的 Q031。这是对已有失败数值的重新判定，**不是五条全套原生专项的重新验收**：此前失败即停止，近等腰、近共线两组仍需按新判据补跑，之后才能决定正式接入。

本轮未据旧数据自动迁移正式/实验库。新增单元测试验证近零点、非零相对容差、方程倍数不变性、明显错误拒绝和非有限/零尺度拒绝。未来如需进一步改进，可记录世界单项式绝对值和以评估消差条件数；不能仅因其很大便无限放宽阈值。当前容差也不是点到曲线距离、拓扑或像素误差的保证。

## 结构化变换与插值的研究边界

反角共轭可用于独立验证来源式：对齐次式代入 `(a²vw,b²wu,c²uv)` 并约去该式实际具有的公共边因子。Q008 到 Q007 的完整系数恒等式已核验；约去边因子得到的是代数闭包，不能据此声称变换在三边上处处有定义。等价重心式不会自动缩短现有世界系数配方。

三角网格 Newton 差分插值曾以精确算术验证，但固定世界坐标采样会在平移后严重消差；例如 `(x−100)^8` 的双精度重建在根处出现巨大误差。该原型不是生产后端，也未取得 GeoGebra 性能验收。未来若尝试局部框架，需独立评估近退化、消差、分支和保存恢复。
