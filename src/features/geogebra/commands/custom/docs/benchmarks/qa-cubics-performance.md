# QA-Cu1 / QA-Cu1Inv 方程与性能（2026-10-28）

本轮只优化这两条曲线，不推进 cubic tools 的下一阶段。结论：保留现有
`QACu1`；将 `QACu1Inv` 改为七项重心三次式，并先绑定其七个数值系数。
在固定测试配置下，逆曲线的创建和拖动更新均约减少 **84%**。

## 垂足构造与方程

固定点 X 的垂足三角形为 D、E、F，分别落在 BC、CA、AB。对动点 P，
把 X 投影到 AP、BP、CP 得 U、V、W；条件是 DU、EV、FW 共点。
把六个垂足写成清分母齐次坐标后，三条直线的行列式对 P 为六次。
其中 P 的三个重心坐标各提供一个边线因子。必须约去这三个因子，
否则直接 `ImplicitCurve` 会把三条边线也画出来，而且次数不对。

以 `A=(0,0), B=(1,0), C=(c,d)`（`d≠0`）规范化，在 SymPy 中
逐一核对了余下三次式的十个仿射系数：它们与现有
`QA-Cu1(A,B,C,P)` 把第四点改为变量、曲线点固定为 X 的方程全部成比例。
比例只依赖 ABC 的面积尺度，不依赖 X 或动点 P。因此该垂足刻画有效。
从它直接计算三个投影和三线共点在 GeoGebra 中反而引入分母和额外依赖；
约简之后使用七项重心式更合适。

令 `s=(a²,b²,c²)` 为 ABC 三边长平方，`f=(p,q,r)` 为固定 X 的重心；
动点重心为 `(u,v,w)`。逆曲线恒过 A、B、C，所以纯立方项为零，
只需六个 `u²v,uv²` 的循环项以及 `uvw`，共七个系数。例如

```text
[u²v] = -a²(a²-b²-c²)qr² + b²(b²-a²)pr² - c⁴pq²
[uv²] = -a²(a²-b²)qr² + b²(b²-a²-c²)pr² + c⁴p²q
```

其余四个边项按 ABC 循环；`uvw` 项是六个循环差项之和。
这七个系数在 GeoGebra 中一次性作为数值列表计算，随后生成三次式，
并以七系数平方和在最终输出处拒绝零多项式。单元测试比较了旧方程与
新七项式，并核对固定 X 为两个等力点 X(15)、X(16) 时，曲线均与
Neuberg cubic K001 成比例；另用原生 GeoGebra 的 X(15) 与
`OrthopivotalCubic(A,B,C,X(3))` 再核对一次。

## 固定视口原生比较

输入 `A=(0,0), B=(6,0), C=(1,4), D=(2,1), P=(2,3)`；每个样本重建点和
单条曲线。先分别预热，再按「旧→候选→候选→旧」测两次创建和每次四次
坐标更新。创建计时是原生命令返回；更新计时包括 `setCoords` 和随后
`getValueString` 触发的方程读取，**不包括完整绘图帧或手动鼠标延迟**。
单机少量样本仅用于本次选择，不是跨设备性能承诺。

| 工具与方案 | 展开字符 | 创建中位数 | 更新中位数 |
|---|---:|---:|---:|
| `QACu1` 原绑定式 | 2,244 | 241 ms | 140 ms |
| `QACu1` 完全代入、无 Zip | 9,415 | 3,622 ms | 2,318 ms |
| `QACu1Inv` 旧式（十系数守卫） | 6,307 | 1,854 ms | 1,182 ms |
| `QACu1Inv` 七系数绑定式 | 4,743 | 309 ms | 185 ms |

第二次逆曲线对照用保留的旧式生成器重跑，因临时变量名更长，
绝对耗时也更高：旧式创建／更新为 3,806／2,416 ms，新式为
649／379 ms；改善比例仍约 84%。无 Zip 的七项式试跑造成原生浏览器
长时间阻塞，未取得完整计时，不据此声称它具体慢多少。

结论不能简化为“Zip 越少越快”：`QACu1` 的绑定复用在本配置下比
完全展开快约 16 倍；`QACu1Inv` 的主要成本在原来为最终非零守卫
重复构造十系数多项式映射。新式虽然仍有匿名绑定，但只计算七个
简单数值系数。

复现入口：`/scripts/geogebra/browser/verification.html?page=smoke&suite=qa-performance&tool=qa`，
以及 `?suite=qa-performance&tool=inverse&variant=bound`。原生回归入口：
`?suite=isocubics&tool=qa-interior`、`qa-neuberg` 和 `degenerate`。
