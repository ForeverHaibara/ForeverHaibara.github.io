## 数学和维护约定

根据用户反馈，假定网站不会修改已编号曲线的数学定义。数据库由人工定期维护，不做全自动更新，不记录抓取快照、哈希、ETag、HTTP 头、审阅流水或版本差异；代码与数据变化由 Git 管理。必要字段限于 ID、名称、次数、来源、公式、测试点和个别数学说明。

退化语义沿用 [三次曲线规则](cubic-tools-roadmap.md)：保留非零的降次或可约特化，拒绝恒零式、重合或共线参考三角形，离开退化后恢复。命名数值中间量沿用 [现有实现](named-intermediates-implementation.md)，包括隐藏、辅助标记、回滚、撤销、导出依赖和孤儿清理。

## 数据与生成

数据位置：

| 文件 | 用途 |
| --- | --- |
| [catalogue.json](../data/related-curves/catalogue.json) | 完整目录位置清单与已知族成员；不随运行时代码打包。 |
| [curves.json](../data/related-curves/curves.json) | 已接入的数学记录，人工维护的单一真值。 |
| [数据说明](../data/related-curves/README.md) | 字段、符号、维护步骤和暂缓条目。 |
| generated/relatedCurves.json | 从数学记录生成的数值系数配方，不手工编辑。 |
| scripts/geogebra/tools/generate_related_curves.py | 手动运行的离线生成器，依赖 Python 与 SymPy。 |

公式使用 u/v/w 重心变量，a=BC、b=CA、c=AB，a2=BC²、b2=CA²、c2=AB²，sa=(b2+c2-a2)/2，循环定义 sb/sc；涉及奇数次边长幂时由边长平方开方得到非负边长。仅支持算术、非负整数幂、cyclic() 和 cyclicProduct()；生成器用受限 Python AST 解析，不对数据字符串执行 eval/sympify。

生成器核对齐次性和标称次数；有另一来源表达式时检查其与主公式仅差非零的边长系数倍。Q002、Q003、Q012 使用页面的第二式；Q039 另用已下载 TXT 的展开式核对。随后离线代入有向二倍面积的线性式，得到笛卡尔各单项式的数值系数配方。网站不做符号展开，不读取点坐标快照，不在线抓取来源。

维护流程：

1. 人工核对页面／TXT／论文，将定义和特征点写入 curves.json。
2. 运行 `python scripts/geogebra/tools/generate_related_curves.py`。
3. 运行 `python scripts/geogebra/tools/generate_related_curves.py --check`、相关单元测试和独立原生验收。
4. Git 一并提交数据、生成产物和必要说明。没有定时任务、自动更新数据库或额外变更日志。

## 公开接口与编译约束

```text
g=GibertCurve(A,B,C,12)
g=GibertCurve(A,B,C,"Q012")
```

- 一个命令名，无 Q012 等公开命令和别名。返回一个原生 implicitCurve。
- 支持的数字编号以数据文件为准；Q036A/B/C 使用字符串，例如 `"Q036A"`，也接受 `"Q036-A"`。字符串大小写不敏感。未实现的族成员明确报错。
- 第四参数是 catalogId 编译期字面量参数：允许正十进制整数、带括号的字面量和引号内 ID；拒绝滑块、数字对象、算术式、12.0、科学记数法和前导零整数。不读取 getValue(id) 冻结选择。
- 对 ID 做一次外层注册表查找，仅生成选中条目的式子；没有目录规模的 GeoGebra If 或列表选择。
- 文件工具／callable 优先，原生 TriangleCurve 完全保留。静态字面量信息经过带类型的不透明 token 传递，使 compose 内部不依赖调用方标签。
- 新增 catalogId 仅为参数角色，不增加伪几何输出类型。补全与拼写检查由 library.json 自动接入。

### 性能档位与安全边界

已接入曲线要求 **Medium 或 High**（页面默认 High）。两档均只物化数值中间量，不需要几何辅助对象。

Low 的完整匿名展开在独立 Q012 实验中超时，因此正式接口在执行前拒绝 Low。新增 requiresNamed 声明：若绑定不能安全物化，也报错，不回落到已知会卡顿的匿名式；既有工具的回落规则保持原样。

当前命名管线不支持对已有输出标签安全物化重定义。因此请使用新标签，或删除旧结果后重建；不能静默用匿名式处理 `g=GibertCurve(...)` 的同名重定义。支持可安全降低的原生包装，如 LeftSide(GibertCurve(...))；含 Zip/Sequence 等局部作用域、多个自定义工具混合而无法安全降低时给出说明。

### 数学与文件行为

输出由原生数值系数和 ImplicitCurve 构成，A/B/C 移动时动态更新，导出后无需站点代码。系数全零、点未定义、参考三角形共线或重合时曲线 undefined；普通可约／降次特化保留。没有采样拟合点、CAS 求解、更新回调或安装宏。

特征点分三类：可用有限点、无穷远点、当前引擎／配置不可用点。例如 [X(30) 是 Euler 无穷远点](https://faculty.evansville.edu/ck6/encyclopedia/part1.html)，不能要求它是有限原生点；X(370) 在本次基准三角形中原生未定义，按条件点记录；X(5456) 超出本次原生 TriangleCenter 支持范围。没有通过删掉断言来隐瞒曲线失败：Q033 另核对了六个页面给出的中点和反中三角形顶点。

## 验收范围与限制

单元测试包括字面量／compose 来源、文件工具优先、命名执行边界、禁止重定义前的无变更失败，以及多个一般、镜像和相似变换三角形下的独立重心公式与生成笛卡尔方程比较。

独立原生页面验证首批及后续抽样曲线的类型、有限特征点、动态更新、共线／重合退化与恢复、正三角形特化、导出重开及辅助清理；另检查撤销／重做和字符串选择器。详细抽样范围见下文。

首批创建仍有约一至数秒的成本，Q039 尤其明显；不能用快速更新掩盖创建开销。独立页面没有同时覆盖主页面自动保存、分析刷新、长时间连续拖动、多曲线共存和移动设备，后续继续按实际使用补测。原生三次专用操作不会因为输出都是 implicitCurve 就自动支持这些高次曲线。


## 来源审核与抽样结果

来源可能是网页公式、TXT、RTF 或图片；数据入库前核对次数、齐次性及可独立构造的来源点。缺少可靠公式或独立核验的编号保留暂缓，不能从示意图推断方程。Q036 的三个成员分别建项；Q084 目录标题未给出次数，目录仍保留 null。清除有理式分母时需区分原式的未定义位置与代数闭包。


批量接入时，离线检查覆盖方程次数、齐次性、命名执行预算，以及来源中可独立构造的特征点；部分条目另有符号恒等式或坐标方程比较。特征点复现脚本为 `scripts/geogebra/tools/check_related_curve_points.py`。各编号的来源和当前状态以 [数据维护说明](../data/related-curves/README.md) 为准。

GeoGebra 5.4.920.0 在 Windows Chrome 上抽测了 Q005、Q014、Q036A、Q202、Q021、Q023、Q029、Q032、Q034、Q064、Q074、Q075、Q099、Q114、Q120、Q121、Q155、Q171、Q200 和 Q201。抽样检查了曲线类型、适用的来源特征点、输入更新、退化恢复、导出重开与辅助对象清理。Q005 和 Q202 在正三角形样本中退化为零式，按 undefined 处理。**抽样不代表所有目录条目均已实机验证**；多曲线共存和移动设备也未覆盖。

这些实验中，复杂曲线的创建耗时可达数秒，且受设备、视口及构图影响；一次性计时不能视作性能保证。有关分阶段系数、平移精度限制及复现方法，见 [相似坐标扩展](benchmarks/gibert-curves.md) 和 [垂足曲线方案](benchmarks/gibert-curves.md)。
