## 本轮核验结论（2026-11-02）

- **12025、32584**：采用用户原始几何核验，均记 `SKIP source-error`，不猜同次式、不将编号悄悄别名到 11 或 115。12025 原贴三圆共轴归结到 Feuerbach 点的结论来自用户核验；32584 的极线/中心矩阵关系已另加独立可执行检查。官方 6–9–13 距离表匹配旧非齐次式，说明它使用了该式，不能证明该式是正确的三角形中心。
- **PB 11753–11788**：全部 36 点已按独立顶点矩阵审计，旧的 32 个已选位置均正确；只为四个缺失透视中心增加 seeds。星号组必须同时在 U 的根式中改变 S 符号：保持 U+ 的形式替换不能保持前言的直径圆性质。将 S/U 看成独立符号时的对调，不能直接用于实际数值根式。
- **14079、14821**：保留已核对的坐标/代数乘积，恢复覆盖；隔离有矛盾的入射声明。没有用附件提供的补点候选覆盖 14083/14084 的已选奇异焦点坐标，主定义的裁决仍待独立核对。
- **14087/14088/14090**：全族审计发现中间选择会由 `A(14084)`、其共轭及含 14083 的交点引入与 BSS/打印坐标不一致的位置。已用互相一致的 BSS、等截/等角共轭坐标固定这三点，60545 的坐标与线表随之重新一致；没有为 60545 再增加特殊 seed。14083/14084 的奇异焦点主定义仍未改动。
- **64802**：六次坐标的循环和严格为零；改记裸 I，保留覆盖且不假装有限点。可进一步复核源线 `{13,44498}` 等方向，但当前小库不为这个未审阅方向增加额外依赖。
- **13137（新发现）**：真实 Simson 线上的反射、打印坐标和四条原生入射线一致；条目标出的 Simson 线 X(115)X(523) 不是真实踏点线。采用两条已核实原生线的交点，不采用该错误线名。

## 单独列出的排版问题与正常边界

- 39301/39303 的部分自身关系写成 30301/30303；39203 有 `SSqrt`。46183、53806、62503 的线表自身编号分别误写 46193、537、6249。

- 39160/39161/39164/39165、39641/39642 是已审阅的非实焦点，51539/51540 另经直接射影实性检验确认为一般位置非实；它们不是等待修正为实坐标的错误。5000–5003、11065/11066 有条件复数域，不能统一永久跳过。
- 一个分支在等腰、等边或中心逆像位置无定义，也不自动说明一般三角形的定义错误。源符号缺解释、自然语言局部量尚未展开，属于未实现/待审阅，不等同于已证实错误。


## 下一轮算法/语法工作与需要几何帮助的边界

- 单个首坐标无 `: :` 的条目不一定是数学错误。当前 AST 比较将加法视为可交换，但没有充分规范化连续减项；一些实际 b/c 对称的长多项式仍无法确认对称性。这是值得改善的规范化问题，不能把所有这种条目直接当成源错误。
- 31664/31665 的 `T²=SA·SB·SC·SW`、72698–72701 的 T/T1/T2 定义链、23032–23034 只写 x 却使用 y/z，需要核对根号分支或明确循环声明；暂不增加无界的自然语言推断。
- 15276 的 `fd12`、38439 的多余右括号、36721/36731 的参数前缀与错误自身编号，是下一批可单独审阅的排版候选；还未仅靠平衡括号或删 token 来接受它们。
- 13580/13581 的 J、47752/47753 的 OH 没有本条明确局部定义。此次只支持显式 `where J=|OH|/R`，不全局猜测未绑定符号。若扩大标准几何量语法，需连同 65627/65628 的实复域一起处理，避免再次把无实样本误算为有限锚点。
