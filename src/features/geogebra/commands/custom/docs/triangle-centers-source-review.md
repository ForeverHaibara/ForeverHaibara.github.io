## 下一轮算法/语法工作与需要几何帮助的边界

- 单个首坐标无 `: :` 的条目不一定是数学错误。当前 AST 比较将加法视为可交换，但没有充分规范化连续减项；一些实际 b/c 对称的长多项式仍无法确认对称性。这是值得改善的规范化问题，不能把所有这种条目直接当成源错误。
- 31664/31665 的 `T²=SA·SB·SC·SW`、72698–72701 的 T/T1/T2 定义链、23032–23034 只写 x 却使用 y/z，需要核对根号分支或明确循环声明；暂不增加无界的自然语言推断。
- 15276 的 `fd12`、38439 的多余右括号、36721/36731 的参数前缀与错误自身编号，是下一批可单独审阅的排版候选；还未仅靠平衡括号或删 token 来接受它们。
- 13580/13581 的 J、47752/47753 的 OH 没有本条明确局部定义。此次只支持显式 `where J=|OH|/R`，不全局猜测未绑定符号。65627/65628 已按用户复核标记一般位置非实；不能因为缺少 OH 解析而重新将其当作待恢复的实坐标锚点。

### 8037：撤销源错误怀疑，处理特殊样本的不定式

令 `X=a², Y=b², Z=c², T=S`，`q=(X+T,Y+T,Z+T)`，`t=(Y+Z−X+T,Z+X−Y+T,X+Y−Z+T)`。X(1131) 的坐标为 `1/t_i`，X(3068) 为 `q_i`。将其代入 Ceva 共轭并清分母后，首坐标是 `q_0(-t_0 q_0+t_1 q_1+t_2 q_2)`。恒等式

`-t_0 q_0+t_1 q_1+t_2 q_2 = t_1 t_2`

使其化为 ETC 的首坐标 `(a²+S)(a²+b²−c²+S)(a²−b²+c²+S)`，其它坐标循环。这不需要数值拟合或额外三角恒等式。
