本清单基于工作区缓存的 ETC 快照（审阅日期 2026-11-02）。官网链接用于定位，网站后续可能已修订。“实现未覆盖”本身不证明 ETC 错误；特别是 `coordinate_admission_or_variants` 和 `geometry_or_transaction` 不能直接当作源错误标签。

- 一个分支在等腰、等边或中心逆像位置无定义，也不自动说明一般三角形的定义错误。源符号缺解释、自然语言局部量尚未展开，属于未实现/待审阅，不等同于已证实错误。
