语法改进：

- 无括号函数共用规范化入口，保留 `sin A`、`sin 2A/3`、`cos B cot B/2` 的原有意义。自然对数也可使用带明确边界的单符号实参；`log bc`、`log b/c`、`log b^2` 仍要求括号。
- 对正边长，`ln(b)-ln(c)=ln(b/c)` 消去共同缩放项，随后按原规则检查齐次性。替换作用于整个减法 AST 节点，不能用子串替换，否则 `2*ln(b)-ln(c)` 和 `-ln(b)-ln(c)` 会被误写。单个带量纲的对数继续拒绝。
- `abs(...)` 保留实参的缩放次数，支持大小写和方括号。只把明确的边长差竖线 `|b-c|` 转为调用；其它含糊竖线不猜。`min(b,c)`/`max(b,c)` 用和差与绝对值恒等式表示，不增加多参数函数解释器。X(13872) 使用 `Abs[...]`，X(14080) 使用边长差竖线；X(15222)–X(15225) 是边长极值簇。

### VU 1st PCC 的统一关系

对前言的 V(P) 展开式，令 P=(p:q:r)，O=X(3)，d=OP，R 为 ABC 外接圆半径。其首坐标可重写为

`2*a²*b²*c²*p*(p+q+r) - a²*(b²+c²-a²)*(a²*q*r+b²*r*p+c²*p*q)`。

利用 O 的重心坐标和 P 对外接圆的幂，可得

`V(P) = O + 2*R²/(d²+R²)*(P-O)`。

这也等于“先对 P 作外接圆反演，取 P 与其反演点的中点，再反演该中点”的结果（这些中间构造均有定义时）。实现使用前一个有限有理式，复用

`F p:2*R^2 3:d^2-R^2`。

为此仅在恰有两个有限输入的 F 系数中定义 d 为两输入距离，量纲为长度。B 和三点以上 F 不接受 d，且不会把它注册成全局坐标符号。运行时绑定两个输入点与距离各一次，避免较长依赖在系数和分子中重复展开。不新增操作字母、虚构中间 ETC 编号或逐成员种子。

### 短轴分支的后续证据
