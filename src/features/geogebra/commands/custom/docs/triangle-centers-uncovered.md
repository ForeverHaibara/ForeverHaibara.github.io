## 已落实的改进

- 坐标 `: :` 后、下一 HTML 行的明确 `where p=..., q=...` 与单个 `D=...` 可以合并。最多两项独立标量定义，先检查其表达式，再整体替换并作循环置换。
- 接受花括号作算术分组；带逗号的集合仍不是合法坐标算术。未知函数、局部变量链以及重定义 a/S/R 等全局符号均拒绝。
- 有局部定义时，允许重复的末尾 `: :` 作为格式冗余；不改变公式自身的循环意义。
- 142 个无候选条目中恢复 56 个可解析公式，完整筛查和闭包后净增 63 个编号，另外 7 个通过依赖解锁。新未覆盖集合是旧集合的严格子集，没有失去旧覆盖。
- 新增 `--uncovered-report`，只在显式请求时写失败条目报告，不恢复 selected.tsv。理想坐标审计被单独计时并有心跳。
- 提取缓存指纹从整个导入器改为解析入口/本地辅助调用图、全局语法数据及坐标/来源代码；修改求解和诊断逻辑不再让所有页面重解析。

具体改进与证据：

- 新增 `O p q r` 三有限中心圆心构造，Python 用平移后的二元线性方程求圆心，运行时用 `Center(Circle(...))`。理想输入、重复点与共线退化均不作为可用有限圆心。X(11619) 以审阅种子恢复；独立垂直平分线构造与目标线均吻合，保留印刷式冲突回归。
- 自然 `log(...)` 规范化为 `ln(...)`，仅接受单参数，继续要求参数无量纲；数值域错误保留 undefined。X(40300) 的锚点由幂曲线 P(t)=(a^t:b^t:c^t) 的切线系数独立核对，不能只用依赖簇内部关系互相证明。
- 坐标标签后的可选等号不再妨碍公式解析，恢复 X(38343/39222)。不放宽公式语法与齐次性检查。
- X(11755) 的坏括号/反斜杠属于孤立源错误，加入交点种子；其值与展开前言 U 后、补齐括号的坐标在两个样本吻合。相关源错误测试集中在 `test_source_errors.py`。
- 修复页外 J/I 种子闭包直接索引本次页面线表的假设。种子仍按依赖、输入类型和几何检查接入；没有页面线表时使用已有的空证据语义，附专门回归。

全量预计 71 块、2,207,695 原始字节，B 3,708、I 1,177、O 4；深度 6，最大估计展开 101,556。完整运行约 339 秒，包含页面提取与坐标审计，不把该值当作单独算法加速结论。日志为 `.cache/triangle-centers/circle-log-all.jsonl`；未覆盖与差分为 `uncovered-circle-log.json`、`circle-log-diff.json`。
