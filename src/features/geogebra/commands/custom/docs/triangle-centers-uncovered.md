## 已落实的改进

- 坐标 `: :` 后、下一 HTML 行的明确 `where p=..., q=...` 与单个 `D=...` 可以合并。最多两项独立标量定义，先检查其表达式，再整体替换并作循环置换。
- 接受花括号作算术分组；带逗号的集合仍不是合法坐标算术。未知函数、局部变量链以及重定义 a/S/R 等全局符号均拒绝。
- 有局部定义时，允许重复的末尾 `: :` 作为格式冗余；不改变公式自身的循环意义。
- 142 个无候选条目中恢复 56 个可解析公式，完整筛查和闭包后净增 63 个编号，另外 7 个通过依赖解锁。新未覆盖集合是旧集合的严格子集，没有失去旧覆盖。
- 新增 `--uncovered-report`，只在显式请求时写失败条目报告，不恢复 selected.tsv。理想坐标审计被单独计时并有心跳。
- 提取缓存指纹从整个导入器改为解析入口/本地辅助调用图、全局语法数据及坐标/来源代码；修改求解和诊断逻辑不再让所有页面重解析。
