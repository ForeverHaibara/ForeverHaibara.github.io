## 3. 接口与连续性

- 三角形、四点形、六边形用独立的点表达。两组三角形按 `A↔D、B↔E、C↔F` 对应。密克点和拟透视圆锥曲线允许三对顶点同时换序与镜像。Pascal 的六点及选定的两对边有给定次序。
- `point` 表示有限实仿射点，`lineLike` 取无限支撑线，`conic` 接受圆，`circle` 只接实圆。中间点、直线、二次型保留齐次系数；最终输出才有限化。直线型或点型 conic 优先保留原生 conic 元数据。
- 多结果分成同类型独立对象。顶层产生固定槽数，赋值和嵌套沿用现有首槽行为，末尾 `i` 选择 1-based 槽。保留空槽，切触合根如何显示须逐项核定。多根的集合连续性和逐槽编号连续性分别验收。
- 特殊性质写入数学语义，例如共点、共圆锥、曲线上取点。在一般输入上沿用同一几何构造或方程。共点、共线推广用确切构造，禁止加权拟合和最小二乘。构造没有唯一结果或结果在输出类型的表示范围之外时，允许 undefined。可去的中间分母优先约掉；引擎若把恒零方程误建成已定义对象，只在输出边界加必要守卫。
- JavaScript 只负责类型分派和生成表达式。数值、条件及依赖由 GeoGebra 动态计算。短式优先 `expression`，复用站内工具用 `compose`，其余 builder 复用 [齐次运算](../algebra/homogeneous.ts)、[稀疏多项式](../algebra/polynomial.ts) 及 `bind`。长式可评估现有 [Medium／High 隐藏辅助对象机制](named-intermediates-implementation.md)。避免自由构造点、采样拟合、坐标快照、脚本回调或自建持久化变换对象。

## 4. 第一批算法

### 三线密克点

以 A、B、C 为三条线的锚点，记三线为 `l₁,l₂,l₃`，令 `X=l₂∩l₃、Y=l₃∩l₁、Z=l₁∩l₂`。圆 `XBC、YCA、ZAB` 的共同点就是以 XYZ 为参考三角形的密克点。[密克定理及证明](https://isa-afp.org/browser_info/current/AFP/Miquel/Miquel.html)

- **Perspector** 用 `AD、BE、CF`，方向 `d₁=D−A、d₂=E−B、d₃=F−C`。第一组三点为圆的锚点，因此在一般位置交换整组输入可得到另一个密克点；三对顶点同时换序仍给同一结果。
- **OrthologyCenter** 用过 A、B、C 分别垂直于 EF、FD、DE 的线。取 `J(x,y)=(−y,x)`，方向为 `J(F−E)、J(D−F)、J(E−D)`。交换两组三角形求反向中心，输入同一非退化三角形还原其垂心。[ETC 的 orthologic triangles 定义](https://faculty.evansville.edu/ck6/encyclopedia/ext_glossary.html#orthologic-triangles)

直接消掉 X、Y、Z。用局部复坐标表示锚点 `aᵢ` 与非零方向 `dᵢ`，令 `rᵢ(p)=(p−aᵢ)conj(dᵢ)`。例如 `XBC` 的方程可写成 `Im(r₂(p)conj(r₃(p)))=0`，由圆周角条件得到。若两方向平行，该式连续给出支撑线 BC（B、C 不同）。三式同时成立，等价于三个 `rᵢ(p)` 落在过复原点的一条实直线上，也就是原来三条线各绕自己的锚点旋转同一个角后在 p 共点。

1. 循环取 `δᵢ=det(dⱼ,dₖ)`，则 `Σδᵢdᵢ=0`。计算 `T=Σδᵢ aᵢ conj(dᵢ)`。
2. 设共同旋转为单位复数 U。旋转后三线的共点条件恰为 `Im(conj(U)T)=0`。只要 T 非零，取 `U=T/|T|`；U 换号不改变线。实现可用两个实分量乘法，免去求角和取角度分支。
3. 旋转后的线用方向 `Udᵢ` 通过各自锚点，精确求任意一对独立线的交点。一般内核选 `|δᵢ|` 最大的一对并在 GeoGebra 内动态选择，交点由叉积一次有限化。换对时解相同。正交版三方向之和为零，非退化 DEF 的三个子式相同，可直接固定一对，并在 T 中省去共同子式。局部平移可取锚点质心；各方向的任意非零缩放只给 T 乘共同因子。

原来三线有唯一有限共点且 T 非零时，T 为实数，旋转角为 0 模 π，直接还原经典中心。原来某两线平行、某线过其他锚点，或中间三角形因三线共点而塌缩时，仍用同一公式。三方向张成二维但 T 为零时，每个共同旋转角都满足共点条件。若锚点不全重合，按不同的角度趋近可得到不同交点。例如经典透视中心在 ABC 的外接圆上且各方向均有定义时，三圆重成这个外接圆。此时经典透视中心仍可能唯一，但密克点推广在此处没有唯一的连续极限，输出 undefined。若锚点全重合且三个非零方向仍为秩二，唯一有限极限是共同锚点。三方向同向或某条方向缺失时，检查该输入是否仍给唯一极限，常规退化保持 undefined。验收用一般位置三圆、两线平行、三线共点、上述共圆退化，以及同时换序和镜像。

### 拟透视圆锥曲线

对变量齐次点 `X=(x:y:w)`，过 D 的候选线由 D 与方向点 `(x−Aₓw:y−Aᵧw:0)` 叉积得到，E、F 循环。三线系数行列式为三次式，在 `w=0` 时三方向相同，故含因子 w。直接生成商式。取仿射 `x⃗=(x,y)`，商式可写为

> `det(x⃗−B,x⃗−C) det(x⃗−A,D) + det(x⃗−C,x⃗−A) det(x⃗−B,E) + det(x⃗−A,x⃗−B) det(x⃗−C,F) = 0`。

每个第一因子本来就是一次式。更短的生成方式是复用 ABC 的有向面积重心 `(u:v:wᵦ)`，输出

> `det(C−B,E−F) v wᵦ + det(A−C,F−D) wᵦ u + det(B−A,D−E) u v = 0`。

将上式用仿射一次式 u、v、wᵦ 展开成六系数 `Conic`。全式由有向行列式和坐标差组成，无须除以三角形面积，也无需逐点计算共点条件。参考 ABC 非共线；A、B、C 是轨迹闭包的基点。三系数均零时条件对整平面成立，例如 DEF 与 ABC 仅差位似或平移，输出 undefined；只有部分系数为零可保留线对。对经典透视中心，三线正好为 AD、BE、CF；对正交中心，三线是 DEF 的高线，交于 DEF 的垂心。这两项是独立验收条件。一般位置的密克点推广不必落在这条 conic 上。

### 二次型束与两圆的另一交点

- **ConicPencil** 用同一组原生六系数计算各自的 `qⱼ(P)`，再输出系数向量 `q₂(P)·q₁ − q₁(P)·q₂`。输入各自换非零尺度或交换次序只改变总因子。P 是共同基点时整个束都经过 P；两个方程成比例时输入没有给出一维曲线束。这两种情形都使输出系数为零。用 [Coefficients](https://geogebra.github.io/docs/manual/en/commands/Coefficients/) 和六系数 `Conic`，沿用 [现有的系数顺序](../algebra/homogeneous.ts)。用经过四点的两条线对构造有独立答案的测试，也验收圆束、线对和点型成员。
- **SecondIntersection(c1,c2,P)** 取两圆心连线，原生表达式为 `Reflect(P,Line(Center(c1),Center(c2)))`。反射保持每个圆；P 为共同点时给出另一点，相切时返回 P。一般位置的 P 也照样反射，圆相离也可使用。同心时轴没有唯一方向。保持两个 `circle` 参数的独立重载，核对现有 `SecondIntersection(conic,point,point/lineLike)` 的分派。

### 圆束极限点

`CirclePencilLimitingPoints` 求圆束中半径为零的实成员的中心。令 `d=O₂−O₁`、`D=d·d`、`k=D+r₁²−r₂²`。成员 `(1−t)c₁+t c₂` 用二次项系数为 1 的圆方程，圆心 `O₁+t d`，半径平方为 `D t²−k t+r₁²`。以 `O₁` 为原点，判别式可写为

> `Δ=(D−(r₁+r₂)²)(D−(r₁−r₂)²)`。

两个槽按 `(k−√Δ)/(2D)`、`(k+√Δ)/(2D)` 对应，换圆次序交换槽。稳定求根取 `m=(|k|+√Δ)/2`、`σ=sgn(k)`，两根以（分子，分母）保留：

> 大绝对值根 `L=(σm,D)`，小绝对值根 `S=(σr₁²,m)`。

正半径圆在有实根且 `D>0` 时 k 非零。槽位可用 `(1+σ)/2` 在分子、分母层将 `S,L` 排回 `−,+` 的顺序，最后对选中的 `(N,W)` 计算 `O₁+(N d)/W`。距离和半径先用共用尺度归一化再计算系数。同心异半径时有限槽返回共同圆心，另一槽没有有限极限；重合圆两槽未定。相切两槽合到切点，横截时没有实槽。用半径平方为零、圆束成员方程以及从相离拖到相切、横截、内含和同心的序列核验。特别测近同心大小两根、近内切以及大量级平移；判别式容差只在实机证实有必要后确定，近切的不同对象仍要区分。

## 5. 第二批算法与拐点试验

### 对应点与无穷远方向

在 `Collineation`、`Involution` 和 `InvolutionCenter` 的标定参数中，`point` 转成 `(x:y:1)`，`lineLike` 若支撑线为 `ax+by+c=0`，转成 `(b:−a:0)`。线的位置、端点顺序和长度不参与标定。复用 `supportingLine` 取得系数，在这些 builder 内专门做方向转换。其他命令的 `pointOrLine` 参数仍按其原有语义解释。全程保留齐次坐标，待输出时才有限化。最后的动点 P 及返回值采用实仿射点；像在无穷远时为 undefined。

### Collineation 与 Affine

对每个四点标架取 `M₀=[P₁ P₂ P₃]`，`u=adj(M₀)P₄`，`M=M₀ diag(u)`。这样三个坐标基点及 `(1:1:1)` 对应四点。源和目标分别在自身局部坐标中构造标架；在目标局部坐标中以 `H=M_target adj(M_source)` 作用于源局部点，最后有限化并还原。无须逐项除以行列式。

每个四点标架无三点共线，因此每组最多两个方向参数。可用前三点行列式和 u 的三分量确认标架可逆。允许有限点和方向点互相对应。验收四对点、两组同时换序、逆向往返、同方向的不同支撑线，以及 P 穿过映到无穷远的直线。点像可和原生 `ApplyMatrix` 对照；后续若有线／conic 像需求，分别复用 `adj(H)ᵀl` 和 `adj(H)ᵀ Q adj(H)`。

`Affine` 用三个有限源点的有向面积权重 `(u:v:w)`，返回 `(uD+vE+wF)/(u+v+w)`。非共线 ABC 确定唯一仿射映射；DEF 共线时同一公式仍给唯一的降秩仿射映射。用仿射分点、平行四边形、镜像、错切和降秩作对照。

三对标定的 `Affine` 只收有限点。一个仿射映射有六个参数；一对有限点提供两条约束，一对方向只提供一条约束。即使两对有限点加一对方向全都相容，仍一般剩一个自由度，例如固定 `(0,0)、(1,0)` 及竖直方向允许任意非零的竖向伸缩。仿射自同构还要求有限点对有限点、方向对方向。若将来需要方向输入，另设计带足够对应约束或带长度的向量签名。

### 射影对合与中心

解释为 `A↔C、B↔D`，四点在射影一般位置。非恒等实平面射影对合有一个固定中心 O 和一条逐点固定的轴 ℓ。用完全四点形的三个对角点直接得到

> `O=AC∩BD`，`K=AB∩CD`，`L=AD∩BC`，`ℓ=K∨L`。

`InvolutionCenter` 将 O 有限化。`Involution` 直接计算 `Q=(ℓ·O)P−2(ℓ·P)O`。在轴上矩阵作用为乘 `ℓ·O`，在 O 的代表向量上乘 `−ℓ·O`，因此平方在射影意义下为恒等；轴、中心和两个交换点对可分别验算。轴可以是无穷远线，中心也可以是无穷远点，中途无需创建原生点或线。例如 O 在无穷远的仿射镜像仍可用 `Involution` 计算有限点像。恒等映射没有指定的对合中心；点对重合或四点失去一般位置时，标定可能不足或不相容。用 `ℓ·O≠0` 确认该构造给出有效的中心和轴，验收混合方向点、齐次代表缩放、两次作用返回原点及像跨越无穷远。[调和同调及其对角点构造](https://www.voutsadakis.com/TEACH/LECTURES/PROJECTIVE/Chapter5_6.pdf)

### PascalLine 与 PerspectiveAxis

共用定义 `U=(A×B)×(D×E)`、`V=(B×C)×(E×F)`、`ℓ=U×V`。有一个交点在无穷远时，ℓ 仍可是一条正常的有限直线。两交点都在无穷远且不同时，结果是无穷远线。有重合边使某个交点无唯一值，或 U 与 V 重合时，所选两点也无法确定有限直线。只在最后以原生线系数生成器输出。

共圆锥时经典 Pascal 第三点 `CD∩FA` 也在 ℓ 上。ABC 与 DEF 透视时 Desargues 第三点为 `CA∩FD`，同样在 ℓ 上。在一般配置中只用 U、V，所以 `PerspectiveAxis` 在 `PascalLine` 的 `aliases` 声明，两者共用签名。离开定理配置后，改变取用的两对边可以改变结果。验收一个交点在无穷远、两个交点在无穷远，以及经典两种配置及各自的第三点。[Pascal 构造](https://sites.math.washington.edu/~king/coursedir/m445w01/lab/lab09.html)

### 三次曲线的密切圆及直线极限

`OsculatingConic(P,F)` 对一般 P 使用通过 P 的等值线 `F(X)=F(P)`。复用 `withCubic` 取得十系数，按三次输入契约计算梯度 g 与 2×2 Hessian H。令 `s=g·g`、`K=(Jg)ᵀH(Jg)`、`δ=X−P`，输出原生六系数 conic

> `K ||δ||² + 2s g·δ = 0`。

`K≠0` 且 g 非零时，结果确实是圆，圆心 `P−s g/K`，半径 `s^(3/2)/|K|`。`K=0` 且 g 非零时，原式给等值线的切线，可连续跨过普通拐点。为涵盖这个直线型输出，选名 `OsculatingConic`，参数次序与原生 `OsculatingCircle(P,Object)` 对齐。g 为零时整式为零。用 `F=y−x³` 测过拐点时的圆↔直线型 conic，用 `F=y²−x²−x³` 测结点，另测 F 乘非零常数和 P 离开 F 后的等值线语义。[OsculatingCircle 手册](https://geogebra.github.io/docs/manual/en/commands/OsculatingCircle/)

### 三次曲线拐点

`CubicFlexes` 对应旧路线图待试的 `CubicInflexionPoints`。第一版以光滑实射影三次曲线为契约，求 `F₃=det Hess(F₃)=0` 的三个实射影交点，输出可表示的有限点。无穷远点保留空槽。重根、奇点与公共分量留待扩展奇异三次的契约。[三次曲线的实拐点算法](https://i.cs.hku.hk/~gfxgroup/publications/pdf/Computing%20real%20inflection%20points%20of%20cubic%20algebraic%20curves.pdf)

按旧试验，原生隐式曲线 `Intersect(F,H)` 被拒绝，顶层 CAS `Solutions` 虽可解，嵌入点输出失败。先作为对照保留 Hessian 联立。实现试验优先考察 Chen–Wang 的实拐点线算法，以 Hilbert 特征式确定包含三实拐点的直线，再按齐次一元三次求交。现有 `cubicRestriction` 与三次曲线／直线求交的原生路径可复用。比较能否用现有数值绑定表达系数，并在有限化前分配槽位。用 `x³+y³=1` 的两个有限拐点与一个无穷远拐点作基线，再以射影变换把三点全部带到有限位置。逐点验收曲线上、光滑且切线三重相交，另测穿越无穷远与编号恢复。[既有实机记录](cubic-tools-roadmap.md)

## 7. 实现阶段的验收

1. **定义与兼容**。确认英文定义、参数顺序和别名。检查原生命令的实际重载、文件工具优先级及类型推断。涉及 conic 退化时查原生 XML 的类与后续命令分派。
2. **代数与几何对照**。各工具至少有一个独立的经典配置和一个一般位置对照。覆盖镜像、适用的换序、尺度改变、大坐标平移。对限制条件构造，用拖动穿入和穿出该条件的序列检查连续性。区分可去分母、唯一但病态的结果与真正非唯一的结果。
3. **真实引擎**。在 [浏览器验收入口](../../../../../../scripts/README.md) 中逐签名创建、拖动、导出重开；验收顶层独立槽、编号、空槽恢复、嵌套首槽及文件宏覆盖。记录对象计数及辅助对象的隐藏、清理与保存恢复。
4. **性能**。按现有匿名／命名执行路径分别测创建与更新；高成本构造复用已验证的数值绑定。只有确认匿名模式无法实际使用时才考虑 `requiresNamed`，并在入口明确限制。以交互数据决定是否保留展开、复合或矩阵后端。相关先例见 [三次曲线性能](benchmarks/qa-cubics-performance.md) 与 [辅助对象性能](benchmarks/named-intermediates-performance.md)。
