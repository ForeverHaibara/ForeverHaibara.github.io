# 几何关系发现与作图依赖分析

本目录从 GeoGebra 当前作图读取对象与点坐标，建立依赖图，数值发现共线、平行、垂直、共圆、点重合、等长、普通等角、相似／全等、中点、小常数长度比、二倍角及可选的余角／补角，并用方向与长度生成模型压缩重复关系。排序使用作图依赖局部性，展开的生成子观测另作冗余折扣。

**这是辅助探索，不是严格证明。** `nonTriviality` 估计参与对象在当前作图方式下有多熟知、平凡；既不是定理难度，也不是关系成立的概率。未来的微扰检查可以增强数值可信度，独立的自动证明系统不能仅依赖本模块。

条件选择、AG2 导出与无语言模型推理已独立放入 [reasoning](../reasoning/README.md)。
该入口要求明确接受性质作为条件，不会将本模块的观测或压缩来源自动提升为前提。
前端现使用同一个关系目录完成发现浏览、接受条件与选择目标；浮点精度修补和
操作方式见 [精度与统一目录](docs/precision-and-unified-catalog.md)。
后续修订将计算范围、列表过滤与条件角色分开，并支持按几何量检索；见
[结构化检索与筛选](../reasoning/docs/catalog-search-and-filters.md)。

评分采用统一的依赖图模型，不要求识别上百种工具或解释展开后的公式。详见 [设计、实验与局限](./docs/value-scoring-design.md)。

## 当前发现算法

### 1. 读取与建图

`getAllObjectNames` 后，读取每个对象的 `getCommandString`、`getObjectType`；对支持的二维点读取有限的 `getXcoord`、`getYcoord`。建图保留非点对象，数值检测只使用有有限坐标的点。

图为已有名称建立顶点。例如 `M=f(g(A),h(B))` 的父节点为 A、B，匿名子表达式不增加图顶点。不需要知道 f、g、h 的含义；它与 `M=(A+B)/2` 的局部依赖一致。解析不完整时尽量从 token 保留已知对象引用。

无依赖、空定义或读取失败的对象经 `fallback` 边连接哨兵根；评分不会使用这个根来连接自由对象，并将不完整依赖单独处理。

更新防抖为 200 ms，拖动期间跳过 `update` 刷新，结束立即刷新。页面关系发现已迁入 Worker；不能创建 Worker 的受限环境使用有数量上限的同步回退，回退任务内部不能即时响应停止。

### 2. 点预处理

1. 合并坐标完全相同的点名，避免重复影响尺度。
2. 用坐标下中位数平移原点，以“各点距离下中位数的下中位数”估计尺度。
3. 在归一化坐标中检测，基本距离／角度容差为 `2e-7`；排除归一化距离超过 `1/(2e-7)` 的极端点并提示。
4. 与固定代表点比较，合并容差内的近重合点，避免近邻链传递合并。

近重合位置的代表仍取决于输入顺序；坐标重合不代表作图身份或定义等价。

### 3. 直线与方向

枚举非退化点对，方向角取模 π，以周期排序建立直径有界的方向组，避免密集桶中的两两并查集合并。在方向簇内优先用短线段作锚，按点到锚线距离分组；mod π/2 的正交帧用于复用平行／垂直候选。

- 同一直线上至少三个不同位置：共线组。
- 一个稳定方向族中至少两条不同直线：平行组。
- 两个方向族夹角接近 π/2：垂直组。
- 方向族检查角簇漂移，并排除共享点的不同直线，减少远点近似射线误判。

不要求存在命名直线。平行、垂直按方向族汇总。

### 4. 共圆

枚举非近共线三点的外接圆，最多保留 **8000 个有效候选**；另有可配置的三元组枚举上限，达到任一上限后提示。按圆心与半径分桶，比较邻桶中每桶最多八个代表，用并查集合并。每簇再以首个圆复核所有参与点的径向误差，至少四个不同位置才输出。

这是有预算的数值搜索；候选截断及聚类可能影响召回。

### 5. 评分与结果

默认对关系组的**全部位置代表点**评分，再展开别名。最多八个共线／共圆见证点的显示限制不影响评分。有明确约化时改用有效支持：射线别名不重复参与评分；生成模型、共享全等的核心／剩余条件和有限角色族分别评分并取最大值，消去的参考量不因原写法而抬高价值。完整对象仍保留用于联动与回看。排序按：

1. `nonTriviality` 降序；
2. `confidence` 降序；
3. 固定类型次序；生成摘要与相似／全等优先于普通标量，保留原四类的相对次序；
4. 关系 ID。

`confidence` 保留原有固定值／按点数递增的启发值，只作兼容及次级排序，不作为概率百分数呈现。新类型与方向生成模型的细节见实现记录。页面将计算、显示、筛选分离，分数徽章不再按类型配色。

## 当前评分公式

每个命名构造的有效输入数为 k；纯引用别名（如 `X=A`）折叠，重复的同一输入只计一次。其他构造每条向父节点的边代价为：

```text
step(k) = 1 + 0.5 × log2(k)        k ≥ 1

d(x,y) = min [ upDistance(x,a) + upDistance(y,a) ]
         a 遍历包含 x、y 自身在内的共同祖先，不包括哨兵根
```

这里距离只向父节点上溯，不会通过无关的下游构造建立捷径。输入越多，代价适度增加；函数名、公式长度、匿名嵌套次数都不改变一步的代价。

用 d 连接关系的所有代表点，求最小生成森林：

- 无法连通：`constructionSpan=null`，基础分为 100。
- 能连通：`constructionSpan=L` 为最小生成树最长边，基础分为 `100 × (1-exp(-max(0,L-1)/8))`。
- 上游存在读取失败、部分解析、自引用或循环：评分上限为 50，并显示依赖不完整。
- 不足两个不同对象：评分为 0。

这是依赖基础分。展开由当前生成观测约化得到的子关系时，展示价值另乘 0.25 并显示来源，避免大量低信息重复结论重新占据高分位置；方向模型摘要在结果组预算中保留优先名额。

最大必要连接而非点对均值，能避免 `Q=f(A,B,C,P)` 的大量输入／输入点对抬高分数，也避免许多邻近点稀释一个远端点。该距离是结构代理，**没有实际执行几何消元，也没有判定某关系由定义必然成立**。

示例：`M=f(A,B)` 的 MAB 关系 6.06 分；共享 ABC 的 AKD 关系 9.43 分；Pappus 线在匿名连接线表示下 31.27 分，命名展开后 46.47 分。完整实验及取舍见设计文档。

## 性能与边界

- 点对为 `O(n²)`；方向排序 `O(p log p)`，p 为点对数。线关联分组仍有扫描成本，并不意味着整个管线是近线性的。
- 三点圆枚举最坏 `O(n³)`；现在同时限制有效圆数和尝试的三元组数。
- 依赖质量与别名用拓扑遍历处理；最短祖先距离按需计算、在一次分析内缓存，点对距离也缓存。最坏祖先缓存和点对缓存仍可能为二次空间。
- m 个评分点的最小生成森林需 `O(m²)` 次距离查询；每个未缓存查询还要扫描较小的祖先距离表。
- 候选聚类、输入顺序、重合代表和分组仍有局限。当前不做微扰验证，不为自动证明系统提供完备事实或证明证书。
