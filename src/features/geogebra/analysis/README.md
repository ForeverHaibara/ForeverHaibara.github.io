# 几何关系发现与作图依赖分析

本目录从 GeoGebra 当前作图读取对象与点坐标，建立依赖图，发现数值上成立的几何关系，并按启发式非平凡程度排序。

当前实现的分数叫 `nonTriviality`，本质上是**参与点的依赖分离度**，不是定理难度、关系成立的概率，也没有识别关系是否就是作图定义。本轮仅新增文档；改进设计见 [价值评分改进方案](./docs/value-scoring-design.md)。

## 文件与数据流

| 文件 | 职责 |
| --- | --- |
| `constructionSource.ts` | 读取对象名称、类型、定义指令和二维点坐标，记录读取错误。 |
| `expressionParser.ts` | 尽力解析定义表达式为 AST，并提取对已知对象的引用。 |
| `constructionGraph.ts` | 建立完整依赖图；另提供依赖图视图的筛选与路径压缩。 |
| `graphTypes.ts` | 对象、表达式、图和诊断的类型。 |
| `dependencyMetric.ts` | 强连通分量、祖先集合、深度、依赖分离度及分数解释。 |
| `equivalence.ts` | 并查集、周期角距离和分桶聚类。 |
| `geometryRelations.ts` | 点预处理、共线／平行／垂直／共圆发现、分组、评分和排序。 |
| `geometryTypes.ts` | 关系、见证、容差、评分和分析结果的类型。 |
| `useDependencyGraph.ts` | 监听作图变化，合并刷新请求并避免旧读取覆盖新结果。 |
| `useGeometryRelations.ts` | 随图更新调度关系发现，将结果交给界面。 |
| `constructionGraph.test.ts`、`geometryRelations.test.ts` | 解析、图投影、关系发现、数值稳定性和重合点等现有测试。 |

入口是 [`GeoGebraStudioPage.tsx`](../../../pages/geogebra/GeoGebraStudioPage.tsx)，结果由 [`GeometryRelationsView.tsx`](../components/GeometryRelationsView.tsx) 显示。

```text
GeoGebra API → ConstructionSnapshot → 完整 DependencyGraph
                                         ├→ projectGraph → 依赖图视图
                                         └→ detectGeometryRelations → 关系列表
```

**关系发现使用完整图，不使用依赖图视图的投影图。** 面板中筛掉某类对象，不会改变评分。对象仅被隐藏、对象成为命名辅助步骤、步骤只在匿名表达式中出现，是不同情形；当前图并没有用户作图意图或操作边界的记录。

## 当前发现算法

### 1. 读取与建图

`getAllObjectNames` 后，对每个对象读取 `getCommandString`、`getObjectType`；对支持的二维点类型读取有限的 `getXcoord`、`getYcoord`。只在关系检测时取有有限坐标的点，建图仍保留其他类型的对象。

解析器保留嵌套调用 AST，但图只为**已有名称**建立顶点。例如 `Reflect(P,Line(B,C))` 产生 `P,B,C → 输出`，不会为内层匿名 `Line(B,C)` 建立顶点。它不解释 `Reflect` 的几何含义。对不完整语法仍从 token 中保留已知名称引用，避免轻易丢失依赖。

无已知依赖、空定义或读取失败的对象，通过 `fallback` 边连接哨兵根。该边既可能代表自由对象，也可能代表信息不足；现评分不区分这两种证据质量。

更新事件防抖 200 ms，拖动期间跳过 `update` 引发的刷新，拖动结束立即刷新。关系计算通过 `setTimeout(...,0)` 调度，仍在主线程同步执行，不是 Worker。

### 2. 点预处理

1. 合并坐标完全相同的点名，避免其重复影响尺度估计。
2. 用坐标下中位数平移原点，用“各点距离下中位数的下中位数”估计尺度。
3. 在归一化坐标中工作，距离／角度基本容差为 `2e-7`；排除归一化距离超过 `1/(2e-7)` 的极端点，并给出诊断。
4. 与固定代表点比较，合并容差内的近重合点，避免近邻链传递合并。代表取决于输入顺序，几何重合并不等于作图身份或定义等价。

### 3. 直线与方向关系

枚举所有非退化点对，将方向角归一到模 π；以角分桶和并查集聚类方向。在方向簇内优先以短线段为局部锚点，按点到锚线的距离分组。

- 一条线包含至少三个不同位置时，生成共线组。
- 同一稳定方向族包含至少两条不同直线时，生成平行组。
- 两个方向族夹角接近 π/2 时，生成垂直组。
- 方向族另检查角簇漂移，并排除共享点的不同直线，以减少远点形成的近似平行射线误判。

这些关系不要求画面上存在命名直线。平行、垂直结论是整个方向族的汇总，不是逐一输出所有线对。

### 4. 共圆

枚举非近共线三点，计算外接圆。最多保留 **8000 个有效三点圆候选**，达到上限时停止后续枚举并提示；这不是均匀抽样。

按圆心和半径分桶，对邻桶中每桶最多八个代表进行比较，以并查集合并候选圆。每簇以首个圆重新检查簇内所有参与点的径向误差，至少四个不同位置才输出共圆组。

### 5. 生成结果

发现完成后再展开重合点别名。共线、共圆的评分点集来自最初最多八个代表见证点；平行、垂直则使用见证中的全部代表点。随后按以下顺序排序：

1. `nonTriviality` 降序；
2. `confidence` 降序；
3. 固定类型顺序：共圆、垂直、平行、共线；
4. 关系 ID。

`confidence` 是固定值或按点数递增的启发值：平行／垂直为 0.98，共线从 0.75 起，共圆从 0.85 起。它没有使用残差、多构型验证或证明；界面将其显示为百分数，不应据此理解成统计置信概率。

## 当前评分的精确定义

先将图的强连通分量缩成 DAG。根深度为 0，其他分量深度为父分量最大深度加 1，因此正常自由对象深度为 1。祖先集合排除哨兵根、不包含自己，也不包含同一强连通分量的其他成员。

对用于评分的每个点对 `(i,j)`，设祖先集合为 `A_i,A_j`，祖先权重 `w(v)=depth(v)/(1+depth(v))`：

```text
pairSeparation(i,j) = 1 - W(A_i ∩ A_j) / W(A_i ∪ A_j)
                      若并集权重为 0，则取 1

B = 所有点对 pairSeparation 的算术平均
D = 1 - exp(-参与点平均深度 / 3)
I = 互不为祖先的点对数 / 总点对数

score = clamp(100 × (0.55 B + 0.25 D + 0.20 I), 0, 100)
```

`sharedAncestorWeight` 是各点对交集权重之和除以并集权重之和，用于解释；由于各点对分母不同，它通常不是 `1-B`。

算法的优点是可解释、无须证明器、与四种关系共享实现，并能给跨作图分支的关系一些优先级。主要问题是：**仅用无类型点集评分，没有利用关系种类、点的角色、构造操作的语义或定义中已知的结论。** 直接依赖在分支项里仍可表现为完全分离，深度又可能奖励辅助步骤。具体反例和改进顺序见设计文档。

## 边界与验证

- 当前只是单个构型的数值发现，不能区分恒真关系、特殊位置和偶然近似成立。
- 点对数为 `O(n²)`；方向分桶在大量同方向点对时仍可能退化为 `O(n⁴)` 比较，线分组也有扫描成本。
- 三点圆枚举最坏需检查 `O(n³)` 个三元组；8000 限制的是有效候选数，大量共线时不限制无效三元组检查数。后续候选聚类有桶代表上限，但可能漏合并。
- 祖先集合最坏占 `O(V²)` 空间；每条关系的成对祖先集合运算还会增加成本。当前不宜把全部流程理解成线性或近线性。
- 现有测试覆盖数值稳定性和部分发现行为；排序测试只验证分数降序，未验证价值排序是否符合几何直觉。
