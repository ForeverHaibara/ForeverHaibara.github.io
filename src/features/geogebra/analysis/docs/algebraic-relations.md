## 2. 可复用内核与几何量

`quantities/lengths.ts` 提供唯一的正长度入口：从真实端点重新核算长度，拒绝自身点对、同名端点、重合／近重合、非有限坐标及重复无向点对。先确保属于正乘法域，再取 log。等长、固定长度比、中点和长度模型共用它，不依赖显示层过滤非法结果。

`algebra/scalarSearch.ts` 提供：

1. 整数线性表达式的合并与消项，零表达式不当作新关系。
2. `matchScalarTransform`：排序索引检索 `y≈a·x+b`。普通角二倍用 a=2、b=0；余角／补角用 a=−1、b=π/2 或 π；长度比在 log 域用 a=1、b=log(p/q)。每次查询和候选复核都计预算。
3. `RationalCombinationIndex`：对一个局部基预建小系数表，再用二分区间检索目标。偏移由调用者提供，可用于 log 常数、角常数或其他标量域；不写死几何名称。

两类搜索都只生成候选。检测器仍在原始长度或普通角域复核。长度比检查 `qL₁≈pL₂`，不通过两个接近零的乘积制造关系。角始终保留射线顺序和普通角折返分支，不把 30° 与 150°混为等角。

`QuantityEquation` 存储量的类型、对象角色、整数系数及可选 π 常数。UI 从结构化数据格式化，不解析公式字符串。距离统一显示 `dist(I, Q)`，避免把旧的 `|I·Q|` 看成 `II·QI` 或长度乘积。

## 3. 无量纲的长度生成模型

对参考三角形 ABC 选 L₀=AB，候选范围只取与 A/B/C 至少一顶点相连的正长度。先从 AC、BC 的长度比中挑出不能由当前小系数表描述的生成元，最多两个。模型是：

```text
(L/L₀)^d ≈ (p/q) × ∏ (Gᵢ/L₀)^aᵢ
1≤d≤4，|aᵢ|≤4
p/q ∈ {1,3/2,2,3,2/3,1/2,1/3}
```

因此 √2、倒数和小有理幂可以表示，且统一缩放不会改变模型。**不直接将有单位的 log(L) 当作具有绝对常数项的量拟合。** 每条模型关系都用实际正长度比及乘幂重新核算，数值溢出或相对误差过大即丢弃。

索引为每个基预建至多 `4×9²×7=2268` 条组合，按值排序；每个目标进行一次区间查询，而非每目标重复枚举全部系数。候选段约 O(n)，基础点对资源仍有 20000 上限。

log 关系登记为：

```text
d·log L + (Σaᵢ−d)·log L₀ − Σaᵢ·log Gᵢ
− e₂·log 2 − e₃·log 3 ≈ 0
```

`log 2`、`log 3` 是不可选作主元的常数列；e₂、e₃ 根据 p/q 精确取得。行空间、分数消元、来源及误差传播复用首批实现。

仅参考边和生成元自身的换基描述不输出；成员至少比生成元数多三条，并且必须新增至少一条约束。同一成员支持集不会反复报告换基模型。每个类型最多 12 个有效参考三角形尝试、默认 6 个输出模型；方向和长度各有自己的模型额度。

本轮模型仍是局部、可重叠、有界秩的启发描述，不宣称覆盖完整有理线性空间或整数格。没有根据点星的长度可描述性推定中心之间的所有连接也可描述。

## 4. 冗余控制与层级

- 固定长度比和简单角关系先商掉数值等值簇，使用代表量检索；不把簇中所有见证两两配对。近似等值仍用逐组直径复核，不能靠传递闭包跨过容差。
- 中点登记两半等长和全长为半长二倍；相似／全等登记对应长度约束。长度生成模型随后登记其新约束。
- 等长、固定长度比、二倍角、余角／补角会先用相应空间约化；已生成且误差上界足够小的结论默认隐藏。展开时保留来源并应用已有的生成关系价值折扣。
- 同一个长度倍率在相似三角形的多条对应边上成立时，一条倍率加上相似约束可覆盖其余倍率。
- `refinements.ts` 单独维护相同支持集的细化：中点覆盖其三个点的共线观测；四个以上点的共线组不会因此被吞掉。展开时可查看子结论及来源。
- 方向表达式的通用望远镜恒等式消项后直接移除，即使“展开”也不展示。这里没有把任何满足数值关系的结果自动升级为证明。

修正了三角形长度约束误差登记：使用实际观测残差加数值余量，而非对每条约束都使用整个容差档。后者容易在消元后把误差上界过度放大，造成明显重复倍率没有被压缩。误差较大的近似约束仍不能强行吞掉新结果。

普通角还显式累计“实际射线角”与“近似共线载体的方向表达式”之间的差值；组合和消元都传播该差值，避免将近似载体当作精确几何对象后低估误差。

## 5. 候选顺序与预算

`balancedTriples` 按名称稳定排序后的索引跨度轮转：同一跨度先走过不同顶点，再增加跨度。每个无序三元组完整运行时只出现一次。三角形、方向种子、长度种子和三顶点角共用此顺序；普通角对每个三元组轮流计算三个顶点。原四种关系的圆候选暂保留原顺序。

这比穷尽首个顶点的全部三元组更均衡，但仍依赖名称次序，**不是随机均匀采样，也不保证预算截断下全局召回**。

继续使用 maxTriangles、maxAngles、maxComparisons、maxModels、maxRelations。中点、各角组合及固定长度比另受每类输出上限约束，最后统一按价值筛至总结果限额；生成摘要优先保留。达限明确报告 partial。代数空间预算耗尽只影响后续压缩，不绕过原值复核。

## 6. 分类及批量控件

`RelationTypeControls.tsx` 根据关系目录自动生成 Basic、Lengths、Angles、Triangles、Generators 五组。各组默认折叠，显示已启用数／总数。

最初全局和每组均提供 Compute 与 Show 的 All／None／Invert。2026-10-22
修订为两个独立用途的选择器：

- Compute 只改计算类型，支持真正的空集合；下一次自动运行按新的集合计算。
- List filters 只改当前角色视图的展示类型，不重算，也不受计算集合限制。
- 分类操作保留其他组的设置；隐藏条目或关闭计算不会取消同快照的已接受条件。
- 批量选择逻辑提取为纯函数 `changeRelationSelection`，稳定按目录排序，不依赖 UI 组件位置。

存储新增 knownKinds，用于识别未来新类型；已经明确关闭的已知类型不会在归一化时被重新打开。旧版没有该字段时，仅“完整选中旧十类”的设置采用新默认类型；旧版选择子集或空集合保持原选择。新默认仍不开启余角／补角。
目录过滤不再读取旧的显示偏好。具体角色状态、重置规则和结构化检索见
[结构化检索与筛选](../../reasoning/docs/catalog-search-and-filters.md)。
