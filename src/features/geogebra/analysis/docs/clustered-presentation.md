# 等值簇与生成模型的约简展示

2026-10-19，承接 [第二批代数关系实现](./algebraic-relations.md)。本次完善已有类型的聚类、支持集和展示，没有新增几何类型；结论仍是数值探索。

## 1. 等值类不能只留下代表元

此前角度与长度搜索已经通过等值类代表元减少组合数量，但生成二倍角、余角、补角和固定长度比时只保留代表量，丢掉了其他见证。

现在 `ScalarClass<T>` 同时保存代表量、完整成员及数值最小／最大值。搜索仍在类代表上运行；输出用 `QuantityEquation.terms[].equivalents` 保留整簇，正文例如：

```text
(∠A = ∠B) + (∠C = ∠D) = π/2
(∠C = ∠D) = 2 × (∠A = ∠B)
2 × (dist(A,B) = dist(C,D)) = (dist(E,F) = dist(G,H))
```

同一等值簇可以与自身形成余角／补角关系：两个 45° 角合并为 `2 × (∠A = ∠B) = π/2`，两个直角合并为 `2 × (∠C = ∠D) = π`。单个角不以“两角”名义自配对。

完整成员参与关系的对象支持集、评分及对象联动。正文每个类默认显示前八项，展开可查看较长摘要；截断标出剩余项数，显示限额不裁剪底层成员或评分。

## 2. 整簇复核与推论判断

`algebra/scalarClasses.ts` 将标量排序后用极值维护有界直径的类，排序后线性扫描，不通过近似传递闭包合并，也不需要比较密集类中的所有成员对。超出预算只保留已复核的成员，并报告 partial。

对于 `y≈a·x+b`，通过两类极值直接核算整个笛卡尔积的最大残差。倍数会放大源簇跨度，不能只因代表元相符就将所有替换一并发布。长度在 log 域复核整簇范围，并保留原长度交叉倍数校验；普通角直接在实数域检查，不合并普通补角。

`relations/clusteredQuantities.ts` 统一判断一个簇关系包含的两部分信息：

1. 代表量之间的倍数／固定和关系；
2. 每个类内部所有成员与代表量的等值关系。

只有这两部分都能在当前约束空间中可靠约化，才把整条关系标为生成推论并按设置隐藏。如果代表关系已知而类内还有新等值信息，整条聚合结论仍保留。登记约束采用代表星形结构，附带原始数值残差及角载体误差，不枚举全体成员配对。

同理，代表式本身消成零，不意味着整条带等值簇的结论都是恒等式；只有代表式和全部成员绑定都纯消项时才直接移除。

## 3. 长度生成式恢复为原几何量

生成模型内部继续使用无量纲式：

```text
(L/L₀)^d = (p/q) × ∏(Gᵢ/L₀)^aᵢ
```

展示层先化为原长度的幂积：

```text
L^d = (p/q) × L₀^(d−Σaᵢ) × ∏Gᵢ^aᵢ
```

这样参考长度的共同分母自动抵消；零幂、相同无向线段、整数系数公因子和常数的完全幂也统一约简。长度均为正，约去共同幂时没有符号分支；仍保留 `L²=2R²`，不会错误约成 `L=2R`。

相同的精确有理描述先合并成员，参考／基自身的恒等式不占行数。用户提供的例子约为：

```text
2 × (dist(E, L) = dist(F, L)) = dist(E, F)
```

如果多个描述只是同一长度的有理倍数，还会进一步合成原始整数系数的比例链。例如：

```text
AP=BC/2，BP=BC，CP=2BC
    ↓
4 × dist(A, P) = 2 × (dist(B, C) = dist(B, P)) = dist(C, P)
```

相同几何信息不再分别铺成三条含重复分母的式子。无理幂或一般多生成元乘积仍保留必要幂次，不为了缩短文本丢掉关系。

## 4. 方向生成式与 π 分支

方向显示统一使用 `∠(u, v)`；它是两条直线的有向夹角，方程中保留 π 分支。θ 的内部快照 lift 及有理约束计算保持原有机制，展示没有把 `2α=π` 错当成 α=0。

展示层消去不再出现的参考方向，省略参考／基的恒等式，将同描述成员合为平行簇。可以直接表达的同向与半周分支分别显示成 `DE ∥ FG ∥ AC`、`(HI ∥ LM) ⊥ AB`；有共同参考的两角之差可直接写为另一对直线的夹角。其余表达式仍显示小整数系数和 π 项，省略零项与 `+ -`。

`presentation/generatorPresentation.ts` 独立负责两类模型的标准化、恒等式移除及合并，不修改检测得到的模型、约束来源或独立约束数量。对不可变快照使用 WeakMap 缓存，避免筛选／展开时重复整理成员。

`GeneratorDetails.tsx` 按约简后的方程数截断，剩余数量也按分组方程计，不再把隐藏的基恒等式算作“尚未展示的关系”。
