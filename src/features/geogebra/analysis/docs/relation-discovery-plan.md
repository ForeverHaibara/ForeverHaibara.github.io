## 1. 目标与设计决定

将目前四种关系扩展为可维护的数值探索系统。优先补充**点重合、长度相等、角度相等、相似和全等**，再加入简单倍数、比例、加减关系。先研究生成关系与低复杂度空间，后枚举不能被约化的表达式。等角共轭点对仍是低优先级。

采用三层模型：

1. **几何量提供器**：从当前对象与坐标生成位置、长度、方向、角度、面积等带对象角色的量。
2. **代数搜索内核**：复用近似等值、固定偏移、小整数线性组合、乘积／商组合搜索。
3. **关系定义与展示**：指定数值域、候选约束、对称性、显示名称与分组，不重复实现底层匹配。

不把所有几何问题硬塞进一个算法：关联、共圆、并发、相似等可以有专门候选生成器，但应复用实体、数值校验、索引、预算、结果协议、评分和 UI。原生／custom／展开公式统一依赖当前对象图，不要求逐工具理解语义。

数值观察仍是探索，不是证明。微扰检查独立留接口；本次扩展不依赖自动证明系统。

| `isogonal-pair` 等特殊三角形关系 | 关于指定 ABC 的特殊点对 | 参照构型模板，不进入第一批 | E，低优先级 |

这些 ID 是设计建议，阶段落地时才加入运行时注册表。UI 只显示已经实现的类型，不把未来项伪装成可运行选项。

### 2.1 第一批角度的明确约定

- 默认 `equal-angles` 指射线 BA、BC 的普通角，取值 [0,π]。∠ABC 与 ∠CBA 等价；30° 与 150°不相等。
- `equal-directed-angles` 单独控制，默认采用直线方向差 mod π，结论必须显示“有向、mod π”。反向只在指定域允许的对称性下规范化。
- 0 和 π 在非零射线时是有定义的角，不能误标为未定义；其大量重复关系可折叠到退化／平角小组，默认不刷屏。零长度射线则不能构成角。
- 四条互不相交支撑线之间的角搜索属于进阶范围，不在默认模式穷举所有四点对角。

### 2.2 组合搜索的初始边界

长度常数比的标准集先用 {3/2,2,3}，倒数通过交换两边表示；进阶允许互素 p、q≤4 的有限集。默认二倍角，不枚举任意实数系数。通用线性关系先限制三项，再放开四项，每项小整数系数，禁止无上限组合。

长度加减用 L；平方长度加减用独立量 L²。例如勾股型 L₁²+L₂²=L₃²可以复用加法搜索，但默认只在三角形三边模板中查找，不在任意线段全集中枚举全部组合。Ptolemy 等“乘积之和”也应优先使用四点模板，不能盲目生成全量六项表达式。

特殊关系名称是模板展示层，不要求为每个名称重写数值内核。中点不能仅凭 AM=MB 识别，还必须检查共线和非退化端点。

## 3. 候选范围与成本

设 n 为不同位置数，s 为线段数量，a 为角量数量，m 为某一数值域的量数。复杂度只描述候选规模，不承诺具体耗时。

| 量／搜索 | 不加限制的规模 | 默认策略 |
| --- | --- | --- |
| 点位置 | O(n) 个量 | 空间索引搜索重合；对象身份另存 |
| 两点长度、方向 | O(n²) 个量 | 建一份点对表，多类型共享；无效短段排除 |
| 有顶点普通角 | n·C(n−1,2)=O(n³) 个量 | 排除退化射线、交换端点去重，按明确预算生成 |
| 两条任意支撑线的角 | O(s²)，即可能 O(n⁴) | 进阶，优先命名线／当前选中对象的关系 |
| 三角形面积／形状 | O(n³) 个量 | 单份三元组资源；组合阶段才按需建立 |
| 量等值／固定偏移 | 标准标量排序／哈希可接近 O(m log m + 输出) | 适配各域的索引；密集桶仍有输出爆炸 |
| 三项和／比例匹配 | O(m²) 个组合候选 | 预算内的 pair-join，不用三重全扫 |
| 四项和／乘积等式 | O(m²) 个二项表达式，最坏 O(m⁴) 个匹配 | 分组、去恒等式、封顶见证；明确报告截断 |

例如 n=40 时已有 780 条线段、29640 个有顶点普通角。若再让所有角两两构造差，会超过四亿个二项组合。因此“内核可复用”不等于“默认穷举所有类型与所有组合”。

每个类型必须声明资源、候选上限和输出上限。关闭一种结论时，不再执行它的候选／验证／评分；其他开启类型需要的共享底层资源仍可计算。例如关闭平行输出，不意味着关闭等角所需的方向计算。

对截断同时报告“枚举／比较／输出”哪个阶段达限。使用确定性次序与分层配额，不能只永久取对象列表最前面的组合；但预算搜索仍然不是全量发现，UI 必须明确标识。

### 3.1 可用于首轮实验的预算草案

先将下列值集中放入可配置的预算预设，而非散落在 detector 中；它们是待实测调整的起点，不是性能承诺：

| 限额 | 标准探索初始值 |
| --- | --- |
| 共享基础点对 | 20000 个 |
| 有顶点角量 | 50000 个 |
| 每组合类型的二项表达式 | 100000 个 |
| 每类型候选复核 | 200000 次 |
| 每次运行保留的关系组 | 500 组，按类型分配配额后共享剩余空间 |
| 每组默认可见见证 | 8 个，成员／评分支持不受此显示限额影响 |
| 运行软截止时间 | 标准约 1 秒；深入组合约 3 秒，超时保留已完成部分并标记 |

数值生成按顶点／实体类别轮转，而非让某一个顶点消耗全部角预算。每 256 个候选及阶段边界检查取消；主线程分块目标约 8 ms，但原生排序等不可中断工作仍需单独测量。达到存储成员上限时降级为有明确见证的摘要，不能在没有保存／验证成员的情况下声称完整等值类。

## 4. 实现里程碑

### A. 拆出基础架构并交付 UI 控制与分数颜色修正

1. 增加关系目录、统一结果协议、运行计划和每类型状态；保持 `geometryRelations.ts` 为兼容入口。
2. 将点对和归一化资源从四种检测逻辑中提取为共享 provider。旧检测器先作为 adapter 接入，不同时重写其全部数学过程。
3. 实现计算开关、显示开关、显示筛选与单次／自动运行；改变显示筛选不重跑几何算法。
4. 评分徽章改为统一的单色顺序色阶；类型用中性文字和符号。该项不等待新类型完成。
5. 增加预算与取消检查；同步分块 runner 先可用，Worker 接口及实现随后接入同一纯计算 API。

验收：四种原有关系在预算未截断的回归样本中保持结论和评分；相同数值的徽章跨类型同色；关闭类型不执行其 detector；隐藏类型不触发重算。

### B. 第一批新增：重合、等长、等角、相似／全等与方向生成模型

1. 为重合发现保留原始点身份，在位置合并前形成近似重合观测，再提供去退化的几何代表。
2. 实现标量／二维／周期域近似匹配与严格见证复核；解决误差链，不把并查集连通分量直接当等值组。
3. 增加长度和普通角 provider，运行时复用已有点对数据；新增 `coincident-points`、`equal-lengths`、`equal-angles`。
4. 增加有向角域和可选 provider，默认不做任意四线角的全量搜索。
5. 将现有平行／垂直的方向匹配逐步迁入同一索引内核，仍保留线关联与方向族稳定检查。
6. 提前相似／全等，共享形状与尺度索引，将对应边／角作为生成约束，压缩重复子结论。
7. 使用参考三角形的点星、有界整数关系和观测行空间；先描述簇的生成元，再搜索跨簇的新关系。实现状态与数值实验以生成空间文档为准。

验收：等腰三角形底角、圆周角、等弦、正方形、两个独立构造点重合等构型得到预期观测；补角不会误标普通等角；纯别名与独立点重合可区分。

### C. 加减、倍数、比例与面积

1. 加入带维度和代数域的表达式节点、符号抵消与对称规范化。
   先在 log 长度等域复用生成约束空间；三角形面积改为叉乘族的特例，未来点乘共享向量原语，不将高项数穷举作为默认路线。
2. 实现固定偏移及二项和／差索引；正乘法群通过 log adapter 复用加法搜索，有向量再加入符号因子。
3. 先交付小常数比、二倍角、中点；再交付限额的等比例、角和／补角、面积等值与组合。
4. 加入基础量的恒等式证书，拦截方向差的望远镜求和、AB=BA、比例自身相消、面积通用剖分式。
5. 在标准和进阶预设中分别开启低成本与组合类型，不改变普通用户的运行模式含义。

验收：中位线、角平分线、圆心角／圆周角二倍关系、相似三角形对应比、面积比能用相同内核表达；零分母、负号、角域模数处理正确；不会产生海量普遍恒等式。

### D. 命名解析对象与复合构型

1. 扩展只读数据适配器，为命名直线／圆提供结构化解析参数。先核实当前引擎 API／XML 的实际格式并做适配测试；不解析本地化显示字符串，不创建临时 GeoGebra 对象。
2. 扩展点在线／圆上、线圆重合、共点、切触关系；命名对象和点对形成的隐式实体采用同一实体协议。
3. 相似／全等已移至 B；这里继续完善命名实体对应、对称生成元和更大构型的公共约束复用。
4. 再评估向量平行四边形、交比和有限构型模板。

这些工作按类型拆分，不要求一次加入所有类型。数据不可读应显示该类型“缺少输入／不支持”，不能返回“没有发现”冒充成功。

## 5. 质量与维护验收

- **代数内核测试**：精确相等、容差边界、周期跨界、误差链、符号、零值、模群不可约分、量纲错误和重复表达式。
- **数值几何测试**：平移／旋转／统一缩放，极端尺度隔离，近退化角／圆／线、正反顶点顺序、镜像构型；不得承诺高于输入浮点精度的能力。
- **评分兼容**：实际原始对象支持集交给现有评分函数，虚拟几何量不加入作图依赖图。对象组不能因只显示八个见证而漏评。
- **行为测试**：计算关闭、显示隐藏、筛选、取消、旧快照、Worker 迟到消息、切换预设、导入／清空、存储迁移和异常类型隔离。
- **构型库**：等腰／等边／直角三角形，平行四边形／菱形／矩形，同圆点、圆内接四边形、中位线、角平分线、Pappus；后续添加 Simson、Desargues 等。仍只检查数值观测与相对排序。
- **性能实验**：至少 20／40／80 个位置及大量共线、共圆、等距、近等角的密集桶，分别记录量数、候选数、复核数、内存和耗时。不能只测随机点的稀疏匹配。
- **阶段门槛**：新增一个普通等值类型，应主要增加 provider／domain／关系定义与测试，而非修改调度器和关系主列表的巨大 switch。新增复合类型允许专用生成器，但复用公共协议。

首版预算从上面的草案出发，在 B 的性能实验后定稿；未测量前不承诺 80 点下开启全部组合类型仍实时。默认自动运行、停止后的快照更新、单次深度运行的具体状态见 UI 文档。
