# 条件退化分析：架构与实施计划

2026-10-19，**设计提案，尚未实施**。本轮不修改运行代码。数学定义见 [理论说明](./conditional-degeneracy-theory.md)，具体预期见 [验收构型](./degeneracy-casebook.md)。本计划应先于更多组合关系的大规模扩展实施。

## 1. 当前实现的实际边界

这次问题不只是展示重复；无关辅助对象进入评分、候选预算被别名耗尽、复合关系掩盖较小条件，都需要在发现管线内处理。

| 位置 | 已有能力 | 尚缺能力 |
| --- | --- | --- |
| `scene/geometryScene.ts` | 合并重合位置，建立非零点对、支撑线及方向组；支撑线以锚线复核 | 普通角的同向／反向射线商，以及商后的候选枚举 |
| `relations/directionSpaces.ts` | 点对映射到已有支撑线，方向关系使用载体 ID | 共线来源目前依赖启用的共线结论；应区分基础几何事实与输出开关 |
| `relations/metricRelations.ts` | 普通角与方向行保留角度分支信息；等值类参与关系合并 | 仍先枚举大量三点角再约化；没有统一的条件支持分析 |
| `relations/lengthRelations.ts` | 对数表达式已经能抵消同量，生成空间检查线性独立 | 模型对象仍来自成员端点的并集；代数量的行独立不等于几何对象不可消去 |
| `relations/triangles.ts` | 排除退化三角形；保留顶点对应；登记对应边的长度约束 | 缺少共享边消去、独立背景扣除及剩余轨迹的分解 |
| `relations/clusteredQuantities.ts` | 复用等值簇，保留对应别名 | 等值簇不能替代有角色的关系族索引 |
| `presentation/generatorPresentation.ts` | 约去展示中的公共归一化分母，移除恒等式、合并比例链 | 展示后约简不能挽回先前候选预算、模型支持和评分的失真 |
| `geometryRelations.ts` | 可通过 `scoringNames` 单独指定评分对象 | 尚没有有效支持／守卫支持的统一契约 |
| `dependencyMetric.ts` | 对实际作图图衡量局部性，保持宏工具的一步语义 | 不做几何条件消元；不应把虚拟量节点塞入原作图图来补救 |

因此，“已有线载体，但尚未充分在普通角枚举前复用”比“完全没有共线压缩”更准确。第一阶段保留已有相位逻辑，向前移动公共约化能力。

## 2. 数据契约：表达、信息与证据分开

以下为概念协议，具体 TypeScript 名称在实施时确定，避免先造一个覆盖全部几何的庞大类型系统。

### 2.1 带类型的表达式与谓词

每个量记录量类型、对象角色、数值域、允许的对称性和定义域守卫。例如：

```text
Length(A,B)                     正长度；端点可交换；A≠B
OrdinaryAngle(A,C,D)             [0,π]；端点可交换；A≠C、D≠C
DirectedAngle(line1,line2)       明确指定模数；保留顺序与 lift
Congruent(T1,T2,correspondence)  带顶点对应的复合谓词
ExistsInLinearFamily(basis,P)   以后接入；存在非零参数向量
```

普通角可以有零角；不能把“非零射线”误写为“角度非零”。长度的 log 域则确实要求长度严格正。

面积／叉乘等可为零的量先区分零分支、符号及非零分支。`u·v=u·w` 不能无条件约去 u；u=0 与 u≠0 分别对应完全不同的支持与剩余条件。

表达式操作记录乘除、幂、和差等已有代数结构。只理解本模块生成的几何量，不尝试理解任意 GeoGebra 命令或展开函数的语义。

### 2.2 规范化结果

一个候选约化为以下内容：

```text
原始谓词及角色绑定
核心条件 + 剩余条件 + 定义域守卫
原始见证支持 / 有效支持 / 假设与守卫支持 / 参考框架支持
约化步骤、独立来源、数值误差、未解决的分支
```

有效支持可以有多个等价选择，不要求每次找到唯一最小集。只从有记录的合法步骤减少对象。不能把无法解释的数值零残差直接解释为对象无关。

例如 `AB/BD=BC/BD` 的等式支持是 ABC，守卫支持含 BD；一个模型若另有仍依赖 D 的有效行，D 仍应留在该行及模型的信息支持中。

### 2.3 关系族与自由度诊断

关系族记录模板、允许置换、固定角色、可变角色、**实际验证的绑定元组**、代表实例与来源。附加诊断可取：

| 字段 | 含义 |
| --- | --- |
| `freedomStatus` | 未知／有限见证／受轨迹约束／结构上不依赖某角色 |
| `evidenceKind` | 表示约化、独立背景约化、矩阵容量、重复角色、局部试动 |
| `rankEstimate` | 可选秩区间、阈值与稳定性；不承诺全局维数 |
| `coverage` | 已测试、满足、未访问与被预算截断的数量 |

方程展示数、见证数、生成约束秩、生成元数和几何自由度必须分别保存。现有标题中的 `dim` 继续指生成元个数。

## 3. 管线及模块边界

```text
不可变场景快照
→ 基础位置／线／射线商
→ 有预算的几何量和关系候选
→ 带角色的谓词、守卫与原始见证
→ 共享规范化与支持约化
→ 对独立背景计算新增条件
→ 有限关系族索引与可选诊断
→ 选择核心及复合见证，评分
→ 展示
```

建议增量增加以下模块职责；先迁移现有逻辑，再扩充能力，不同时维护两套约分规则。

| 建议位置／职责 | 输入与输出 |
| --- | --- |
| `scene/` 的射线索引 | 点、支撑线 → 以顶点为基准的同向射线类及端点别名 |
| `algebra/` 的带守卫规范化 | 本模块表达式 → 规范式、守卫、支持映射及约化记录 |
| `relations/` 的条件比较适配器 | 全等等复合谓词 → 原始比较条件与剩余条件 |
| `relations/` 的背景事实库 | 基础载体事实、已接受独立观测、来源 DAG；与 UI 输出目录分开 |
| `relations/` 的角色族索引 | 规范化实例 → 具有固定核心和变化角色的有限实例族 |
| `relations/` 的可选诊断 | 纯数值评价器 → 局部秩／试动结果，允许返回 unknown |
| `presentation/` | 选择核心、余下条件、有限绑定列表与展开入口 |

基础事实库不意味着关闭的类型仍完整运行。例如已有线索引可以给角度提供同线信息，不必为了角度启用全部共线卡片；而一个昂贵、未执行的关闭类型不能被当作已知背景。

### 来源必须无环

一个全等候选可能向长度空间登记三条对应边相等。随后不能再用这三条由自己产生的事实判定自己“完全已知”。

实施采用不可变背景批次或显式排除当前候选及其后代；互相等价的表达保留一个代表。记录“由哪个独立事实约去哪个条件”，而不是只记录一个 `redundant=true`。

如果约化得到尚无展示类型的小核心，先保留原卡片并附约化说明，不得在无法展示核心时把整条发现删除。

背景只包含受控几何事实，不包含把所有点坐标数值固化后的全部常数等式。批次间选择代表时以规范化条件和来源去环，不能因发现顺序不同就互相消去全部信息。

## 4. 第一优先：在源头消除表达冗余

### 4.1 普通角先商射线，再枚举角

对顶点 V，在其关联支撑线上按实际向量区分两个方向。每个射线类保留端点别名、与锚射线的数值校验及非零条件。

- 同向端点替换可以复用同一个普通角。
- 反向端点替换产生补角，不能等同于同一个普通角。
- 有向角另用有序载体和相位；不能沿用普通角端点交换。
- 共线的零角／平角可成为背景，不反复输出大量含任意辅助射线的恒等写法。

若顶点 V 有 k_V 个不同射线类，候选数量与 `Σ k_V²` 相关，而不必对每个原始端点三元组重复计算。最坏情况仍是三次量级；这不是普遍降到二次复杂度的承诺。

别名绑定宜因子化保存，不能为了显示又展开端点笛卡尔积。只有结构约化保证成立的别名组合才可压缩表示；预算之外未验证的数值近似组合不能自动补齐。

删除的是量之间的恒等比较，不是代表量本身。若同一个代表角还等于另一构型的角，该跨构型等式及它真正依赖的 D 必须保留。

### 4.2 生成约束先约分，再决定支持与输出类型

把现有对数量消项、公共分母抵消和展示约分收敛到共享规范化入口：

1. 消同量、合并系数、受非零守卫约分。
2. 用独立背景中的等值／倍数约束约化，保留来源。
3. 得到真正非恒等的条件和对象支持。
4. 若退回简单等长／固定长度比，优先保留该较小条件，生成模型只作来源或复合入口。
5. 在规范式上去重、判断新约束并评分，展示复用同一个结果。

已有的“所选 log 量行空间”继续用于代数压缩；它不是一般几何理想，也不能独自判断最小对象支持。归一化锚长度消失时，锚的端点不应仅因展示选基而抬高评分。

## 5. 第二优先：复合谓词的剩余条件

先为已有全等提供对应边比较器，使用平方距离的差，避免无必要的开方；先消共享边，再扣除独立等长背景。

`△ABD≅△CBD` 在 AB=CB 背景下剩下 `AD²−CD²=0`。这一条件关于 D 的坐标是仿射的，可识别为 AC 的中垂线，不需要知道 B 是如何构造的。若 A=C，先走重合位置与三角形合法性分支。

这是“原始比较条件分解＋有限低次残差识别”的首个适配器。以后相似、向量叉乘／点乘、圆幂可以接入自己的原始条件，不为每个特殊命令建立退化规则。相似涉及尺度和定向分支，不能直接照搬全等的 SSS 相等残差。

若剩余轨迹已经是独立已知事实，则全等是复合见证；若轨迹关联尚未发现，就保留这条新条件。没有命名中垂线时可显示 `AD=CD` 及其轨迹解释，不为此自动在 GeoGebra 中创建对象。

对普通、无特殊共享结构的全等，不能因为 SSS 等价就一律降级成边相等列表。先按新增信息去重，再按几何表达的可读性选择主摘要；全等／相似仍保有较高的摘要优先级。

## 6. 通用重复形态：先有限打包，后研究普遍性

以规范化后的谓词模板为键，枚举少量“留一个角色孔”的投影；固定其它角色，收集实际满足的实例。角色置换必须来自该谓词声明的对称性。

首批只做一个变化角色；第二批对确有收益的模板支持两个变化角色，并保存绑定元组。避免枚举所有核心子集或所有角色掩码。

例如 `{f(ABC,D),f(ABC,E),f(ABC,F)}` 可以显示为 `f(ABC, {D,E,F})`。这只表示有限观测。若它们又被结构约化为同一条 ABC 核心，则显示一次核心，原实例折叠为见证。

重叠的关系族不强行做一次全局最优覆盖。先按结构证据、支持大小、覆盖量和稳定 ID 贪心选择展示代表，原始实例到各族的关联仍保留。不能因为某实例已在一族展示，就把它包含的未覆盖新条件删除。

“满足次数／已检查次数”只用于诊断，不解释为概率：候选筛选、相关构造和计算预算都有选择偏差。通过点集拟合出的直线／圆，也不能自动成为谓词在整条轨迹上成立的证据。

## 7. 价值评分与展示

保留现有作图依赖距离，先修正它的输入支持，不重建一套依赖图。

- 原始见证用于选中、悬停、筛选、回看；约去的辅助对象仍可追踪。
- 新条件使用其有效支持评分；守卫或选基对象不因出现在原式中而增加价值。
- 背景已覆盖的派生写法归入来源；未记录的小核心必须先保留。
- 对有剩余轨迹的关系正常评分，不将“有连续运动”作为统一减分项。
- 关系族初版取成员新增条件分数的最大值，覆盖数单列，不对所有见证点并集重新评分。
- 只有重复次数／数值试动的怀疑，先作说明或有限排序辅助，不硬删除。

这与现有“全量位置代表参与评分”的规则需要有条件地衔接：没有约化证据时继续使用全量支持；不能以本次优化为名，随意只取几个易得低分的代表点。

展示建议采用“核心结论 → 仍有的条件 → 复合见证”的层级，默认折叠纯派生表达。有限点列表、轨迹、全域无关三种措辞明确区分。数值来源不包装为证明，诊断失败不显示“已确认任意位置成立”。

## 8. 后续诊断：脱离式试动与参数容量

### 8.1 可选试动与雅可比

只在克隆坐标上调用纯评价器，固定选定核心，按定义域和背景采样；绝不调用真实 GeoGebra 的移动、赋值、构造命令。分别记录环境平面中的试动与背景允许域中的试动。

采用多方向、多尺度、非零位移，并加入离开候选轨迹的对照。单点导数零、一个方向不变或若干次采样通过，都不能独自触发硬删除。奇异点、分支切换、近零分母和不稳定数值秩返回 unknown。

即使局部秩稳定且自由度与环境相同，也须保留角域、符号及连通分支限制。局部开集成立不等于完整允许域成立，未跨分支的试动不能消除这些条件。

此处评价的是几何谓词对坐标的依赖，不声称恢复了黑盒工具的实际可拖动性。也不等同于未来用于排除偶然相等的作图微扰系统。

### 8.2 线性参数族

以后接入一般的“存在参数使所有评价为零”模块，复用评价矩阵、核维数和增加点所消耗的参数容量。三次曲线只是一个实例。

需要明确非零参数、次数约定、是否允许可约／奇异成员。坐标归一化、矩阵缩放、秩阈值间隙与不确定区间进入结果；接近秩跃迁时宁可保留原观测，也不把第十点判为无关。

不在本批实现完整三次曲线搜索，更不按 Cayley–Bacharach 名称建立特例。若后来启用，应同时保留有价值的核心秩下降，而不是只隐藏任意附加点。

## 9. 预算与降级

保留现有点对、角度、组合比较、模型和结果数量预算。以下是新增预算的**实验起点**，不是已经实现的默认值或耗时保证：

| 项目 | 首轮建议上限 |
| --- | --- |
| 表达式规范化 | 每个候选 64 步，全轮累计 200,000 步 |
| 角色投影 | 每个模板最多 16 个掩码，首批仅一孔 |
| 角色族 | 2,048 个索引桶，最多 64 个进入深入分析 |
| 可选试动 | 最多 16 族，每族 24 次，全轮最多 512 次评价 |
| 附加诊断软时间预算 | 约 150 ms，需实际构型测量后调整 |

计数同时记录 attempted／matched／unvisited／truncated。候选未访问不能当作不满足，预算耗尽不能当作已经约化完毕。预算不足时保留原始有效数值观察，停止可选诊断，不增加现场计算或阻塞界面。

规范化结果、来源和角色索引只在同一场景版本内复用，不能跨拖动版本继承未复核的退化事实。

## 10. 里程碑与验收

| 阶段 | 交付 | 通过条件 |
| --- | --- | --- |
| M0：协议与诊断 | 守卫、四类支持、独立来源、统计字段；补充固定构型 | 不改现有输出；能解释当前冗余从何进入 |
| M1：角度候选商 | 共享支撑线上的射线索引，角度别名因子化 | 同向替换只算一次；反向补角及垂直剩余条件保留 |
| M2：生成约束与评分 | 共享带守卫约化，支持先于评分确定 | 公共分母不引入辅助点价值；小核心和真正依赖辅助点的行均不丢失 |
| M3：复合关系 | 全等 SSS 剩余条件及简单轨迹说明 | 共享边／中垂线构型不重复占据高分；未知轨迹仍作为新信息 |
| M4：有限角色族 | 一个角色孔的通用索引、保守打包与来源入口 | 不误称任意点，不补齐未验证笛卡尔积，不重复加分 |
| M5：可选数值诊断 | 脱离式试动、局部秩及 unknown 降级 | 奇异、分支、相关样本、预算不足均不导致错误删除 |
| M6：后续参数族接口 | 线性族的存在性与容量分析 | 精确样例与数值不稳定边界均有记录；完整曲线发现另立需求 |

M1／M2 是直接修复当前问题的第一批；M3／M4 在其规范化与来源基础上实施。M5 是辅助研究，不作为前四阶段落地的前提。

验收同时看数值正确性、信息是否保存、评分、展示和候选量。重点不变量：

1. 加入任意辅助点或改变同一表达的选基，不提升已知核心的价值和生成维数。
2. 只消去已经有证据无关的角色；剩余轨迹信息和未知核心保留。
3. 所有除法消项有守卫，零射线／退化三角形不混入正常模型。
4. 名称、输入顺序和允许的相似变换不改变理论分类；近似分组差异需记录而不掩盖。
5. 关闭展示类型不使已有基础载体事实失效；未计算的昂贵类型不伪装成背景。
6. 没有循环来源、未验证组合或真实作图状态变更。

性能对比记录原始／商后量数、评价次数、规范化步数、模型秩、卡片数与耗时分位数；不要仅以“少了多少结论”判断改进。详细构型及反例见 [验收构型](./degeneracy-casebook.md)。
