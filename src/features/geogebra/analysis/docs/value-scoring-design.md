# 价值评分：统一的作图局部性模型

状态：已实现第一版，2026-10-18。本文根据用户对上一版方案的调整重新设计，替代“识别每种工具的语义契约、再判断定义已知”的主路线。现状与文件入口见 [README](../README.md)。

## 1. 目标与范围

关系发现以数值观察为主，为几何探索提供候选。分数仅回答：

> 在用户当前采用的作图依赖中，这些对象的联系离直接构造有多远、涉及多少输入？

依赖近、输入少，一般更熟知、平凡；展开命名步骤会增加结构上的跨度。这里借鉴消点的思想，以邻近父节点作为可回溯的构造背景，**不执行符号消元，不理解函数的数学意义，也不证明关系**。

未来微扰检查可以增强数值可信度。独立自动证明系统需要自己的表示、前提、推理与验证；不能仅依赖本模块的数值候选或评分。当前既不建立证明状态分层，也不为了评分建立逐工具事实库。

同一模型覆盖原生、站点 custom、文件工具和任意嵌套表达式。百余种工具无需逐一登记。等角共轭只是“黑盒与展开作图不同”的说明例子；将来新增检测类型时，**相等角度的优先级高于等角共轭点对**，本轮不新增这两类检测器。

## 3. 为什么原函数失真

原式为 `100 × (0.55 B + 0.25 D + 0.20 I)`，分别使用祖先集合分离度、绝对深度和互不为祖先的点对比例。

### 3.1 直接父子关系被误判为分离

若 A、B 自由，M=f(A,B)：

```text
Anc(A)=∅, Anc(B)=∅, Anc(M)={A,B}
```

每对祖先交集都为空，所以原分离度 B=1。中点定义下的 MAB 共线仍约 70.64 分。问题与 f 的具体定义无关。

### 3.2 多输入关系被大量无关点对稀释

对 A、B、C、P、Q=f(A,B,C,P)，十个点对中六个输入／输入点对没有祖先关系。原独立性比例为 0.6，原分离度仍为 1，总分约 75.24。真正应抓住的是 Q 直接把这些输入连接在一起。

### 3.3 绝对深度和共有祖先不合适

绝对深度会奖励参与对象共同上游的任意步骤，即使目标关系仍只是邻近对象的局部性质；另一方面，整个祖先集合的权重又会随上游数量改变，无法只关注最近的作图背景。

只给祖先集合补上自身仍不够：高元关系的点对平均会继续稀释父子联系，长链也会改变相似度。此次改为局部最短距离和整体连接跨度。

## 4. 当前模型

### 4.1 构造边的代价

一个输出直接引用 k 个不同父对象时，到每个父对象的边权为：

```text
w(k) = 1 + α log2(k), α=0.5
```

1 代表一个实际命名步骤；对数项温和计入输入数量，避免把二输入和几十输入完全视为相同，也避免参数数量使分数线性膨胀。

匿名嵌套统一按当前已有名称提取父节点。例如以下四个定义使用相同的图与分数：

```text
M=Midpoint(A,B)
M=(A+B)/2
M=f(A,B)
M=outer(inner(A),inner(B))
```

评分不解释 callee，不按 AST 长度计步。若用户先命名 U=inner(A)、V=inner(B)，再构造 M=outer(U,V)，则确实多了依赖步骤，可以增加分数。

只有纯引用恒等别名（X=A，包括解析后只是同一引用的括号形式）被折叠。未知的一元 f(A) 仍算一步；不能假定它是无意义包装。别名参数指向同一对象时，输入数量去重。

### 4.2 对象间的共同祖先距离

对 x 计算包含自身的最短上溯距离表：

```text
up(x,x)=0
d(x,y)=min_a [up(x,a)+up(y,a)]
```

a 遍历共同的上游对象，包括 x、y 自身，不含哨兵根。无共同对象则 d=∞。

- M 到父对象 A 是一步，解决空祖先盲点。
- 两个输出都直接来自 ABC，它们可经 ABC 的某个对象汇合，属于近距离联系。
- 上游再添加很深的公共历史，只要已有更近汇合点，就不会提高分数。
- 只沿父方向查找，不能因后来添加一个无关下游工具，就把几个原本自由的输入点连接起来。
- 非点对象同样有效，例如同一圆上的 P、Q 都直接引用 c，其距离为 2。

父输入数只是对“涉及多少东西”的近似。距离选择最便宜的共同上游路线，并不要求消去沿途全部侧输入，也不是真实的最小几何消元复杂度。

### 4.3 整个关系的连接跨度

对参与对象建立以 d 为边权的图，求最小生成树。若无法连通，则得到森林。

```text
L = min_生成树 T max_{edge∈T} d(edge)
```

L 是连起这些对象所需的最小瓶颈阈值。使用最小生成树而不是所有点对均值／直径有两个原因：

1. 对 Q=f(A,B,C,P)，可以沿 Q 的四条近边连通所有输入，不会被六个输入／输入点对的无穷距离抬高分数。
2. 用树的最大必要边而非平均值，避免许多近点把一个远端对象的联系稀释掉。

因此 AKD 中 K、D 均直接依赖 ABC，虽然不需要互相依赖，也可沿 K—A—D 的近边连接，得到低分。不需要知道 TriangleCenter 或 HarmonicConjugate 的定义。

### 4.4 映射到分数

```text
V = 100 × (1-exp(-max(0,L-1)/τ)), τ=8

无法连通时：V=100
少于两个不同对象：V=0
依赖信息不完整：V=min(V,50)
```

这一映射单调、平滑、封顶。减去 1 将单输入的一步联系作为最低跨度；α 控制宽度成本，τ 控制明确展开步骤造成的分数增量。当前参数使直接联系处于低分区，常见两三步构型适度提高，较深分支逐渐接近高分。

参数是启发式标尺，不是拟合出的客观常数。此次先验证偏好关系和不变量，不以“某条定理必须得到某个精确整数”为目标。界面分数相同也不代表数学难度相同。

### 4.5 不完整和循环

自由对象的父集合可以合法为空，但读取失败、部分解析和循环不是独立性的正证据。

拓扑遍历向下传播“依赖完整”状态；未能拓扑处理的循环及其后代、自引用、读取／解析不完整及其后代都标为不完整。仍使用已读到的边寻找近联系，同时以 50 为保守上限，解释中显示降级。此上限仅防止“信息丢了反而得到最高价值”，不表示 50% 置信度。

不将循环分量成员误计为独立点对。最短路径用非负边权，循环也能终止，不再依赖递归深度计算。

## 5. 实验结果

可运行 [评分实验脚本](../../../../../scripts/geogebra-relation-scoring.ts)：

```sh
node node_modules/vite-node/vite-node.mjs scripts/geogebra-relation-scoring.ts
```

该脚本只构造依赖图，不调用 GeoGebra 或证明器。几何构型名称不参与评分。结果：

| 依赖构型／评分对象 | 连接跨度 L | 价值分 |
| --- | --- | --- |
| 中点或任意 M=f(A,B)：A、B、M | 1.50 | 6.06 |
| 陪位中线：A、K、D，共同背景 ABC | 1.79 | 9.43 |
| 三个直接从 ABC 得到的中心：O、H、G | 3.58 | 27.61 |
| 中位线关系：AB∥MN，M=f(B,C)，N=f(A,C) | 3.00 | 22.12 |
| 在同一个命名圆上取出的四点 | 2.00 | 11.75 |
| Pappus 构型中同一输入直线上的三点 | 2.00 | 11.75 |
| Pappus 线：交点直接用嵌套 Line 表达式构造 | 4.00 | 31.27 |
| Pappus 线：先命名连接线，再取交点 | 6.00 | 46.47 |
| 从 ABC 分出三支，每支再明确增加四步 | 11.58 | 73.37 |
| 三个无共同上游的自由点 | 不连通 | 100.00 |
| 16 个输入及其一步黑盒输出 | 3.00 | 22.12 |
| 含缺失依赖且不连通的关系 | 不连通 | 50.00（上限） |

这些结果符合本轮偏好：任意黑盒直接联系也低分，局部三角形性质较平凡，展开步骤适度加分，深分支高于近联系，多输入没有被自由点对平均值主导。

自由三点关系的 100 分只表示“依赖图没有给出邻近联系”，**不表示坐标观测恒真，也不代表研究价值一定很高**。数值探索允许用户看到这种现象，随后通过拖动／经验继续判断；目前不强行将其归入证明验证流程。

等角共轭黑盒与反射点外心法另有结构偏好回归测试，但没有专用评分规则，也没有新增等角共轭检测器。

## 6. 数值构型与回归验证

[dependencyMetric.test.ts](../dependencyMetric.test.ts) 覆盖：

- 中点、未知 f、匿名嵌套形式的一致性。
- AKD 及两个共享三角形背景的输出。
- 多输入星形构造、侧输入数量、明确展开的步骤。
- 深分支、与目标无关的上游深度、恒等别名。
- 哨兵根和无关下游不得成为捷径。
- 大量近点不得稀释一个不相关点；改名、顺序、重复名称与无关对象不变性。
- 非点父对象、未知／部分依赖、自引用、循环及后代。
- 多路径的最便宜路线，并用分支 DAG 的穷举路径算法核对所有点对。
- 1200 步命名链，无递归栈增长。

[geometryRelations.test.ts](../geometryRelations.test.ts) 另外用坐标运行当前数值检测器，验证黑盒中点型共线、AKD 陪位中线、同圆点和 Pappus 线的发现与相对排序。Pappus 坐标由两条输入线上的点及直线交点计算，而非只给一个排序数字。

共线、共圆超过八点时，也验证关系组的全部位置参与评分。显示见证点仍最多八个；截断不得掩盖后面的远端对象。

当前使用几何位置代表评分，重合别名在发现后展开；不额外按名称数量刷分。

## 7. 实现与复杂度

依赖完整性与恒等别名在一次拓扑遍历中处理。每个被查询对象的最短祖先表用 Dijkstra 按需生成，当前分析内缓存；成对距离也缓存。关系组用 Prim 求最小生成森林。

单个祖先搜索约为 `O((V_a+E_a) log V_a)`；首次点对查询扫描较小的祖先表；m 个参与对象的 Prim 为 `O(m²)` 次距离查询。没有为每条关系重新构建完整祖先闭包。最坏缓存仍可能占二次空间，不能据此宣称大作图一定实时。

当前图每次刷新都会重建，缓存仅属于该图，不会跨定义变更误用。没有修改 custom 工具执行、来源持久化或项目格式。

## 8. 已知取舍与下一步

1. **结构代理会有误排。** 即使 f 的含义非常复杂，f(A,B,C) 与附近 ABC 的联系仍倾向低分；这是本次明确采用的高阶几何启发，不是遗漏语义识别。
2. **最短公共路线会忽略其他复杂分支。** 某个很近的共享输入可能让联系看起来简单，输入数成本只能部分缓和。不能把 L 称为完整消元代价。
3. **瓶颈不累计相似分支数量。** 很多对象若都可通过同样便宜的边相连，不会靠数量刷高分。这适合目前的关系组，但不是代数约束独立性的测量。
4. **组内不同命题被同一图联系串起。** 当前不按每个最小几何命题分别评分，某条高价值子关系可能被组内其他连接降低跨度。后续可研究按关键见证评分，但必须保持统一结构模型。
5. **重合点代表与候选预算仍有顺序效应。** 不同来源的同位置对象可能因选代表而影响分数；这是位置聚合层的问题。本轮保留检测器行为，不把几何重合误作纯引用别名。
6. **数值检测的召回与误差不由价值函数修复。** 现有方向簇、圆簇与 8000 候选上限继续存在；没有新增微扰检测。界面把原 Confidence 百分数改为 Match heuristic，并说明探索定位。
7. **参数尚需更多用户构型校准。** 可继续加入不同表示下的 Simson、Desargues、Miquel 等例子，比较局部性质、展开步骤与较长依赖的偏好；不要只为一个等角共轭案例调参。

后续优先扩大常见构型的评分样本，再考虑相等角度、等长等数值关系。新类型只要提供参与对象便能复用当前模型，不必等待逐工具语义契约。自动证明与本轮评分设计独立推进。

## 10. 有向角的有效参与点修补（2026-10-20）

有向角发现器原来只用消项后的方向方程去重，却仍用原式的全部点评分。
例如 M=(B+C)/2 时，∡ABM=∡ABC（mod π）消去共同的 BA 方向后仅剩
dir(BM)−dir(BC)=0，约束的是 B、C、M。把独立自由点 A 继续计入评分，
会使依赖森林不连通，错误地得到 100 分。

现在以规范方向方程中非零项的端点作为 `scoringNames` 和 `support.effective`。
本例分数为约 6.06，与 B、C、M 的一步局部联系一致。原始角式、全部参与点、
已消掉但仍须非零的边保留，A 记入 `support.frame`；不改变角的模 π 语义，
不删除可供用户选择的性质，也不约掉倍角的整数因子。

此处理只做符号同项消去，不因数值方向相等就合并不同直线。B、C、M 若全是
独立自由点，观察到它们共线仍可得到高分；两组独立点的等角关系也维持原评分。
回归覆盖中点命令、算术表达式、同依赖黑盒、旋转、输入顺序、保留原式与非零
条件，以及独立几何关系。关闭共线／中点显示不影响这项修补。
