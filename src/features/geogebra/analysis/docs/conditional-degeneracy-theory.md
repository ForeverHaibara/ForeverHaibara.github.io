# 条件退化、有效支持集与关系族

2026-10-19 形成的研究与设计提案。随后已实施射线商、有效支持与有限角色族等首批能力，实际范围见 [实现记录](./conditional-degeneracy-implementation.md)；本文的通用消元／维数理论仍含后续目标。配套 [实施计划](./conditional-degeneracy-plan.md)、[验收构型](./degeneracy-casebook.md)。

## 1. 核心判断：剩下多少位置，比“是否有无穷多个位置”更重要

将对象分成固定的核心 A 与考察其自由度的角色 Y；背景几何事实为 H，待发现关系为 F。在固定核心后研究：

```text
M(A) = {Y：H(A,Y) 成立且各几何量有定义}
Z(A) = {Y∈M(A)：F(A,Y) 成立}
```

要区分四件事：

| 情形 | 意义 | 建议处理 |
| --- | --- | --- |
| F 中的 Y 经合法约化完全消失 | Y 只参与原始写法或参考系 | 回到较小核心；Y 不应抬高价值 |
| 已知 H 后，F 对整个允许域恒成立 | 没有新增约束 | 默认折叠，保留来源、定义域与展开入口 |
| Y 仍被限制在一条线／一个圆等轨迹上 | 连续但非平凡的条件 | 保留轨迹上的新信息，可将复合结论归入关系族 |
| 只在若干已观测 Y 上成立 | 有限见证，尚不知一般规律 | 可以打包；不能写成“任意 Y” |

**连续解不自动意味着退化。** 四点共圆时，固定三点，第四点本来就有一维自由度；这仍可很有价值。高阶构型中，可任取的辅助点背后也可能隐藏一个值得显示的特殊核心，不能把整条发现一并删除。

建议统一使用“背景核心＋剩余条件＋见证族”，而不是给所有“非有限解”统一降分。

## 2. 四个例子的精确拆分

### 2.1 共线与角：必须保留射线的方向

对普通角 ∠ACD、∠DCB，顶点都为 C。

- 若 A、B 位于 C 的同一侧，CA、CB 是同向射线。两个角对任意 D≠C 相等。信息来自 A/B/C 的位置，D 不增添约束。
- 若 C 位于 A、B 之间，两射线反向。这时两个角互补至 π；相等还要求 CD 垂直 AB，D 只可沿过 C 的垂线取值。
- 有向角不能直接套用普通角交换端点的对称性，mod π 与实际射线方向也不能混为一谈。

因此应共享“支撑线”，但普通角还要保留射线的正反相位、顶点及非零射线条件。同线不等于同射线；同一支撑线也不允许把所有角都换成锐角。

一个合适的原始约化是：

```text
普通角的端点交换规范化
＋ 同向射线的几何替换
→ 两个角成为同一个量
→ 差为零，D 从关系的有效支持集中消失
```

相反相位则约成 `2∠ACD=π`，而不是零关系。不能删除其中的 D。

### 2.2 公共分母：定义域支持与信息支持不同

```text
AB/BD = BC/BD  ⇔  AB = BC，条件 BD≠0
```

只要 AB=BC 已知，D 可以在除 B 外的全平面取值。这里甚至不需要“B 是 AC 中点”的全部条件，AB=BC 就够了。

D 已不参与新的等式，但仍参与原式的非零分母条件。建议区分：

- **有效支持** A/B/C：承载等式的信息；
- **定义域支持** B/D：用于确认原式有定义；
- **参考／框架支持**：只为生成模型选基、归一化而出现的对象；
- **展示支持**：原见证的全部对象，供回看、筛选和联动。

如果 AB=BC 尚未作为观测记录，则应保留或生成这条较小核心结论，不能仅把四点关系标为平凡后丢弃。

### 2.3 中点与全等：留下的是中垂线条件

取 A=(-1,0)、B=(0,0)、C=(1,0)、D=(s,t)，对应 A↔C、B↔B、D↔D。SSS 比较分解为：

```text
AB²−CB² = 0                 背景已知
BD²−BD² = 0                 同一个量，恒等抵消
AD²−CD² = 4s                剩余条件
```

故非退化三角形全等的剩余条件为 s=0、t≠0。D 有一维自由度，但不可以任取于全平面。应当展示“D 位于 AC 的中垂线上”，并把对应全等作为该条件和背景的复合表达。

更一般地，全等所需的背景只是 AB=CB；并不必须先知道 B 在 AC 上。中点是足够条件，不是最小必要背景。

这给出统一处理方式：复合比较器输出各个原始条件，消去共享量、约去已知背景，再查看还有什么条件。它不依赖识别 `Midpoint` 命令或为每种宏工具建立规则。

### 2.4 九点与第十点共三次曲线：存在性见证可以随点改变

这里的关系是“存在一条非零三次曲线经过这些点”，而不是“第十点位于某一条已经固定的三次曲线上”。两者自由度完全不同。

经典 Cayley–Bacharach 情形可从两条无公共分量、相交于九个不同点的三次曲线 F、G 出发。对任意不在公共零点的 Q：

```text
C_Q = G(Q)F − F(Q)G
```

是非零三次多项式，经过九个固定点和 Q。若 Q 为公共零点，直接取 F 即可。这里允许可约／奇异曲线；若关系要求光滑、不可约，不能照搬“任意 Q”。经典背景与条件可参阅 [Ren、Richter-Gebert、Sturmfels 的原始论文](https://arxiv.org/html/1405.6438v2)。上述任意 Q 的线性组合论证是这里用于设计的直接推导。

更统一的视角是线性参数族。设曲线使用 M 个基函数，点的评价矩阵为 E，非零曲线存在等价于 `rank(E)<M`。若固定点矩阵秩为 r、核维数 k=M−r，那么附加 q 个任意点最多再增加 q 个线性条件：

```text
q < k  ⇒  附加这 q 个点后仍有非零曲线
```

平面三次齐次多项式有 M=10 个系数。九点核维数至少二时，第十点完全自由；普通九点的核维数通常为一，第十点必须位于相应的唯一曲线上。

这里按非零齐次三次形式理解“曲线”；仿射表达可为总次数至多三，齐次化后允许无穷远分量。若产品要求严格仿射次数或特定曲线类别，还需额外条件。

这里是参数族中**存在量词的过剩容量**。可以用通用评价矩阵／核空间处理，不必为 Cayley–Bacharach 名称硬编码。当前并没有高阶曲线检测器，本条是架构应预留的例子。

### 2.5 零因子：不能把非零分支的消元套到退化分支

未来叉乘／面积等量会出现：

```text
u(A)·v(Y)=u(A)·w(Y)
⇔ u(A)·(v(Y)−w(Y))=0
```

在 `u≠0` 分支，剩余条件为 v=w；在 `u=0` 分支，Y 可以完全无关，核心信息只是 u=0。例如 u 是 ABC 的叉乘，ABC 共线就使整族乘积等式自动成立。

这不是只靠统一 log 群就能处理的情况：零不在乘法群里，需要先分零／非零层及定义域，再进入群上的消元。误把零因子约掉会捏造 v=w，反过来将大量 `0=0` 当作新关系又会污染模型。数值近零但分支不稳定时应保留不确定性。

## 3. 条件自由度的理论模型

### 3.1 不以任意核心为“泛型基线”

对于投影 `(A,Y)↦A`，先看哪些 A 存在可行 Y，再比较可行核心上的典型纤维。不能把一般不可行的核心与特殊可行核心相比，宣称后者出现了巨大自由度跃升。

例如共享 B/D 的全等例子要求 AB=CB。对不满足它的核心，根本没有 D；在满足它的可行核心上，D 通常本来就沿中垂线运动。中点位置未必再带来纤维维数增加，仍可通过剩余条件分解识别冗余。

存在稳定、可比较的泛型基线时，才记录：

```text
excessFreedom = 特殊核心上的纤维维数 − 同类可行核心的典型纤维维数
```

基线未知时应返回 unknown，而不是假定为零。

### 3.2 正则位置下的条件约束增量

令 J_H、J_F 为对自由角色 Y 的雅可比。在有关约束集合为正则流形、秩在邻域内适当稳定时，可用：

```text
c_new = rank([J_H; J_F]) − rank(J_H)
dim M = dim(Y) − rank(J_H)
dim Z = dim M − c_new
```

描述切空间层面的新增约束。它是条件增量，而不是直接数有几条等式；例如共享边的 SSS 有若干恒等式，不能机械算成三个独立约束。

但**单点的数值秩不是纤维维数的证明**：

- x²=0 在零点导数为零，实际仍要求 x=0。
- 实平面上 x²+y²=0 只有原点，梯度为零并不表示有二维可动空间。
- 包装成平方残差会改变雅可比秩，却不改变关系零集。
- 角度折返、近零分母、曲线奇点都可能令差分诊断失真。

雅可比方法只在合适条件下使用；正则性与维数的边界可对照 [Artin 的课程讲义第 5.2、5.6 节](https://math.mit.edu/classes/18.721/notes/ag-dec22-2021.pdf)。本项目面向实数值几何，不能直接套用复代数维数来判定实点自由度。

### 3.3 对称性不能作为一律降分的理由

所有点共同平移／旋转会保持许多关系，这不是某个辅助点的冗余。固定核心后，只考察允许变动的角色；或者明确商去关系本身允许的整体群作用。

三个新顶点组成与固定三角形相似的三角形，可以有四维相似变换自由度，这属于该关系的正常自由度。绝对长度关系又不能随意商去缩放。

构造依赖图中的可动自由度也与几何关系的条件自由度不同。冻结其它坐标后试动一个构造点，可能不符合原作图指令；因此不能把几何探测结果说成 GeoGebra 实际可拖动性。

### 3.4 全维也不等于全域：还要考虑分支与不等式

固定 A=(0,0)、B=(1,0)、C=(0,1)，普通角关系：

```text
∠BAD + ∠DAC = ∠BAC
```

对第一象限内任意 D 成立，局部有二维自由度，但对全平面的任意非零 D 并不成立。雅可比增量可能为零，却仍包含“射线 AD 位于相应角域内”的位置条件。

距离的绝对值、普通角折返和符号选择使问题自然具有半代数分层／分支结构。不能仅凭“维数等于环境维数”就宣布完全任意；还要区分局部开集、连通分支和完整允许域。若把角域限制纳入 H，该等式才是在这个 H 下的恒等式。

## 4. 统一的“最小信息核心”

建议把每条发现视为：

```text
原始谓词／存在性关系
→ 带角色、对称性和定义域的几何表达式
→ 在已观测背景 H 下规范化
→ 核心条件 K ＋ 剩余条件 R ＋ 定义域守卫 U
```

目标不是一次求出全局唯一、绝对最小的支持集。最小核心可能不唯一，全子集搜索也不可承受。先求预算内、可解释且能回溯的较小支持，并保留候选替代支持。

支持约化针对的是**某条关系**，不是从场景中删除对应量。`∠ACD=∠DCB` 约成恒等式后，代表角本身仍随 D 变化；它若又与另一个构型的角相等，后一个关系可能含有新的跨构型信息，仍要保留 D 及该比较。等值类内部的别名约化不能把整类的外部关联一并清空。

从代数角度，多项式关系可以考虑背景理想、根理想及带非零条件的局部化；当前有理行空间只覆盖选定量上的线性消元，不等于上述完整问题。第一阶段使用共享量抵消、受守卫的分式约分、射线／载体替换和比较器分解，之后才考虑有界低次多项式模块。

代数 matroid 的独立性／最小依赖思想可供“寻找小核心”借鉴，见 [Rosen、Sidman、Theran](https://arxiv.org/abs/1809.00865)。但含近似误差、多个分支和奇异层的当前快照，不自动构成一个可直接用并查集实现的全局 matroid。

## 5. 重复形态：与 f 的具体公式尽量解耦

把关系实例记录为带角色的超边，例如 `f(A,B,C,D_i)`。索引键包括谓词类型／模板、角色位置、允许的对称置换、固定角色绑定和少量可变角色孔。

这可以通用地发现重复核心，但需要保守解释：

1. 多个 D_i 成立只能提名一个关系族，不能推出任意 D。
2. 原搜索可能偏向某些点、来自同一构造或已被预算截断；出现次数不是独立统计显著性。
3. 相同无序点集不意味着相同角色。全等的顶点对应、有向角顺序必须保留。
4. 两个自由角色只能默认保存已验证的绑定元组；不得把 `{(D,P),(E,Q)}` 擅自补成笛卡尔积。
5. 若若干见证恰好共线，仍不说明 f 在整条线上成立。仅拟合轨迹和验证“沿轨迹可生成 f”是两件事。

安全的首层打包是 `f(A,B,C, D∈{D₁,D₂,…})`，其中花括号表示已经验证的有限列表。得到结构约化证据后，才可升级为“轨迹上的一个条件生成全部这些实例”或“在允许域内不依赖 D”。

关系族与等值类不同：D₁、D₂ 不必重合或有相等数值，只需要在同一角色结构下满足相同形式的关系。

## 6. 证据等级与处理策略

| 等级 | 证据 | 可做什么 |
| --- | --- | --- |
| 表示恒等 | 同量、同载体／同向射线替换及合法消项 | 去掉纯恒等写法，保留守卫 |
| 条件约化 | 基于独立背景的可回溯化简／比较器分解 | 显示核心与剩余条件，折叠已覆盖子结论 |
| 秩／参数容量 | 有明确矩阵或参数族，数值秩稳定 | 给出附条件诊断；高阶族将来接入 |
| 角色重复 | 多个实际见证共享模板与核心 | 打包观测，不宣称普遍成立 |
| 局部试动 | 多方向、多尺度、离开当前点的脱离式采样 | 增强或反驳候选，不凭此永久删除关系 |

“结构约化”指给定已接受的数值背景后的表示推导，不是对原作图的形式化定理证明。背景误差、守卫与来源仍必须传播。

特别要防止循环归因：不能先由一个全等结论登记对应边相等，再用这些子等式把该全等自己判为无新增信息。互相等价的表达式应选一个代表，不应循环互证后全删。

H 是有来源、受预算约束的几何背景，不是把当前全部坐标值都作为代数常数加入“知识库”。否则任何当前成立的观测都可退化为常数等式，分析失去意义。自动发现的小核心也不等于用户早已熟知；应先保留核心，再折叠其派生表达。

## 7. 价值与展示必须分别处理

建议保留四个支持字段：原始见证、有效条件、背景／定义域、纯参考框架。全量见证继续用于联动；只有与新增条件有关的真实构造对象参与其价值判断。

- 被完全消去的 D 不得因是独立自由点而把分数抬到 100。
- 若关系退回一个尚未记录的特殊核心，按该核心评分并保留它；不是整体零分。
- 若 D 仍需在一条轨迹上，则按新的轨迹关联信息评分，不因一维自由度统一打折。
- 关系族的出现次数只表示覆盖量，不直接加分。初始聚合可取新条件成员价值的最大值，另列覆盖数；不把所有重复实例的支持并集再评分。
- 仅凭重复／试动得到的怀疑只作诊断或排序辅助，不作硬隐藏条件。

“在背景下没有新增约束”也不等于“这种表达没有展示价值”。全等与其 SSS 条件可以承载相同信息，但全等往往更易理解，应允许它作为主摘要、对应边作为展开内容。仅当退化背景让它实际退回一个很小的条件时，再突出该条件；不能借此把所有全等都替换成三条等长。

当前 generator 标题的 `dim` 仍表示生成元个数；不能将它悄悄改成这里讨论的几何自由度。展示方程数、生成约束秩、见证数、生成元数与条件自由度分别记录。

最终原则是：**商掉已知背景制造的重复表达，保留背景核心本身，以及剩余角色仍需满足的新条件。**
