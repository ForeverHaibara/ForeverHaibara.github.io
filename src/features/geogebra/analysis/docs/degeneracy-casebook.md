# 条件退化分析：验收构型与反例

2026-10-19，配套 [理论说明](./conditional-degeneracy-theory.md) 与 [实施计划](./conditional-degeneracy-plan.md)。以下是未来实现的验收设计，不表示运行代码已经具备相应能力。本轮仅对第 9 节矩阵样例做了独立整数计算，未新增运行测试代码。

每个构型分别检查：原关系是否成立、可消去哪些角色、必须保留什么条件、评分是否受无关对象影响、候选量是否减少。不能只检查输出条数。

## 1. 共线且同向：辅助射线任意

```text
A=(-2,0), B=(-1,0), C=(0,0), D=(s,t)≠C
F: ∠ACD=∠DCB
```

CA、CB 同向，普通角端点可交换，所以 F 对所有合法 D 成立。

- 在各象限及轴线上取不同 D，原角相等；D=C 则角无定义。
- 支撑线和射线约化后只保留同向背景，D 不参与该结论的信息评分。
- D 是独立自由点，也不能把这个背景的分数抬到 100。
- 把 B 移出直线后，等式一般不再对任意 D 成立；不能把一次共线约化缓存到新快照。
- 在同一射线上增加许多端点，不应按全部端点对重复评价同一个角。

再引入另一构型的角 α，使 α 恰等于当前 ∠ACD。射线别名恒等式可以消失，但 `α=∠ACD` 仍可能是新信息；代表角及 D 不能因前一条恒等式而全部删除。

## 2. 共线但反向：仍有垂直条件

```text
A=(-1,0), B=(1,0), C=(0,0)
D=(0,2) 或 D=(0.3,2)
F: ∠ACD=∠DCB
```

CA、CB 反向，两角互补。第一个 D 给出两个直角；第二个 D 不满足等角。

- 原关系只在过 C 的垂线上成立，不能删除 D。
- 可约成 `2∠ACD=π`，或 `CD⊥AB`；背景共线与新增垂直应分开。
- 普通角、mod π 有向角、mod π/2 方向帧不能混用同一条“端点等价”规则。
- 另用 30° 与 150° 的角对，验证射线压缩没有把补角当成相等。

## 3. 中点与公共分母

```text
A=(-1,0), B=(0,0), C=(1,0), D=(s,t)≠B
F: AB/BD=BC/BD
```

两侧都等于 `1/√(s²+t²)`，但关系实际只说 `AB=BC`。

- 记录等式支持 ABC，非零分母守卫支持 BD。
- 若 AB=BC 已被独立记录，原式作为派生见证；若未记录，则保留较小的等长核心。
- D=B 时原式没有定义，不能用交叉相乘后的 `0=0` 接纳它。
- 改用 B=(0,2)，A/C 不变，仍有 AB=BC，公共分母仍可消去；说明处理不应依赖“中点”模板或指令名称。
- 令 B=(0.2,0)，则 AB≠BC，合法 D 上原式应不成立。

评分对照使用两种作图依赖：D 为无关自由点，或 D 为很深的远端构造。约化后的等长核心分数应一致。

## 4. 生成模型：不能只改展示

以第 3 节构型增加若干合法辅助点 D₁、D₂、D₃，并记录：

```text
AB/BDᵢ=BC/BDᵢ
```

期望只有一个等长核心及若干折叠见证，不能产生三个新增几何条件，也不能因辅助点增多而提高核心分数。

另测：

```text
AB/AB=1
AD/AB=AD/AB
EL/AB=(1/2)(EF/AB)
```

前两条为合法域内的恒等表达；第三条应约成 `EL=(1/2)EF`。AB 是原式参考量，不能只因选基出现就进入第三条的价值支持。

反向保护：同一模型若还有一条确实涉及 D 的非恒等条件，不能因其它行消去了 D，就把 D 从整个模型一律删除。模型标题的对象来自剩余信息行；原始选基和所有见证仍可展开。

## 5. 共享两顶点的全等

```text
A=(-1,0), B=(0,0), C=(1,0), D=(s,t)
F: △ABD≅△CBD，对应 A↔C、B↔B、D↔D
```

比较平方边长得到 `0、0、4s`。非退化情况下 F 等价于 `s=0、t≠0`。

- D=(0,2)、(0,-3) 均满足；D=(0.2,2) 不满足。
- 若只知道 AB=CB，必须保留 AD=CD 这一新条件，并可解释为中垂线轨迹。
- 若 AD=CD 也由独立来源已知，全等可以折叠为复合见证。
- t=0 时三点共线；原三角形关系不能因 SSS 数值满足就通过合法性检查。
- 改用 B=(0,2)，D=(0,3)，仍可全等；中点不是必要背景。
- 全等自己登记的对应边相等，不能反过来成为删除自己全部信息的独立来源。

加入多个在中垂线上的 Dᵢ，可以打包全等见证及各自已验证的 ADᵢ=CDᵢ。即使见证共线，也不能仅凭共线拟合宣称任意线上点都全等；需要剩余条件的结构分析。

## 6. 连续自由度仍有价值

### 固定三点后的共圆

```text
A=(1,0), B=(0,1), C=(-1,0)
D=(cos θ,sin θ)，排除与 A/B/C 重合
```

D 有一维连续自由度，但共圆确实限制了它。把 D 移出单位圆，关系应失败。不得因“非有限个位置”将其当作全平面任意或统一降分。

### 相似与全等的正常群作用

固定一个非退化三角形，另一组不共享顶点的三角形可通过平移／旋转保持全等，通常有三维连续自由度；相似允许再缩放，通常有四维。镜像是额外离散分支，不增加连续维数。

这是关系自身正常的自由度。应与固定大部分角色后、某个辅助角色完全消失区别开来。改变所有点的整体坐标系，也不能算作某个点是冗余角色。

## 7. 通用关系族的安全边界

先使用抽象模板 f，不要求知道 f 是共圆、全等还是未来的高阶关系：

| 输入 | 可显示 | 不可推出 |
| --- | --- | --- |
| f(ABC,D)、f(ABC,E)、f(ABC,F) 均验证通过 | f(ABC, {D,E,F}) 的有限见证族 | 任意点都可替代最后角色 |
| 通过的 D/E/F 又恰好共线 | 附记实际点集的共线背景 | f 在整条直线上成立 |
| 两孔实例只有 f(ABC,D,P)、f(ABC,E,Q) | 绑定列表 {(D,P),(E,Q)} | f(ABC,D,Q) 或 f(ABC,E,P) |
| 同一无序点集，顶点对应不同 | 各合法对应的规范化实例 | 任意置换都等价 |
| 搜索只访问了部分候选 | 明示检查覆盖和截断 | 未访问实例不满足 |

另构造大量由同一个工具生成、相互相关的 Dᵢ。出现次数不能被解释为独立采样的显著性，也不能直接转化为普遍成立的置信概率。

对重叠族验证：一个实例进入多个候选族后，其未被其它结论覆盖的条件仍可到达最终输出，不因展示覆盖算法而丢失。

## 8. 数值秩与试动的反例

| 残差／环境 | 容易犯的错误 | 预期 |
| --- | --- | --- |
| x²=0，在 x=0 | 导数为零，所以 x 自由 | 实际仍要求 x=0；秩诊断返回不充分 |
| x²+y²=0，在实原点 | 梯度为零，所以有二维解 | 实零集只有一个点 |
| 把正常残差改写为其平方 | 零点雅可比变小，所以几何条件减少 | 关系零集未变；应使用合适原始残差或弃权 |
| 只沿候选轨迹采样 | 全部通过，所以全平面成立 | 必须区分轨迹域与环境域，并做离轨对照 |
| 近零分母、角度折返点 | 差分很小／很大即代表约束秩 | 检查守卫、分支与尺度，无法稳定时 unknown |
| 构造点坐标被脱离式试动 | 用户可在原作图中这样拖动它 | 只说明纯几何谓词的坐标依赖，不说明黑盒构造可动性 |

补充全维但非全域的例子：A=(0,0)、B=(1,0)、C=(0,1)，`∠BAD+∠DAC=∠BAC` 在第一象限内的 D 均成立，在其它角域一般不成立。局部二维自由度不能抹去角域限制。

补充零因子例子：`cross(AB,AC)·DE=cross(AB,AC)·FG`。ABC 共线时即使 DE≠FG 也成立；非共线时才可约成 DE=FG。近共线、数值分支不稳定时不能强行选择任一解释。

测试中监视 GeoGebra API：诊断不得调用实际移动、赋值和新建对象命令。快照版本变化后，旧诊断不能污染新结果。

## 9. 参数容量与三次曲线：已核对的精确样例

用仿射基函数：

```text
[1,x,y,x²,xy,y²,x³,x²y,xy²,y³]
```

其非零线性组合表示总次数至多三的多项式，齐次化后对应射影三次形式，允许可约／奇异及无穷远分量。若未来产品要求严格仿射三次、光滑或不可约，必须另外定义并检查，不能直接用以下秩判据代替。

### 9.1 九点留下二维核

九点为网格 `{0,1,2}×{0,1,2}`，由齐次三次曲线：

```text
F=X(X−Z)(X−2Z)
G=Y(Y−Z)(Y−2Z)
```

给出九个不同公共点，且 F/G 无公共分量。评价矩阵九行秩为 8，核维数为 2。加入 Q=(3,4) 后十行秩为 9，仍有非零曲线。

在 Q 处 F(Q)=6、G(Q)=24，因此 `4F−G` 经过全部十点。不同 Q 可以选不同曲线；并不是第十点都在某条固定曲线上。

期望识别“九点核心导致参数容量增加”，将任意附加点的存在性关系作为见证折叠，同时保留九点核心的特殊性。不能把全部发现归零后丢掉核心。

### 9.2 泛型九点不允许任意第十点

使用整数点：

```text
(0,0), (1,0), (0,1), (2,3), (3,2),
(−1,2), (2,−1), (4,1), (1,5)
```

九行矩阵秩为 9。加入同一个 Q=(3,4) 后秩为 10，不再存在非零三次形式通过全部十点。两组样例的九点／十点矩阵秩均已用 BigInt 整数消元独立核对，没有使用浮点阈值。

更一般地，至多八个点本来就给十维系数空间留下至少二维核，因此任意第九点仍存在曲线。这是关系类型自身的参数容量，不应作为特殊核心的高价值发现。

### 9.3 数值边界

未来测试加入对网格一个点的不同尺度扰动，并同时记录奇异值间隙。非常小的非零扰动可能在浮点阈值下与精确秩下降难以区分；不预设所有扰动都会给出可靠的同一数值分类。

应返回秩区间／不确定状态，保留原观察而不强行宣称附加点任意。理论背景与适用假设见 [理论说明第 2.4 节](./conditional-degeneracy-theory.md#24-九点与第十点共三次曲线存在性见证可以随点改变)。

## 10. 一致性与性能验收

对以上构型做名称置换、输入顺序变化、坐标平移旋转、合理范围缩放、显示类型切换及预算截断对照。

- 原关系、约化核心与剩余条件的数值成立性相符。
- 新增任意辅助见证不改变已有核心分数或虚增生成维数。
- 守卫未满足时不接纳原式，未知核心和新增轨迹条件不丢失。
- 输出的所有普遍性措辞都能追溯到足够的结构依据；有限列表始终是有限列表。
- 同向共线端点增多时，记录商前／商后角量和评价次数，验证源头压缩。
- 比较模型约束秩、展示方程数、原始见证数，避免只把冗余藏到另一层。
- 数值探测预算不足、奇异、不稳定时安全返回 unknown，界面仍可浏览原观测。

这些构型应逐阶段变成有意义的回归测试和基准，而不是一次性用大量快照锁死当前展示字符串。
