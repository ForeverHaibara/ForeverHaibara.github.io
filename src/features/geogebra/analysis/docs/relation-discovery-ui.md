# 发现面板：计算、显示、筛选与价值颜色

状态：完整交互目标。2026-10-19 已交付计算／显示开关、自动／单次／停止、预算档位、显示筛选及统一分数配色；更细的类型进度、范围预设等仍待实施，详见 [当前实现](./generator-spaces.md)。对应 [扩展计划](./relation-discovery-plan.md)、[架构](./relation-discovery-architecture.md)。

第二批已交付五个可折叠类别，以及全局／分类、计算／展示各自的 All／None／Invert 控件；偏好迁移和行为规则见 [第二批实现记录](./algebraic-relations.md#6-分类及批量控件)。

关系正文现保留完整等值簇；生成模型省略参考／基恒等式、合并等值与倍率链，方向展示使用 ∠ 并保留 π 分支。详见 [聚类与约简展示](./clustered-presentation.md)。

## 1. 当前问题与目标

最初版本按关系类型选择整个分数徽章颜色：共线为淡黄、垂直为紫色等。这会让人把颜色理解成价值等级，类型增长也会耗尽易区分的颜色。首批实现已改为所有类型共享的分数蓝色色阶；下文保留完整交互目标。

调整原则：**分数徽章只编码分数，类型只用文字／符号表达。** 所有类型共享同一套分数色阶。类型、选中、高亮、计算状态和数值质量分别有自己的显示位置。

## 2. 面板布局

兼容当前约 280–560 px 的侧栏，不新增宽大的常驻设置区。推荐结构：

```text
Discovered relations             [自动运行 开] [运行一次] [停止]
数值探索 · 当前快照 · 已完成 7/8 类型 · 1 类型达限

[计算与显示 ▾]  [标准预设 ▾]
  类型             计算   显示   状态／数量
  点重合            ☑     ☑      完成 · 2
  长度相等          ☑     ☑      完成 · 6
  角度相等          ☑     ☐      完成 · 12
  比例组合          ☐     —      未启用

[类型筛选 ▾] [涉及所选对象 ▾] [最低价值 0 ─── 100]
[搜索对象或结论…]                      [按价值 ▾]
显示 18 / 已发现 32 组                 [清除显示筛选]

[∠ 角度相等]  ∠ABC = ∠DEF                    [价值 64]
  涉及对象…  数值误差…  依赖说明…
```

计算与显示表默认折叠，只显示当前预设和开启类型数量；展开后按“基本／角度／长度与比例／面积／构型”分组。关系列表使用注册目录的标签和格式化器，不在组件中为每种新增类型硬编码 JSX。

面板整体可继续承载未来其他分析模块，但当前发现区域明确标明数值探索，不与自动证明的成功／失败状态混排。

## 3. 三种控制必须分开

| 操作 | 数据含义 | 是否触发几何计算 |
| --- | --- | --- |
| 某类型“计算”关闭 | 不安排该类型的新候选、复核和评分，取消该类型在途任务 | 是，更新计划；仅重排受影响任务 |
| 某类型“显示”关闭 | 保持计算，当前结果不出现在普通列表 | 否 |
| 类型／对象／分数／文本显示筛选 | 过滤已计算的 family | 否 |
| 改变容差、搜索范围、比例常数集或预算 | 改变实际检测问题 | 是，产生新请求 |
| 改变排序、展开折叠或 hover | 展示与临时交互 | 否 |

### 3.1 类型计算与显示状态

- 计算开＋显示开：正常运行并展示。
- 计算开＋显示关：继续计算和缓存；计入“已发现”，不计入当前“显示”。
- 计算关：该类型标“未启用”，显示开关暂不可用，但保留用户之前的显示偏好。普通列表不混入它先前的旧结果；缓存可保留供同快照重新开启时复用。
- 若关闭类型 A 后，B 仍需要某个共享方向／长度资源，该资源继续计算；说明文案为“仅关闭此类结论的计算”。不向用户暴露内部 DAG。
- 增加一个已实现类型时，从目录默认值与存储迁移得到其初始状态；未实现类型不显示可勾选框。

“清除显示筛选”不更改计算开关／容差／预算。“恢复标准计算设置”是另一项明确操作，不能让用户清除搜索文字时意外开启昂贵组合搜索。

### 3.2 自动、单次、停止与旧结果

默认自动运行，沿用拖动结束刷新／更新防抖的习惯。关闭自动后，作图变化仅把旧结果标为“来自上一快照”；直到运行一次才更新。折叠面板只折叠，不暗中更改计算设置。

“停止”取消当前任务并暂停后续自动调度，等价于关闭自动；保留已完成结果及它们的快照标签。重新打开自动或点击运行一次才能继续。执行中“运行一次”按钮改为“重新运行”，明确取消旧请求后重启。

类型状态至少覆盖：未启用、等待、计算中、完成、已达预算、缺少输入、失败。过期是结果版本属性，不能伪装成“当前完成”。某类型失败不应清掉其他类型已完成结果。

## 4. 范围、对象筛选与高级选项

### 4.1 默认只做展示筛选

显示筛选可选择“全部”“涉及任一所选对象”“包含全部所选对象”。空选择时明确退回全部。选中使用 `ObjectLink` 的实际 selection，不使用 hover／focus 预览来反复触发筛选或计算。

对象过滤依据结果的完整原始支持集，而非仅显示出来的八个点名。虚拟线段／角显示来源对象 chips，沿用现有选择与键盘焦点联动，不为预览改变对象样式或创建几何对象。

### 4.2 计算范围是另一项高级设置

进阶搜索可选择“全图”或“涉及指定对象的关系”。后者冻结一次运行开始时的选择为计算 scope，并显示范围摘要；不是在每次鼠标移动时重跑。

受限搜索仍可以需要全图的基础长度／角索引来找到另一个未选对象组；其语义是“至少一个命题角色涉及选中对象”，不能把背景点全部删除后再声称穷尽局部关系。允许模板限制 partner pool 时，应明确标注更窄范围。

### 4.3 显示与计算的高级设置

- 显示：最低价值、包含／排除依赖不完整、平角／特殊常数关系的折叠、按价值／类型／误差排序、关联观测折叠。
- 计算：普通／有向角域、常数比例集、组合项数和预算预设。高级容差设置通过 domain 的参数解释，不能一个浮点 ε 同时控制长度、角度和圆心误差。
- 第一批不提供“置信度百分比”滑块。数值残差筛选若提供，应按同域的归一化误差比定义；值越低越好，但不等于概率。

## 5. 预设与持久化

建议两个主要预设及一个兼容入口：

| 预设 | 内容 |
| --- | --- |
| 标准探索（默认） | 原四种＋已实现的重合／等长／普通等角；阶段 C 完成后加入中点、小常数比与二倍角 |
| 深入组合 | 用户主动启用比例、加减、面积、有向角等已实现类型；仍有独立预算，不代表无限穷举 |
| 仅原有关系 | 原四种，便于性能对照与回归 |

用户改动预设任一计算项后显示“自定义”。选择预设明确覆盖哪些计算项；保留对象显示筛选和列表展开状态，避免不相关选项随之跳变。

发现设置使用独立、版本化的浏览器本地存储，例如 `geogebra-discovery-preferences-v1`，在 `analysis/preferences` 验证与迁移。**不并入现有 `GgbPreferences` 或 `PreferenceController`**，因为它们会把样式／视图偏好写给引擎，发现选项不应修改作图。

持久化计算类型、显示类型、预设参数和常用列表偏好；不持久化原始数值结果、在途请求、临时选择和展开见证。导入／清空切换文档 epoch、清除旧结果，保留用户发现偏好。无法使用本地存储时按默认值工作，不阻断发现。

## 6. 分数颜色规格

### 6.1 单一、有序、跨类型一致

采用五档蓝色明度／饱和度色阶，避免紫／金等稀有度联想；不是给类型分配五种颜色。初始候选 token：

| 显示分数 | 背景 | 文字 | 视觉含义 |
| --- | --- | --- | --- |
| 0–19 | `#eff6ff` | `#1e40af` | 很浅蓝 |
| 20–39 | `#dbeafe` | `#1e40af` | 浅蓝 |
| 40–59 | `#bfdbfe` | `#1e3a8a` | 中浅蓝 |
| 60–79 | `#2563eb` | `#ffffff` | 深蓝 |
| 80–100 | `#1e40af` | `#ffffff` | 更深蓝 |

token 是待视觉校验的起点，实施时检查实际字号下的对比度与明暗主题；若不合适，调整同一套全局 token，不为单一类型特设例外。

- 所有徽章显示“价值 N”，只读 `nonTriviality`，不读 `kind`。
- 先 clamp 到 0–100，再四舍五入成显示整数；颜色、可见分数档位和整数分数筛选使用同一显示整数，避免 19.6 显示 20 却仍用 0–19 档颜色。排序仍可使用原始分数。
- 未计算／数值不可用显示灰色“—”，不是 0。依赖不完整仍显示其已有封顶分数，另加中性状态文字，不偷偷改成另一套颜色含义。
- 默认不出现“普通／精良／史诗”等等级名；tooltip 解释为构造非平凡程度，不表示数学难度或观测可信度。

### 6.2 其他颜色各司其职

类型用中性灰底文字和可辨符号，例如 `∠ 角度相等`、`|AB| 长度相等`、`∥ 平行`。类型数量增加时不需要新颜色。

选中使用卡片边框／焦点环；预览使用细描边或下划线，不覆盖评分徽章。错误、预算提示、过期结果分别用文字／图标表达，状态色只出现在状态位置，不能把高分徽章染成“验证成功”的绿色。

颜色不是唯一信息：数值、类型文字和状态名称在灰度及色觉差异下仍能理解。键盘用户可聚焦控件和对象 chips；计算状态更新使用节制的 live region，不逐候选播报。

## 7. 列表、分组与空状态

- 等值类先显示一组及少量有代表性的量，不展开成 O(m²) 行等式。用户可展开成员和独立复核的见证。
- 对只有“均接近代表量”保证的组，按架构文档的星形关系显示，不能一律渲染为 `a=b=c`。
- 普通角用明确三点名；四线角和有向角附带约定。长标签使用分隔符与 chips，不把 `A_{12}BC` 等名称简单拼成有歧义的字符串。
- 类型关闭：“尚未启用此类型”；预算截断：“已搜索部分候选”；缺少实体输入：“当前缺少可读圆参数”；筛选为空：“有 N 组结果被当前筛选隐藏”。这些都不同于“没有发现关系”。
- 列表先采用可折叠分组和分页／限制渲染数；测量后再决定是否引入虚拟列表，不为类型扩展预先引入 UI 大依赖。
- 缓存结果与新快照不混装到同一“当前结果”列表。允许查看上一快照时单独标记，并避免对已删除对象继续发送选择请求。

## 8. UI 实施与验收顺序

1. 先抽出通用 `RelationScoreBadge` 与目录驱动的类型标签，移除当前 `colors[kind]` 对评分的控制；不改算法也能先修复视觉歧义。
2. 加入发现偏好 store、计算与显示控制，再将 view filters 从 runner 入参中隔离。
3. 加入每类型进度、预算和快照状态；再接入新的关系类型。

验收重点：同分不同类型同色；同类型高低分色阶递进；文字不依赖颜色；类型／分数／文本筛选不调用 detector；计算关闭确实取消该类任务；隐藏不取消计算；hover 不重算；停止不会立刻因下一个自动事件再次启动；导入后旧结果不冒充当前结果。
