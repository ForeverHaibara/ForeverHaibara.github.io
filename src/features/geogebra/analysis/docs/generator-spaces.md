# 生成关系与低复杂度关系空间：调整后的计划及首批实现

2026-10-19。本文件纳入对已提交扩展计划的反馈，并记录本轮实际代码。后续不能再把“枚举大量角／长度表达式，最后统一去重”作为主路线。

## 1. 优先级与总体路线的调整

1. **相似、全等提前**，与等角／等长一批实现，先于任意线段和三角形面积的加乘比例。全等作为相似的细化，复用形状索引与顶点对应，不重复生成同一结论。
2. **先发现少量生成关系，再约化候选**。把平行、垂直、共圆、相似／全等和有限整数拟合所得的约束登记到带来源的关系空间。角表达式先约化，再比较；不枚举某个簇内部所有角和式。
3. **从基础双线性形式出发**。向量点乘／叉乘统一长度平方、垂直、平行和有向面积；圆幂的二次式与极线的双线性式作为圆相关扩展的基础，切触是其特例。
4. **局部、可重叠的模型**，不是把所有点或线一次性并成一个全局等价类。按参考三角形的点星先查 O(n) 条线，允许某点在一个模型内、另一个模型外。
5. **计算、系数、存储及显示都要有预算**。达到限额降级为部分结果，不靠增加不受限的有理系数掩盖模型拟合失败。

这是数值探索。单构型中满足小整数关系，不等于证明恒真，更不意味着得到了客观的 Q-线性独立性或一个完整整数格。

## 2. 从“等价类”到“约束空间”

不同结构不能全用一个普通并查集表达：

| 结构 | 合适表示 | 不能丢失的信息 |
| --- | --- | --- |
| 真正的身份别名 | 原对象引用的商 | 对象来源与定义变化 |
| 近似等值 | 复核过的匹配边、直径受限的组 | 近似相等不传递 |
| 平行／垂直 | mod π 方向，经 mod π/2 分帧后保留相位 | 同帧不意味着平行，也可能垂直 |
| aθ₁+bθ₂+cθ₃+kπ≈0 | 稀疏多元约束与有理行空间 | 整数系数、π 分支、误差、来源 |
| 正量的乘除关系 | log 量上的同类加法约束 | 非零条件、量纲、常数与符号 |
| 局部生成模型 | 约束超图上的带作用域模型 | 可重叠成员及未被覆盖的连接 |

“小对称群的积／商掉对称性”提供了很有用的组织思路，但实际观察到的任意关系簇不一定构成独立群的直积。代码先用可检验的约束、生成描述和对称代表元表达，不预设没有验证的群分解。

### 2.1 周期角必须保留 lift

方向 θ 属于 R/πZ。在当前快照选取 θ∈[0,π) 后，将每条已检查的模关系记录成：

```text
Σ aᵢθᵢ − kπ ≈ 0
```

其中 k 是从当前实数 lift 核算出的整数。行空间把 π 作为固定常数列，不能把它当成可随意消去的未知量。

例如 2α−2β≡0 mod π，在 α−β≈π/2 的分支中实际登记的是 `2α−2β−π≈0`。有理消元得到 `α−β−π/2≈0`，而不是 α≈β。因此不会错误约去模群中的因子 2。换快照后重新核算分支，不永久沿用旧 lift。

普通角还需要射线顺序与折返分支，可写成 `s(θ₂−θ₁)+mπ`，s=±1。计算和规范化时保留它，不能把 30° 与 150°作为普通等角。

当前实现是**当前 lift 下的有理仿射行空间**，不是对整数关系模做饱和／Smith normal form，也不宣称得到完整 lattice。若未来需要严格整数格商与挠元，应增加独立的整数模层，不能把有理高斯消元冒充它。

### 2.2 O/H/I 与 G 的例子

以 AB 为方向参考，从 AC、BC 选择仍未被小系数表达的生成元。对每条候选线拟合：

```text
d·δ(l) ≈ a·δ(g₁) + b·δ(g₂) + cπ
δ(l)=θ(l)−θ(AB)
|a|,|b|≤4，1≤d≤4
```

先尝试常数或一个生成元，再使用两个；所以正多边形／特殊角构型可能只需 π 或一个方向生成元。

先检查 A/B/C 发出的点星，而非所有已有线两两夹角。某点 P 的 PA、PB、PC 都能描述时，把 P 列为该模型的 point cover；**不据此推定 PO、PH、PI 等连接也属于模型**。其他参考三角形可以得到不同、重叠的点星模型。

本轮不对任意多个独立生成元做全系数穷举。默认最多六个输出模型、最多十二个参考三角形尝试；这是有明确边界的启发搜索，不是完整子空间分解。

### 2.3 共圆如何提供约束

圆上点的弦方向满足带分支的 `θᵢⱼ≡(φᵢ+φⱼ)/2+π/2 mod π`。因此 n 个一般位置的同圆点形成的 O(n²) 条弦方向只需约 n 个原始方向参数；扣除整体旋转后约 n−1 个，并不意味着任意同圆四点都能落进某个二维模型。

实现利用已经数值发现的共圆点组，为锚点 A/B/C 与新增 D 登记圆周角约束，例如：

```text
θ(AD)−θ(AB)−θ(CD)+θ(BC) ≡ 0 mod π
θ(BD)−θ(AB)−θ(CD)+θ(AC) ≡ 0 mod π
```

新增点间的弦使用同类稀疏约束联系。每条约束仍从当前方向值复核，并保存 lift 和误差；不展开全部圆周角配对。

平行／垂直同样提供方向约束；相似／全等提供带顶点对应和镜像符号的角约束，及 log 长度的比例／等值约束。这些只是数值关系间的压缩依赖，不是新增自动证明系统。

## 3. 基础量的进一步下沉

`quantities/vector.ts` 已提供：

- 位移、点乘、叉乘、范数平方。
- 有向二倍面积 `cross(B−A,C−A)`；三角形面积是其特例。
- 圆幂 `|P−O|²−r²`。
- 极线评价 `(X−O)·(P−O)−r²`。
- 直线垂足处的圆幂 `distance(O,l)²−r²`，为零对应非退化线圆切触。

本轮已在外接圆和三角形退化检查中使用这些原语，并有零长度、圆幂／极线切线一致性的测试。**尚未把任意叉积／点积／圆幂等式、极线或切触注册成新的 UI 检测类型**；它们后续共享同一量与约束空间，而非各写一套特殊判断。

### 4.1 压缩、来源与价值

量表达式先在已登记约束中约化，相同形式只提供一份数值匹配代表。最终发布的等角仍对原始数值做范围复核，不能因符号形式相同就忽略观测误差。约束来源与误差随消元系数传播，超预算／误差放大时退回数值搜索。

默认隐藏已由当前观测生成的重复等角／等长。用户可开启“Expand derived observations”重新计算展开；这些子观测保留原始依赖基础分，并将展示价值乘 0.25，显示生成来源。这个折扣按“是否为已知生成关系的重复表达”生效，不按几何类型加分或减分，也不是证明可信度。

关闭某个输出类型，不要求其子类型一并关闭：只开相似仍会显示相似；等角检测也不要求方向模型／共圆／三角形类型同时开启。没有计算这些父观测时，子关系不依赖它们完成搜索，只是少了相应压缩机会。

### 4.2 当前预算与运行边界

默认上限为：基础点对 20000、三元组 8000、普通角 20000、各类比较 200000、方向模型 6、最终组 500；有理约束空间最多 128 行、每空间 200000 次系数操作、分数 192 bit。提供 Light／Standard／Deep 预设。

达到量／比较限额，结果显示 partial；代数运算预算用完，只停止进一步压缩，不将“没压缩到”误写成“独立”。最终组预算优先保留方向生成摘要，其余按价值排序截取，不承诺全局穷尽。相似／角三元组仍有确定性前缀范围；角生成按端点对轮转顶点，后续再改进更均衡的三元组采样。

Worker 令页面在密集数据下仍可停止，不等于每个数据集都满足 1 秒软目标；当前尚未加入按时间轮转的完整调度器、逐类型流式进度与局部增量缓存。同步回退不能在单个同步任务中即时响应停止，应优先使用 Worker。

## 5. 实验与验证方法

运行：

```sh
npm test -- --run src/features/geogebra/analysis --maxWorkers=2
node node_modules/vite-node/vite-node.mjs scripts/geogebra-discovery-benchmark.ts
node node_modules/vite-node/vite-node.mjs scripts/geogebra-discovery-benchmark.ts --scale
```

在非特殊三角形 A/B/C 的坐标构型中，ABC 模型用两个生成元加 π 表示 12 条线，point cover 为 A、B、C、H、I、O，G 不在其中。仅方向模型时，17 组等角可降至 3 组；再复用 Euler 线的共线载体后，当前最终版本不再逐条展示这 17 组等角，保留一个方向生成摘要及原有共线／垂直等观测。旋转、平移、换单位仍保持 O/H/I 与 G 的区分。该例的中心坐标由几何公式计算，测试没有根据 `TriangleCenter` 名字给模型特殊待遇。

另覆盖：跨模型的新等角不能被压缩掉，普通 30° 与 150° 不相等，镜像与缩放相似、同尺度全等去重、等边三角形的六阶对应代表、任意四点共圆的约束、近似链反例、π 分支、log 整数拟合、误差传播、存储损坏、对比色档位，以及原四种关系的回归。

一次本地标准预算实验的量级如下，耗时只是当前机器样本，不是性能保证：

| 位置数 | 散点 | 同圆密集数据 | 网格密集数据 |
| --- | --- | --- | --- |
| 20 | 约 0.06 s | 约 0.18 s | 约 0.28 s |
| 40 | 约 0.25 s | 约 0.78 s | 约 0.65 s |
| 80 | 约 0.45 s | 约 1.54 s | 约 1.57 s |

密集样本会触发角、比较或代数预算，80 点结果不能解释成全量枚举。性能表应随算法或默认限额改变重跑。

当前近似匹配采用确定性、直径受控的贪心分组，不求全部重叠团覆盖；容差边界附近可能漏掉某些跨组近似匹配。它保证已发布组经过复核，但不宣称最优分组或完整召回。

浏览器中另外验证了真实 GeoGebra 页面：隐藏等角时总结果数保持不变；关闭计算等角后总数减少；恢复选项后结果恢复。测试没有更改现有几何对象或用合成数据覆盖用户作图。

## 6. 后续计划

1. **先完善压缩覆盖和可解释性**：更均衡的参考三角形／三元组选择，限制可复用约束的误差放大，避免多个局部模型只是在重复换基。必要时保留不同局部作用域，而非强制全局合并。
2. **长度 log 生成模型**：复用当前精确约束核和有界枚举，以相似／全等、简单常数比为种子；先展示代表长度与生成描述，再考虑高项数比例式。
3. **叉乘／点乘关系族**：面积、平行、垂直、投影等作为双线性形式的受限模式。优先已有人用得上的构型，不默认枚举全部向量四元组。
4. **圆幂／极线**：取得可靠命名直线／圆参数后扩展二次型与双线性评价，切触作为特例进入目录。
5. **整数关系后端**：系数规模／秩确有需要时才接 LLL／PSLQ 类候选生成器。它们只生成候选，仍受输入精度、系数限额、原值复核和作用域约束，不自动给出真实性证明。

关于最后一点，参考 [fplll 的 LLL 接口](https://fplll.github.io/fplll/classLLLReduction.html) 与 [mpmath 的整数关系识别文档](https://www.mpmath.org/doc/current/identification.html)。GeoGebra 当前快照是有限精度数据；把双精度数字复制成高精度表示并不能增加有效信息，因此本轮先选用小系数枚举，不添加新的外部依赖。
