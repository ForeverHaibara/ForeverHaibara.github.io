# 条件退化：首批实现记录

2026-10-19。对应 [理论](./conditional-degeneracy-theory.md)、[计划](./conditional-degeneracy-plan.md) 与 [验收构型](./degeneracy-casebook.md)。本批落地射线商、有效支持评分、共享全等比较器及有限角色族；不是通用几何消元或维数判定器。

## 当前行为

### 角度先商射线

`scene/rays.ts` 在已有线载体上，按顶点区分正反射线，并用向量点乘和相对叉乘对固定代表复核。只有有实际有效点对的端点进入索引；不补齐被点对预算截掉的组合。

普通角由射线类对产生，各顶点轮转消耗角度预算，不再为同向端点的每种替换重复评价。同线反向射线保持分离，仍可产生补角与直角的剩余信息。纯载体恒等式不占据新等角结论，但代表角继续参与其它构型的等角／倍角比较。

别名以两端的端点列表保存，不展开笛卡尔积。完整对象用于选中和回看，代表角用于价值评分。共线卡片关闭时，已有载体仍可作为数值背景，并有明确的内部来源说明。

### 长度生成式共享规范化

`algebra/lengthConstraint.ts` 将当前正长度拟合转为整数对数行，消同量、约公共整数因子，保留原量的非零守卫。发现、有效支持与展示复用该模块。

例如：

```text
AB/BD=BC/BD             → AB=BC，BD 留作定义域守卫
AB²=AB·BC              → AB=BC，不能继续把 AB² 放在左边
EL/L₀=(1/2)(EF/L₀)     → 2EL=EF，L₀ 不再增加价值
```

长度模型标题展示非恒等规范行实际涉及的对象，完整参考量和原始成员仍可展开。若另一条有效行真正需要参考端点，该端点仍保留在信息支持中。

两种生成模型都按各条**新登记的规范约束**分别评分，取最大值；不再对全部拟合成员或参考对象的并集重新评分。原始 lifted 方向约束保留 π 分支，不改变 `dim` 的生成元数含义。

这是表达式内的确定消项，并未实现任意背景理想上的最小支持消元。有理空间仍负责已有观测的代数独立性／派生压缩，不能据此声称已找到绝对最小几何核心。

### 共享两顶点的全等

`relations/conditionalComparisons.ts` 只分析带明确对应的两三角形全等，且要求共享两个位置；普通不相交全等仍保留原摘要。

比较器分解三个对应边条件，取消相同边。对共同端点的等距条件，可以附加中垂线轨迹说明。若共同端点在另两点中点处，单独用场景坐标及相对等长误差复核该背景；不依赖 `Midpoint` 命令名称，也不依赖中点类型开关。

```text
△ABD≅△CBD
  AB=CB                 可由独立中点坐标检查作为背景
  BD=BD                 恒等，消去
  AD=CD                 仍是新条件：D 位于 AC 的中垂线上
```

没有中点背景时，保留两条非恒等条件。即使中点数值背景成立，也保留该小核心的独立评分，与剩余条件取最大值：自动检查成立不等于用户早已熟知，不能因此丢失一个可能高价值的核心。背景来源不取自全等自己登记的长度行，避免自我归因。完整三角形及已通过的非退化检查仍是原观察的前提；不在真实画布上创建中垂线或移动对象。

当前独立背景适配器仅覆盖此处的中点数值事实，并非任意等长背景数据库。下一步扩充背景提供器时必须继续遵守独立来源和核心不丢失原则。

### 有限角色族

`relations/roleFamilies.ts` 为可支持的类型做一个角色孔的投影，至少三个不同绑定才合并。当前支持普通角组、长度组、无复合等值类的量方程、具有两个三角形的相似／全等比较。

模板分别尊重：线段端点交换、普通角端点交换、等式集合次序、对应顶点的同时重排及两三角形整体交换。不会把一个对应列任意翻转，也不以无序点集替代对应关系。

界面可以显示：

```text
△(A·B·{D,E,F}) ≅ △(C·B·{D,E,F}) · 3 observations
```

这只表示 D/E/F 三个已验证实例。展开可查看共同条件、每个原实例及其剩余条件，并通过 Show more 查看后续实例。所有原来源 ID 和绑定均保留，派生结论能回溯到被合并的来源。

不根据重复次数推断全平面任意、不根据点集拟合推断整条轨迹成立、不自动产生两个角色孔的交叉组合。覆盖策略先选较大的族；没有入族的实例原样保留。族价值取成员条件最大值，覆盖数不加分。

## 数据与边界

- `RelationSupport` 区分有效对象、非零长度守卫、参考框架和背景对象；`scoringGroups` 保留分条件评分。
- `RelationCondition` 保存原始比较式、背景标记、来源和可选轨迹说明。
- `RelationFamily` 保存固定对象、明确的有限绑定、原始见证和共同条件。
- 全量见证仍用于画布联动；不能用显示截断替代有效支持约化。
- 数据通过现有 Worker 快照返回；不写入真实 GeoGebra，不做坐标试动。

角色族新增预算：每实例最多 16 个不同角色；每模板最多 8 个量（两三角形模板单独支持）；全轮最多 200,000 次投影、2,048 个桶和 64 个输出族。复杂等值簇原本已被压缩，超过模板上限时不再深加工，并说明原因。数量预算与单次模板大小同时控制，避免“次数有限、每次巨大”的隐性开销。

计划中的完整谓词 IR／一般背景事实库仍需随更多适配器发展；M5 脱离式试动、局部秩诊断与 M6 高阶线性参数族仍为后续研究。本批不以估计自由度或重复次数硬删除发现。

## 验证

新增 `relations/conditionalDegeneracy.test.ts`，覆盖同向／反向射线、别名代表仍可跨构型比较、枚举压缩、参考消去、真实参考依赖、模型评分、全等背景／剩余条件、有限绑定、错误对应、两孔组合保护及模板大小降级。

本批新增 19 项回归；全项目 28 个测试文件、313 项测试通过，TypeScript 检查和生产构建通过。另有回归确保新发现的背景核心不会因条件化而丢失其价值。

```sh

npx tsc --noEmit
npm run build
node node_modules/vite-node/vite-node.mjs scripts/geogebra-discovery-benchmark.ts --scale
```
