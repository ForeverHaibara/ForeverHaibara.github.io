# Welcome to my blog

This is a small, Markdown-maintained corner of my personal page.

I will use it for notes on mathematics, programming experiments, and ideas that are still taking shape. Articles live in `src/assets/markdown/blog/`, so publishing a new post only requires adding another `.md` file and committing it.

## A tiny example

The existing renderer supports regular Markdown, tables, code blocks, and mathematics:

```ts
const keepWriting = true;
```

When there is something worth keeping, it can become a post here.
