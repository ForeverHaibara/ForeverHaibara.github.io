
# Triples Library Documentation

Welcome to the documentation for the Triples library. This library provides tools for mathematical inequality proving using the Sum of Squares (SOS) method, primarily implemented in Python with SymPy.

This documentation site allows you to explore:
- How to get started with the library.
- Detailed API references for its core components.
- Examples and use cases.

## Navigation

Use the menu on the left to navigate through the different sections of this documentation.

- **Getting Started:** Learn how to install the library and run your first proof.
- **API Reference:** Dive deep into the functions, classes, and methods available.
  - `sum_of_squares`: The main function for SOS decomposition.

## About the Triples Solver

The "Triples Solver" tab on this website provides an interactive interface to a Gradio backend running the `sum_of_squares` function. You can experiment with different mathematical expressions and constraints to see the library in action.

Thank you for exploring the Triples library!
